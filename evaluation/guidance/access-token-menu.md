# Current SCA access-token menu

In the user-provided SCA screenshot, the **Profile** menu in the upper-right corner contains **Access Tokens**. The 2026.7 [Managing user access tokens](../../BlackDuck%20SCA/docs/help-center/administering-black-duck/access-tokens/managing-user-access-tokens.md) page calls this menu item **My Access Tokens**. Use the label shown in the current UI.

The screenshot does not show the token creation page. For the steps after opening **Access Tokens**, the 2026.7 SCA page says to click **Create New Token**, enter the token details, click **Create**, and copy the token while it is displayed.

The C/CPP Tool's token page documents a companion tool. It does not establish the SCA UI path.
