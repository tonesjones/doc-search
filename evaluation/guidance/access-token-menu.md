# Current SCA access-token menu

In the user-provided SCA screenshots, open the **Profile** menu in the upper-right corner, select **Access Tokens**, then click **+ Create Token** on the Access Tokens page.

The 2026.7 [Managing user access tokens](../../BlackDuck%20SCA/docs/help-center/administering-black-duck/access-tokens/managing-user-access-tokens.md) page uses the older labels **My Access Tokens** and **Create New Token**. Use the labels shown in the current UI. The screenshots do not show the creation dialog; for its fields and the steps after opening it, refer to the SCA page. Copy the token when it is displayed because it is shown only once.

The C/CPP Tool's token page documents a companion tool. It does not establish the SCA UI path.
