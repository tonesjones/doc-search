# Tool First Seen Date

The "first seen" date reflects the earliest date that a finding was imported (or
*seen*) by SRM, which will either be the date the finding was first observed in
SRM or the earliest date reported by a supported tool.

The following tools are supported and will provide a "first-seen" date:

- ApiSec
- Aqua
- ASoC
- AWS Security Hub
- CloudGuard
- Continuous Dynamic (formerly WhiteHat)
- Coverity
- Coverity on Polaris
- Dynatrace
- GitHub Security
- HackerOne
- Polaris
- Qualys WAS
- Seeker
- SonarQube
- Tenable.sc
- Twistlock
- Wiz
