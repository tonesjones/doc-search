# Understanding Rule Sets

In performing cross-tool analysis, results that do not have matching data can still refer
to the same issue. In this case, correlation depends on rule sets. A rule set consists
of multiple rules (e.g., specific tools and tool codes, categories of results in a
specific tool, CWEs, etc.) that are used to evaluate results and create findings. For
more information, see the section on Rule
Sets.
