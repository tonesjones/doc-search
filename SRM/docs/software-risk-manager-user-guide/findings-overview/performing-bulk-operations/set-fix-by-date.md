# Set Fix By Date

The *Set Fix By Date* button opens the *Set Fix By Date* dialog. The dialog is used
to either set or remove the fix-by date on all findings that are currently selected.

If a project is configured to use policies, this bulk operation is used to override the fix-by date that was
determined by the policy rules.
