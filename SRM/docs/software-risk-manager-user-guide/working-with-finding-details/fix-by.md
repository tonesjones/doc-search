# Fix By

Software Risk Manager allows users (with the `update`
role) to change the finding's fix-by date.
If the project is configured to use policies, a user can override a fix-by date that was determined by a policy rule.
If the project is not configured to use policies, a user can simply set or remove a fix-by date.

The controls for setting the fix-by date are located under the finding severity information, above the tag controls.

[image: image]

The dropdown allows the user to either pick a specific date to set as the finding's fix-by date, or the user can choose to
remove a finding's fix-by date.
