# Attachments

Allows files to be attached to the finding. Existing attachments are listed here.

[image: image]

To attach a file, click the Add Attachment button and select a file or use drag-and-drop.
Click an attachment to download its contents. To delete an attachment, click the
dropdown configuration icon and select Delete.
