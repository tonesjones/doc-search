# Predicted Status

**Note:** This section is only applicable to Software Risk Manager users with the Machine Learning
Triage Assistance add-on.

A finding’s prediction is included on the Finding Details page only if machine learning
is enabled on the Machine Learning Control Panel. Each prediction is presented as a
*Predicted Status*and a *Prediction Confidence*. Users can set a finding’s
Status to its *Predicted Status* by clicking on the Use Prediction button, which is
next to the finding’s prediction.
