# Installation

The Software Risk Manager Burp Suite plugin is available for download from the BApp Store
and from our [GitHub Repository](https://github.com/codedx/burp-extension/releases).

## BApp Store

To install the Software Risk Manager Burp Suite plugin from the BApp Store, go to the
Extender tab in Burp Suite, click the BApp Store tab, and click on *Code
Dx*.

  
 [image: image]   

On the right panel, click the *Install* button.

## GitHub Repository

The Burp Suite plugin can be found on our [GitHub Repository](https://github.com/codedx/burp-extension/releases).

  
 [image: image]   

To install the extension, go to the Extender tab in Burp Suite and click *Add*
in the Burp Suite Extensions section.

  
 [image: image]   

Click *Select file* for the Extension file field and navigate to the
burp-extension-assembly jar, then click *Next* to load the extension.

  
 [image: image]
