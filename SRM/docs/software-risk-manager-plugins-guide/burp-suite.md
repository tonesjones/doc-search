# Burp Suite

The Software Risk Manager Burp Suite plugin provides a way to upload Burp Suite findings
to your Software Risk Manager server from within Burp Suite.

A Software Risk Manager project and an API key are required. The API key must
have the `create`
role on the project it needs to interact with.

This section of the Plugins Guide explains how to install and use the Burp Suite plugin.
For more information, you may visit our [GitHub Repository](https://github.com/codedx/burp-extension). This plugin is open source and we welcome community
involvement.
