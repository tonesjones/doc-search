# Installation

The Eclipse plugin is installed through the usual plugin installation method. Navigate to
*Help* -> *Install New Software*. Then click the *Add* button to
add a new update site.

Enter *Code Dx* for *Name*. Enter https://eclipse.codedx.com/ for
*Location*.

Then click *OK*.

Select the *Code Dx* plugin and continue with the wizard in order to complete the
plugin installation process.
