# Finding Details View

The Finding Details view shows a minimal version of the Finding Details page in the Code
Dx application. If you have the `update`
role
for a project, you can change the status of a finding in that project and post to its
activity stream.

  
 [image: image]   

The toolbar contains a *Sync* button. When enabled, selections in the Findings table
will automatically update the information in the Finding Details view.

  
 [image: image]
