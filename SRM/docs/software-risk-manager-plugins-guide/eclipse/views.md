# Views

The Eclipse plugin provides two main views: the *Code Dx Findings View* and the
*Code Dx Finding Details View*. Both of these are available by navigating to
*Window* -> *Show View* -> *Other*.

  
 [image: image]   

The views will be located under the *Code Dx* folder.
