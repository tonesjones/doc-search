# Installation

The Software Risk Manager Jenkins plugin is available for installation through the
Jenkins plugin management page. You must be running Jenkins version 2.200 or later, or
one of the LTS releases [listed here](https://repo.jenkins-ci.org/releases/org/jenkins-ci/main/jenkins-bom/).
