# OWASP ZAP

The Software Risk Manager OWASP ZAP plugin provides a way to upload OWASP ZAP alerts to
your Software Risk Manager server from within OWASP ZAP.

A Software Risk Manager project and an API key are required. The API key must
have the `create`
role for
the project.

This section of the Plugins Guide explains how to install and use the OWASP ZAP plugin.
For more information, you may visit our [GitHub Repository](https://github.com/codedx/srm-zap-extension). This plugin is open source and we welcome community
involvement.
