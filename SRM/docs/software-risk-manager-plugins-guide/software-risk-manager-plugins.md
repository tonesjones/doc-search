# Software Risk Manager Plugins

There are a number of plugins available to make it easier to bring the power of Software
Risk Manager to other software development tools, including IDEs, CI/CD Build Systems,
and open source Application Security Testing tools. This guide includes instructions for
installing and using these plugins.

**Note:** SAML authentication isn’t currently supported for Software Risk Manager
plugins.
