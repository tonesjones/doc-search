# Data Directory

Software Risk Manager stores data in the data directory you configure during the
installation. The default location is the typical place used by your adopted platform to
place program data files. This can be changed, if needed, from the relevant installer
screen. For production installations of Software Risk Manager, we strongly recommend
that this data directory be part of your backup plan as it contains all data managed by
Software Risk Manager.
