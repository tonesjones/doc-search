# Uninstallation or Reinstallation

Software Risk Manager is distributed with an uninstaller, which will remove the files and
system services that were setup for Software Risk Manager. You will be prompted with the
choice of removing the data files used by Software Risk Manager. Be aware that removing
data files is irreversible and will result in data deletion.

To reinstall Software Risk Manager, running the uninstaller first is recommended.
