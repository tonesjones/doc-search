# EULA Acceptance

Normally after the initial installation of Software Risk Manager, the end-user license
agreement (EULA) will be presented to the first admin user to log in. You can configure
Software Risk Manager to skip this step by accepting the EULA via the props file:

```
codedx.eula-accepted = true
```
