# Getting the Binary

Please see Downloading Sigma for prerequisites. Then, follow these
steps to get the Sigma binary:

1. Download Sigma as a binary.

   At this point you can use Sigma as a standalone product for pre-flight
   testing, configuration, and so on.
2. For CI/CD: Upload Sigma to a location the CI/CD platform can access.

   This location can be a file repository to host the binary for
   curl commands to download.
3. For CI/CD: Create your CI/CD job templates to use the URL where the binary is
   hosted to download Sigma and run it.
