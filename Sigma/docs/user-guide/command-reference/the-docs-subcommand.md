# The docs Subcommand

## Syntax

sigma
docs

## Description

The `docs` subcommand opens the default browser and links to the *Sigma User
Guide*; afterwards, Sigma will quit.

Note: Do not use this command to access Sigma docs if the version of Sigma you're using
has been installed with Coverity.
