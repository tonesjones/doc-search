# Configuration Methods and Precedence

You can use the following methods to change the default Sigma configuration.

Note: The methods are listed in order of precedence.

- Command line

  Use the `sigma analyze` command to set configuration options for
  file scanning. See The analyze Subcommand.
- Environment variables

  These are described in Environment Variables.
- Local configuration file

  Use a configuration file to change global options and analyze options.
