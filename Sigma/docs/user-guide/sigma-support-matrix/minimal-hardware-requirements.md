# Minimal Hardware Requirements

| Operating System | Processor |
| --- | --- |
| Linux | x86_64 / ARM64 |
| macOS | x86_64 / ARM64 |
| Windows | x86_64 |

**Memory**

12GB for projects with less than 1 million lines of code; 9GB + 3GB per million lines of
code for larger projects.
