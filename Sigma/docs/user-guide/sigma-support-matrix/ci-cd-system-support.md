# CI/CD System Support

## Supported versions of GitHub

| Function | License/Tier requirements |
| --- | --- |
| Sigma as a quality gate | - github.com - GitHub Enterprise Server 3.0 |
| Code scanning with Sigma | - github.com  Public repositories and private repositories owned by   organizations where GitHub Advanced Security is   enabled - GitHub Enterprise Server 3.0 |

## Supported versions of GitLab

| Function | License/Tier requirements |
| --- | --- |
| Sigma as a quality gate | GitLab Free |
| Configure/customize Sigma as a "SAST Analyzer". See <https://docs.gitlab.com/ee/user/application_security/sast/analyzers.html>.  View JSON or SARIF results | GitLab Free |
| Security dashboard: Triage/manage vulnerabilities | GitLab Ultimate |

## Supported versions of Jenkins

| Function | Version requirements |
| --- | --- |
| Sigma as a quality gate | 2.440.3 or newer |
| Code scanning with Sigma | 2.440.3 or newer |
