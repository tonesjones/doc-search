# OS Support

The following Operating Systems are supported.

| OS | Architecture(s) | Version |
| --- | --- | --- |
| Linux | x86_64  arm64 | Kernel versions 4.4.0 or newer, glibc 2.28 or newer, and libstd++ 6.0.21 or newer. |
| macOS | x86_64  arm64 | macOS 14.x  Note: Support for macOS 14 is deprecated as of 2026.4.1 and will be removed in a future release.  macOS 15.x  macOS 26.x  Note: macOS x86 has been deprecated. |
| Windows | x86_64 | Windows 10 (deprecated)  Windows 11  Windows Server 2022  Windows Server 2025 |
