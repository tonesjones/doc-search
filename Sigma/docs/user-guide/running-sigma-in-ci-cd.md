# Running Sigma in CI/CD

The recommended workflow to run Sigma in CI/CD is as Rapid Scan Static on Polaris with
the appropriate Black Duck CI/CD plugin. Black Duck supports integrations with GitHub,
GitLab, Jenkins, Azure DevOps, Bitbucket, and more. See [Using Rapid Scan Static with Bridge](https://docs.blackduck.com/r/polaris/continuous-integration-for-polaris/using-rapid-scan-static-with-bridge.html) and [CI/CD Integrations](https://docs.blackduck.com/p/bridgeintegrations).

Direct integrations of Sigma with GitHub, GitLab, and Jenkins, including the Rapid Scan
Static Jenkins plugin, are deprecated.
