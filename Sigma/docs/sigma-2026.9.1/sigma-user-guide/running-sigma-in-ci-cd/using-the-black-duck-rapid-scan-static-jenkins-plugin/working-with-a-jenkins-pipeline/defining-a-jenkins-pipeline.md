# Defining a Jenkins Pipeline

The initial steps for defining a Jenkins Pipeline are as follows:

1. In the main Jenkins dashboard, click on New Item and select
   Pipeline.
2. Specify the Pipeline name in the Enter an item name field.
3. Click Pipeline and select either Pipeline script (for a scripted
   pipeline) or Pipeline script from SCM (for a declarative pipeline).

   The configuration screen displays a Pipeline section.
4. Click Pipeline Syntax at the bottom of the section to open another
   window that you can use to generate the pipeline code snippet.

   This is available for both scripted and declarative pipeline types.
