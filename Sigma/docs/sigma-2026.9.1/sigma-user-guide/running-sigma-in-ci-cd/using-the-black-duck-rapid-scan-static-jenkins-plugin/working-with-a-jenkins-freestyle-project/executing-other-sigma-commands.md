# Executing Other Sigma Commands

You can use the Command Line field to execute any Sigma command. These are
documented here: Command Reference.

For example, if you input the following,

```
config validate
```

the plugin will execute the command

```
sigma config validate
```

If you input

```
checkers
```

the plugin will execute the command

```
sigma checkers
```
