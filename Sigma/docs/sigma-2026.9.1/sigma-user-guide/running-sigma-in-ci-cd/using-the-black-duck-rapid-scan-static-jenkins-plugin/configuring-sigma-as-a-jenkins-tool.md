# Configuring Sigma as a Jenkins Tool

Configuring Sigma as a Jenkins tool ensures that Sigma can be executed by Jenkins agents.
How you configure it depends on whether you choose automatic or manual installation on
Jenkins agents.

Note: A Sigma tool installation must be defined for each operating system.
