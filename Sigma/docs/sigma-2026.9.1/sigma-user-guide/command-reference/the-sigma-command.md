# The sigma Command

## Syntax

sigma [FLAGS] [OPTIONS]
subcommands [subcommand-flags]
[subcommand-options]

## Flags

You may use the following flags with all subcommands.

| Flag | Description |
| --- | --- |
| `-h`, `--help` | Display help information |
| `-V`, `--version` | Display version information |

## Options

Options are listed and described in Configuration Options .
