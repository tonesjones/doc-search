# Delete a Polaris service account

Learn how to delete a service account in the Polaris user interface.

To delete a service account in the Polaris user interface, follow these steps:

Note: Only Organization Administrators can complete these steps.

1. Go to My Organization > Service Accounts.
2. Select the options [image: icon polaris options] icon next to the service account you want to delete, and select Delete.

   The Delete Access Token dialog appears.
3. Select Delete.

   CAUTION:

   Deleted service accounts can't be recovered.
