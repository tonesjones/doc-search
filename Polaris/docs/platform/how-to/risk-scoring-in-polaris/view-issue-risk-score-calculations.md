# View issue risk score calculations

To view a breakdown of how an issue's risk score was calculated, follow these steps.

1. Go to Portfolio, select an application, then select a project.

   The Issues tab opens.
2. Select an issue.

   The Issue Details panel appears.
3. Select the [image: Risk score calculation icon] icon next to the issue's Risk Score.

   The Risk Score Breakdown window appears. Here, you can see how the issue's score is adjusted, given the application's risk factors, applicable issue risk scores (SCA issues only), application and issue risk score weights, and the maximum issue risk score adjustment.
