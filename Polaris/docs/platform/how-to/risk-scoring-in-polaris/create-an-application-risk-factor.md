# Create an application risk factor

To create an application risk factor, follow these steps:

Note: Only Organization Administrators can complete these steps. You can create up to 100 application risk factors.

1. Go to My Organization > Risk Scoring.
2. Select Create risk factor.
3. (Optional) Enter a Name for the risk factor.

   Risk factor names can be up to 256 characters long, and can include spaces and special characters.
4. (Optional) Update the risk factor's Description.

   Descriptions can be up to 2048 characters long.
5. (Optional) Update the risk factor's categories:

   Each risk factor must include one or more categories. Category names can be up to 256 characters long and can include special characters.

   Tip: The category at the top is the default category. Once saved, the risk factor's default category is assigned to all the applications in your Portfolio.

   - To add a new category, select Add another value, enter a category name, and select the category's Risk Impact.
   - Select the delete [image: risk factor category delete icon] icon to remove a category.
   - Use the radio buttons to adjust the risk impact of different categories.

     Note: A risk impact of -5 (left) reduces risk scores. A risk impact of 0 (center) doesn't affect risk scores. A risk impact of 5 (right) increases risk scores.
6. Select Save.
7. Adjust values in the Weight column of the Application Risk Factors table, so the sum of all weights is equal to 100.
8. Select Save Changes.
