# Change an application's risk factors

To change the application risk factor categories assigned to an application, follow these steps:

Note: Only Organization Administrators, Organization Application Managers, and other users with permissions to manage application settings can complete these steps.

1. Go to Portfolio and select the application you wish to modify.
2. Go to Settings.

   Find the application's risk factors under General > Risk Factors.
3. Customize the application's risk factors, as required.
4. Select Save.
