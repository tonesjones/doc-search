# Modify a risk factor

1. Go to My Organization > Risk Scoring.
2. Select the options [image: risk factor options icon] icon next to the risk factor you wish to edit, and select Edit.

   The Edit Risk Factor or Edit Issue Risk Factor page opens (depending on the risk factor you modify).
3. Modify the risk factor, as required.

   The properties you can change vary depending on the type of risk factor you modify. When you modify an application risk factor, you can:

   - Update the risk factor's name and description
   - Add, rename, or remove categories
   - Change category impact values

   When you modify an issue risk factor, you can:

   - Change the risk factor's description
   - Change category impact values
4. Select Save.
5. Select Save Changes.
