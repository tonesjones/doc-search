# Delete an application risk factor

To delete an application risk factor, follow these steps:

Note: Only Organization Administrators can complete these steps.

1. Go to My Organization > Risk Scoring.
2. Select the options [image: risk factor options icon] icon next to the application risk factor you wish to delete, and select Delete.

   A confirmation appears.
3. Select Confirm.

   The Edit Risk Factor Weights window appears.
4. Adjust values in the Weight column, so the sum of all weights is equal to 100.
5. Select Save changes.
