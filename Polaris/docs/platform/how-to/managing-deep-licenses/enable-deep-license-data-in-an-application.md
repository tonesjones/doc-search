# Enable deep license data in an application

Deep license data can be enabled by Org Admins or Application Admins for the
application.

1. Go to **Portfolio** > (Select application) > **Settings** >
   **Licenses**.
2. Deep license data will be marked either **Inherited** or
   **Modified**/**Reset**.
3. Click either:

   1. **Edit** icon. Select
      or clear checkbox or
   2. **Reset** to return
      modified setting to default.
4. Select Save.
