# Enable deep license data in a project

Deep license data can be enabled by Org Admins or Application Admins for the project.

1. Go to **Portfolio** > (Select application) > (Select a project) > **Settings** tab > **Licenses**.
2. Deep license data will be marked either **Inherited** or **Modified**/**Reset**.
3. Click either:

   1. **Edit** icon. Select or clear checkbox or
   2. **Reset** to return modified setting to default.
4. Select Save.
