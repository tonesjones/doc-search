# Find a test UID

How to find and copy a test's unique identifier (UID).

A test UID uniquely identifies a test in Polaris. Test UIDs are often required to collect information about tests and issues using Polaris APIs. Sharing a test's UID can help support teams identify and resolve issues more efficiently. To find a test's UID, follow these steps:

1. Go to Tests and select a Test ID.

   Note: Alternatively, go to Portfolio, select an application, select a project, open the Tests tab, and select a Test ID.
2. Open the Debugging tab.

   [image: test artifacts debugging]
3. Find the UID under Test ID.

   Select the copy [image: icon test debugging copy uid] icon to copy the UID to your clipboard.
