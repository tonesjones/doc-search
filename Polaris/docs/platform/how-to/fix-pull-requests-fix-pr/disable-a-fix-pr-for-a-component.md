# Disable a Fix PR for a Component

For overview, prerequisites, and inheritance, see [SCA Fix Pull Requests](../fix-pull-requests-fix-pr.md).

If needed, you can disable Fix PR creation for a specific component.

1. Go to the Components tab.
2. Next to the component, click ⋮.
3. Click Create a Fix Pull Request.
4. Select Disable Fix Pull Requests.

   A Fix Pull Requests Disabled entry is recorded in the Triage Panel's Activity Log.

To re-enable Fix PRs for the component, follow the same steps but select Enable Fix Pull Requests.
