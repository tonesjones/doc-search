# Create a Manual Fix PR

For overview and prerequisites, see [SCA Fix Pull Requests](../fix-pull-requests-fix-pr.md).

1. Run an SCA test on an SCM-integrated project.
2. Select the project, open the Components tab, and click on a single component.
3. Click Create a Fix Pull Request.
4. In the selection dialog, choose your preferred Upgrade Guidance from the dropdown.

   Available options:
   - Short term recommendation
   - Long term recommendation
5. Click Create Fix Pull Request.
