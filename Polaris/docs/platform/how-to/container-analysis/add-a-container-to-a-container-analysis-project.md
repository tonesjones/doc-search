# Add a container to a Container Analysis project

How to add a container to a Container Analysis project in Polaris.

1. Go to Portfolio, select an application, and select a Container Analysis project.
2. Open the Containers tab.
3. Select Create New Container.

   The Create New Container window opens.
4. Enter a name for the container in the Name field.
5. (Optional) Enter a description in the Description field.
6. Select Save.
