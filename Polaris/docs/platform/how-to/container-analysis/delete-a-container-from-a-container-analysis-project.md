# Delete a container from a Container Analysis project

How to permanently delete a container and its scan results from a Container Analysis project in Polaris.

1. Go to Portfolio, select an application, and select a Container Analysis project.
2. Open the Containers tab.
3. Select the options icon next to the container you want to delete, and select Delete.

   A confirmation dialog appears.

   CAUTION:

   Deleting a container is permanent and cannot be undone. All scan results for the container will be deleted.
4. Select OK to confirm the deletion.
