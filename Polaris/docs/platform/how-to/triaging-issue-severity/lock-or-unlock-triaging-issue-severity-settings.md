# Lock or unlock triaging issue severity settings

By default, the following roles can enable or disable triaging issue severity in application or project settings:

- Organization Administrators
- Organization Application Managers
- Application Administrators
- Other users with permissions to manage application and project settings

Optionally, you can lock these settings so only Organization Administrators can enable or disable triaging issue severity in application or project settings. Organization Administrators can lock or unlock the setting at any time.

Note: Only Organization Administrators can complete these steps.

1. Go to My Organization > Triage.
2. Under Triage, select the lock [image: Lock icon] icon.

   Note: Select [image: Lock icon] to lock settings; select [image: Unlock icon] to unlock settings.
