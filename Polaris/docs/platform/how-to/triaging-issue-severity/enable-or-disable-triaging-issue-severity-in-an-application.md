# Enable or disable triaging issue severity in an application

To enable or disable triaging issue severity in an application, follow these steps:

Note: By default, Organization Administrators, Organization Application Managers, Application Administrators, and other users with permissions to manage application settings can configure this setting at the application level. However, Organization Admins may lock this setting. While locked, only Organization Admins can complete these steps.

1. Go to Portfolio and open an application.
2. Go to Settings > Triage.
3. Under Triage, select Edit.
4. Enable or disable Allow triaging issue severity, as required.

   When you disable Allow triaging issue severity, issue severity changes that have already been made are preserved.

   Important: Any issue severity changes that are pending approval are hidden (and can be restored by reenabling Allow triaging issue severity).
5. Select Save.
