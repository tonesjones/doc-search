# Enable or disable triaging issue severity for your organization

To enable or disable triaging issue severity in all applications and projects in your portfolio, follow these steps:

Note: Only Organization Administrators can complete these steps.

1. Go to My Organization > Triage.
2. Under Triage, select Edit.
3. Enable or disable Allow triaging issue severity, as required.

   When you disable Allow triaging issue severity, issue severity changes that have already been made are preserved.

   Important: Any issue severity changes that are pending approval are hidden (and can be restored by reenabling Allow triaging issue severity).
4. Select Save.
