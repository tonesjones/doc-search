# Integrate Secure Code Warrior with Polaris

Enable the Secure Code Warrior integration to include links to free training resources with issue details, when available.

## Enable the Secure Code Warrior integration

To enable the Secure Code Warrior integration, follow these steps:

1. Go to My Organization > Integrations.

   [image: scw enable]
2. Select Enable Secure Code Warrior Training.

## Find links to Secure Code Warrior

Once the Secure Code Warrior integration is enabled, links to free, interactive training resources appear in the Issue Details pane, when available. Links are context-sensitive, and direct you to training tailored to a specific issue.

[image: A screenshot that shows a link to Secure Code Warrior in the Issue Details panel.]

If you're interested in more of Secure Code Warrior's features, contact your Black Duck sales representative.
