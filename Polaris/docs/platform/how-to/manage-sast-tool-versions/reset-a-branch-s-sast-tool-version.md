# Reset a branch's SAST tool version

After you change a branch's Coverity version, you can select Reset (in the branch's settings) to remove the change. To do so, follow these steps:

1. Go to Portfolio.
2. Select an application, select a project, and go to Branches.
3. Select the branch you wish to modify.

   The Edit Branch window opens.
4. Select Reset (next to SAST Analysis).

   The Reset Settings: SAST Analysis window appears.
5. Select Confirm.

When you reset a branch's tool version, the branch will inherit its project's tool version.
