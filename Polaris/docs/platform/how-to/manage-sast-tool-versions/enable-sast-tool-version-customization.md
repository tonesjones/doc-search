# Enable SAST tool version customization

The ability to change Coverity versions is generally available, but cannot be used until the feature is enabled by Black Duck Support. To request the ability to change Coverity versions, follow these steps:

1. Select the Help [image: help icon] icon (near the upper-right corner of Polaris).

   The search panel opens.
2. Select Need additional help or support? (near the bottom of the panel).

   The How Can We Help You? page opens.
3. Select Submit a Case.
4. When Black Duck Community opens, create a support case:
   1. Select Polaris fAST using the Product dropdown.
   2. Enter `Enable SAST tool version customization` in the Subject field.
   3. Provide your Organization ID in the Description field, along with other details, as required.
   4. Select a Priority.
   5. Select Submit.

   See [Submit a support ticket](https://community.blackduck.com/s/article/Support-Guide#SubmitaSupportTicket) for more information.
