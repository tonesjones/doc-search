# Enable reachability analysis at the application level

Each application must be individually enabled after an Organization Admin has enabled reachability analysis at the organization level. Projects and branches inherit the application setting but can override it at their own level.

Note: Reachability analysis may impact SCA scan performance.

1. Go to Portfolio > select an application > Settings > Analysis.
2. Select Edit.
3. Enable or disable Enable reachability analysis for test as required.
4. Select Save.
