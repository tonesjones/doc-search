# Enable reachability analysis at the project level

Projects inherit the application setting but can override it at the project level.

Note: Reachability analysis may impact SCA scan performance.

1. Go to Portfolio > select an application > select a project > Settings > Analysis.
2. Select Edit.
3. Enable or disable Enable reachability analysis for test as required.
4. Select Save.
