# Enable reachability analysis at the branch level

Branches inherit the project setting but can override it at the branch level.

Note: Reachability analysis may impact SCA scan performance.

1. Go to Portfolio > select an application > select a project > Branches > select branch you want to edit.
2. Enable or disable Enable reachability analysis for test as required.
3. Select Save.
