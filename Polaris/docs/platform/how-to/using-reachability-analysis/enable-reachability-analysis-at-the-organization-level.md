# Enable reachability analysis at the organization level

Reachability analysis must first be enabled at the organization level by an Organization Admin before it can be enabled at lower levels. Enabling it here does not enable it for applications, projects, or branches. If later disabled at the organization level, all lower-level settings are turned off but restored when re-enabled.

1. Go to My Organization > Analysis.
2. Click Edit.
3. Enable or disable Enable reachability analysis for test as required.
4. Select Save.
