# Polaris UI Overview

Following is a summary of the Polaris UI features.

## Navigation

Use the Top and Left Navigation bars to access Polaris functions.

Table 1. Top and Left Navigation Bars

|  |  |
| --- | --- |
| [image: portfolio] | |
| *Top Nav* | Use to perform basic functions in Polaris. |
| Polaris YouTube | A link to the [Black Duck Polaris](https://www.youtube.com/@BlackDuckPolaris) channel on YouTube. |
| Dev Portal | Link to the Black Duck® Developer Portal. |
| [image: help icon] | Search through the Polaris documentation hosted in the Black Duck documentation portal. Documentation for Polaris is divided into two sets:   - [Polaris user documentation](https://docs.blackduck.com/access?ft:originId=4411d74355056751ace3917564d29bc0/dce6ee4226e0067782f65e5feb6313df.topic) - [Polaris continuous integration documentation](https://docs.blackduck.com/access?ft:originId=cba15d77e1e0a5989f94dbbae8f7dd44/cd6ad452381a0099cb4d143a5cad6fba.topic)   Select Need additional help or support? (near the bottom of the panel) to find links to API references, Black Duck Community, and support. |
| [image: ui account] | Sign out of Polaris, or:  - View your account information (including groups you belong to), or reset your password. - Manage your notification settings. - Create an access token for Polaris. - Download Bridge CLI. |
| *Left Nav* | Use to access pages to set up applications, projects, branches, run tests, and administer Polaris. |
| [image: portfolio icon] | The Portfolio page: Create and manage applications, projects, and branches. View and manage issues. |
| [image: test icon] | The Tests page: Start and monitor tests. View test details, statuses, progress, and comments from assessors. Download test artifacts for troubleshooting. |
| [image: licenses icon] | The Licenses page: Monitor and edit licenses from your whole portfolio in License Manager. |
| [image: ui dashboard] | The Dashboards page: Interactive dashboards you can use to analyze and visualize test and issue data from your applications and projects. |
| [image: ui reporting icon] | The Reporting page: Create a downloadable customized report of test results. |
| [image: policy icon] | The Policies page: Create issue and test scheduling policies that you can apply to applications, projects, and branches. |
| [image: my org icon] | The My Organization page: **(Admin only)** Allows administrators to manage Polaris for the entire organization. |
| [image: bd assist icon] | The Black Duck Assist page: Use Black Duck Assist to gain insight into your organization's data using a large language model (LLM). |
