# The Dashboards page

Use the Dashboards page to analyze and visualize SAST, SCA, and DAST test and issue data from your applications and projects.

Issues you import from third-party tools appear in dashboards, but the components and licenses associated with issues you import do not.

Table 1. Dashboards Page Interface

|  |  |
| --- | --- |
| [image: ui dashboards] | |
| **The Dashboards page** | |
| Dashboards dropdown menu (top left) | Select a dashboard to open it. Polaris includes the following dashboards:  - Component Management Dashboard - Executive Overview Dashboard - Issue Summary Dashboard - Onboarding Dashboard - Polaris Risk Dashboard - Policy Overview Dashboard - Portfolio ROI Dashboard - Remediation Dashboard - Table - Component Search - Table - License Search - Test Summary - Triage Approval Overview Dashboard |
| Filter controls (top center) | - Reset Filters: Restore a dashboard's default (out-of-the-box) filters. - Saved Filters: Apply, manage, or create saved filter configurations. - Save Filter: Save your current filter selections for future use. - Share [image: dashboard share button] : Send a copy of the active saved filter to one or more users or groups in your organization. |
| Filters panel (left) | After you change options in the Filters panel, select APPLY FILTERS to adjust the scope of the dashboard. Available filters vary from dashboard to dashboard. Select CLEAR ALL to clear all filters. Note: To restore a dashboard's default filters, select Reset Filters instead. |
| Options button   [image: dashboard options button] | Select the options button to:  - Refresh all of a dashboard's charts and widgets - Download a copy of a dashboard as a PDF or image |
| Dashboard | A collection of interactive widgets, charts, and tables you can use to analyze information about your applications, projects, and Polaris usage. You can:  - Hover over chart segments to see additional information. - Select chart segments and quantities to quickly apply filters. - Select an item in a chart's legend to hide/show data. |

Note: See [Work with dashboards](../how-to/work-with-dashboards.md) for more information.
