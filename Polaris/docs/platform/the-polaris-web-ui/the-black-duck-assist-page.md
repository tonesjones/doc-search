# The Black Duck Assist page

Use Black Duck Assist to gain insight into your organization's data using a large language model (LLM).

Table 1. Black Duck Assist Interface

|  |  |
| --- | --- |
| [image: ui bd assist] | |
| **The Black Duck Assist page** | |
| Conversations panel (left) | Conversations you start appear in the Conversations panel. Select a conversation to open it. Search and sort conversations using the options near the top of the panel. Tip: The first question asked in a conversation is used as the conversation's title.  Select + New Chat (near the bottom of the panel) to start a new conversation. |
| Message box (bottom right) | Type questions in the message box, and select Send to submit them. |
| Chat panel (right) | Find responses to your questions here. Example questions that you can select appear here each time you start a new conversation. |

Note: See [Chat with Black Duck Assist (Beta)](../how-to/chat-with-black-duck-assist-beta.md) for more information.
