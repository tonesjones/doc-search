# Accessibility statement

We're committed to ensuring Polaris meets the highest standards of accessibility and
usability. In support of this goal, the platform has transitioned from the legacy
Ember codebase to a modern React-based architecture. This migration represents both
a technical advancement and a significant enhancement to accessibility
capabilities.

The development team has incorporated comprehensive accessibility libraries directly into the React development process. Through the implementation of tools such as Storybook with accessibility plugins, developers can monitor real-time accessibility metrics during component creation. This approach ensures that accessibility is integrated into the development workflow from its earliest stages.

Beginning in mid-2025, select features will be transitioned to this new React foundation with enhanced accessibility controls. The complete migration is scheduled for completion throughout 2026, which will standardize Polaris under a more accessible, modern framework.

Accessibility remains a fundamental priority in ongoing development efforts. The Polaris team is committed to continuous improvement in accordance with Web Content Accessibility Guidelines (WCAG), ensuring the platform meets the needs of all users.
