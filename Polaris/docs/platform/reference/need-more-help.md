# Need more help?

## System status

To see the status of Polaris and other Black Duck products, go to <https://status.blackduck.com>. The page shows 90 days of service health history. Select the Polaris filter to view the status of different Polaris instances and services.

Tip: You can subscribe to status updates. Select Subscribe to Alerts to get started.

## Use Polaris to sign into resources on the Help page

When you sign into Polaris, you can access the following resources without signing in a second time:

- Black Duck Support
- Black Duck Community

For best results, sign into Polaris, select the Help [image: help icon] icon, select Need additional help or support? (at the bottom of the search panel), and use the links on the Help page to access Black Duck Support or Black Duck Community. You won't be required to sign into those other resources. If you already have an account at one of those sites *that uses the same email that you use to sign into Polaris*, all your existing issues and messages will still be there.

Black Duck Support can help if you have issues with accounts that you think should be linked, but aren't.

Note the following:

- To ensure the Submit a Case and View Open Cases buttons function as expected, the first and last name associated with your Polaris account should only include English characters.
- Polaris credentials don't work when entered into the sign-in fields on Black Duck Community. (Unless you have used the same password for all your accounts — which you should not do.)
- Changing your password in Polaris doesn't change your password on the Black Duck Community site.

## Contact Black Duck Customer Support

If you have questions or need support, click the Help [image: help icon] icon at the top right from anywhere in Polaris. Use the search panel to search the Polaris documentation, or select Need additional help or support? (at the bottom of the search panel) to open the Help page.

[image: A screenshot of the Help page.]

From the Help page, you can open a support ticket, monitor support tickets, find documentation, or go to the Black Duck Community: <https://community.blackduck.com>.

Note: For troubleshooting failed tests, you may be able to download test artifacts from the Polaris user interface. Sharing a test's UID can help support teams identify and resolve issues more efficiently. See [Download test artifacts](../how-to/download-test-artifacts.md) and Find a test UID for more information.
