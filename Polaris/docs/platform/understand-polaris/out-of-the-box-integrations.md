# Out-of-the-box integrations

Several integrations are available that allow Polaris to interoperate with various tools and platforms.

## Code Sight integration

Black Duck®
Code Sight™ provides an interface for viewing issues reported by various Black Duck products, to help improve the security and reliability of your source code. After you connect Code Sight to Polaris, you can:

- View issues captured in Polaris in your IDE (in Team View).
- Run tests on Polaris from your IDE with VS Code.

For more information, see [Connect Code Sight to Polaris](../how-to/connect-code-sight-to-polaris.md).

## Issue tracking integrations

Manually export issues captured in tests to Azure DevOps or Jira, or use issue policies to automatically export issues to Azure DevOps or Jira. For Jira Cloud, you can also configure two-way synchronization of Polaris triage statuses and Jira ticket statuses.

For more information, see [Issue tracking integrations](../how-to/issue-tracking-integrations.md).

## SCM integrations

Run automated tests when commits are made in your repositories. Supported SCMs include:

- GitHub
- GitLab
- Bitbucket
- Azure DevOps

For more information, see [Connect a Polaris project to a repository in your SCM](../how-to/connect-a-polaris-project-to-a-repository-in-your-scm.md) and Connect Polaris to Multiple SCM Repositories.

## Secure Code Warrior integration

Enable the Secure Code Warrior integration to include links to free training resources with issue details, when available.

[image: A screenshot that shows a link to Secure Code Warrior in the Issue Details panel.]

For more information, see [Integrate Secure Code Warrior with Polaris](../how-to/integrate-secure-code-warrior-with-polaris.md).

## Issue Management MCP server

Use the Issue Management MCP server to retrieve data from Polaris with your preferred AI assistant. The MCP server enables you to:

- Query your security findings using natural language in AI assistants
- Retrieve issue details, remediation guidance, and portfolio metrics

The MCP server is hosted in Polaris and requires only a Polaris access token for authentication. No installation or deployment is required.

For more information, see [Issue Management MCP server](../how-to/issue-management-mcp-server.md).

## Continuous integration for Polaris

Incorporate testing in your pipelines with devops-focused integrations. Build custom integrations and workflows with Polaris APIs.

For more information, see [Continuous integration for Polaris](https://docs.blackduck.com/access?ft:originId=cba15d77e1e0a5989f94dbbae8f7dd44/cd6ad452381a0099cb4d143a5cad6fba.topic).
