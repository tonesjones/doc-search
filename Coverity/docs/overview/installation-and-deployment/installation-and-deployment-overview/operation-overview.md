# Operation overview

The Operation phase consists of post-deployment tasks to configure, maintain, and monitor your
organization's Coverity deployment.

System configuration
:   The "What's Next" list
    provides an overview of tasks that you need to complete in order to set up your
    system (mainly administrative tasks).

System maintenance
:   System maintenance provides recommendations for you to enable features and
    settings that will maintain the size of the Coverity Connect database.

Monitoring the system
:   Monitoring the system is an important part of the process. It is suggested that
    you record trend data over time so you can make sure that the entire system is
    performing optimally. Guidelines for monitoring are provided in Monitoring and diagnosing Coverity Connect performance.

System enhancements and upgrades
:   This step represents the ongoing improvements to the deployment, through
    upgrading new versions and implementing new features.
