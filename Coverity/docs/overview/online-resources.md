# Online resources

You might find the following resources helpful in getting additional information,
support, and training.

## Black Duck Community

Coverity Customer Center (<https://community.blackduck.com/s/>, requires
login)

- Product downloads
- Information and resources such as sample scripts to use in your
  deployment

## Documentation portal

The [Black Duck Documentation
Portal](https://docs.blackduck.com/p/coverity) provides access to the Release Notes, Installation and Upgrade
Guide, and other technical documentation. To install or upgrade this release, you
need to read these documents.

## Support

If you need assistance, please open a Support case by logging in to the [Black Duck Community site](https://community.blackduck.com/s/contactsupport).

## Training

For a catalog of online courses offered by Black Duck Academy (login required), see
<https://blackduck.skilljar.com/#solution_coverity> .

For Coverity tutorials (no login required), see <https://community.blackduck.com/s/coverity-tutorials>.
