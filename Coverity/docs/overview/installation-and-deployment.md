# Installation and deployment

The Coverity 2026.6.0 Installation and Upgrade Guide contains information to help you plan for a
Coverity product deployment. This guide is intended for system architects, deployment
architects, and build engineers who are responsible for the planning and installation of
Coverity tools.

Product functionality, configuration, and operation instructions that are unrelated to
deployment are not covered in this manual, so it is assumed that you have a knowledge of
Coverity products and features. For more detailed information about Coverity tools,
refer to the following documentation:

- Coverity Platform 2026.6.0 User and Administrator Guide - Guidance for system administrators and end users
  of Coverity Connect.
- Coverity Analysis 2026.6.0 User and Administrator Guide - Guidance for build engineers or
  system architects to integrate and configure `cov-analysis` tools
  with the nightly build system.

The complete documentation set for Coverity products can be found under the root installation
directory of either Coverity Connect or Coverity Analysis:

```
<coverity_product_install_root>/doc/
```

- Coverity product overview
- Installation and deployment overview
