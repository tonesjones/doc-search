# Upgrade overview

This chapter provides an overview of the process for upgrading Coverity Connect and Coverity
Analysis to the latest version, with a few tips.

The main steps are:

1. Understand
   product names and installer contents
2. Download installers and
   documentation
3. Understand the impact of changed features on your
   upgrade
4. Adjust performance
   settings
5. Upgrade Coverity Connect
6. Upgrade Coverity Analysis
7. Upgrade Coverity Desktop plug-ins

Important: If you are upgrading a Coverity cloud deployment, refer to
"Upgrading a Coverity cloud deployment"
in the Coverity 2026.6.0 Cloud Deployment Administrator and User Guide. This document provides
important information for administrators who are deploying or upgrading Coverity in a
Kubernetes container environment.
