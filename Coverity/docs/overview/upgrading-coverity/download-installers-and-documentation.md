# Download installers and documentation

All Coverity installer files are on the [Black Duck Community site](https://community.blackduck.com/s/contactsupport). To download Coverity software, you must
have a user account.

Black Duck sent the Black Duck Community credentials to
your license administrator. If you are a license administrator and did not receive
the credentials, or if you do not know who your license administrator is, file a
support ticket here: <https://community.blackduck.com/s/contactsupport> and ask for guidance.

Download the files you need, based on your installation
platform:

- **Coverity Platform package** - This package contains the Coverity Platform installer (the
  server package). Download for the OS platform on which you run Coverity
  Connect.
- **Coverity Analysis package**  - This package contains the Coverity Analysis installer (the
  package client). Download for every OS platform on which you build and
  analyze your source code with Coverity analysis components.
- **Utilities package** - This is your Host ID utility. Download for every OS platform on which
  you plan to install Coverity Analysis or Coverity Connect, if your
  license for that platform requires a Host ID. Note that on some machines
  with complex or multiple network connections, the platform-specific Host
  ID Utility will not produce correct results. If you have problems,
  download and use the platform-independent Java Host ID utility.
- **Documentation package** - This is a subset of the complete
  documentation collection included in the installer files. This subset
  contains the Coverity 2026.6.0 Installation and Upgrade Guide (which contains
  deployment, installation and upgrade instructions), the Coverity 2026.6.0 Release Notes, the Coverity 2026.6.0 Release Notes Archive, and the Coverity 2026.6.0 Cloud Deployment Administrator and User Guide. The documentation is available
  in English, Chinese, Japanese and Korean. Download the Installation
  Documentation bundle of your choice.
