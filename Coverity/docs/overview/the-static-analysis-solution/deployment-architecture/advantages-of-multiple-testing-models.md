# Advantages of multiple testing models

The availability of different testing models makes it possible to introduce static analysis
without alienating developers who like to keep control of their processes. Rather than
forcing them to use another tool, you can first deploy Coverity in the nightly and
weekly Jenkins continuous integration builds. Development managers can then present
Coverity findings as work items, email, or issues in code reviews. Voluntary, hands-on
use of Coverity will grow as developers elect to fix their own issues earlier in the
process and before they are introduced into the main branch.
