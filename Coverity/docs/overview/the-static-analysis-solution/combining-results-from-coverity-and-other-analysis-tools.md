# Combining results from Coverity and other analysis tools

A complete analysis of your code might require results from tools other than Coverity.
Mature software development organizations often have legacy tools that have gathered
valuable information.

You can import results from other analysis tools into a Coverity project using the
Third-Party Integration Toolkit. Once imported, these results can be shown interleaved
with Coverity findings. This allows you to make your analysis more efficient by looking
at all results in one place. It also makes it possible to compare the effectiveness and
scope of analysis performed by different tools.
