# Deployment architecture

A basic Coverity deployment consists of two core components:

- Coverity Analysis – The static analysis engine that identifies issues in your code
  base.

- Coverity Connect – a web-based interface for managing issues found by Coverity
  Analysis and other tools. Functionality includes triaging, organizing, and reporting
  on issues.

Deciding your deployment architecture means finding the right configuration for the
workflow you want to use.

Analysis can be local, central, or a combination of the two. The following sections provide two
basic examples.
