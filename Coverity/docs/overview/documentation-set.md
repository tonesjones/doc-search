# Documentation set

Coverity provides a rich and extensive documentation set numbering in the thousands of
pages. But, depending on your role, you are not likely to have to read more than a
subset of it. This section describes the Coverity documentation set other than
installation documents.

## Coverity Platform (Coverity Connect) Components and Extensions (Issue Management, Reporting, Web Services)

- Coverity Platform (Coverity Connect, Coverity Policy Manager, Coverity Reports): Setting up and
  using Coverity Platform components.

  Coverity Platform User and Administrator Guide

  Configuring and Generating Coverity Reports
- REST Web Services: Creating REST Web applications or scripts that communicate with the Coverity
  Connect database.

  Coverity Platform REST Web Services API Guide
- SOAP Web Services: Creating SOAP Web applications or scripts that communicate with the Coverity
  Connect database.

  Coverity Platform SOAP Web Services API Reference
- SonarQube plug-in: View and triage Coverity issues from the SonarQube
  environment. The [*Sonar plug-in GitHub repository*](https://github.com/coverity/coverity-sonar-plugin/releases) contains `.jar`
  files for the latest version of the plug-in, along with installation and use
  instructions in the Coverity.Sonar.Plug-in.pdf file.
- Compliance Filtering: The Coverity Compliance Guide contains information to help you configure
  and use Coverity Compliance Filtering.

  Coverity Compliance Guide

## Coverity Analysis Components and Extensions (Analysis, Compiler and Third-party Issue Integrations)

Coverity, Compiler Integration Toolkit (CIT), Third Party Integration Toolkit:
Setting up and running analyses from the command line, making additional compilers
available, and integrating third-party issues into the Coverity Connect database.

- Coverity Point and Scan UI and the Coverity CLI
- Coverity Analysis User and Administrator Guide
- Coverity CodeXM: Checker development and the CodeXM language and libraries

## Coverity Analysis: Custom Checker Development (CodeXM and Extend SDK)

- Coverity CodeXM: Checker development and the CodeXM language and libraries

  CodeXM Checkers Development Guide
- Coverity Extend SDK: Creating custom checkers to enhance the analysis of your source code.
  Checkers created with the Coverity Extend SDK supplement the built-in
  Coverity checkers.

  Coverity Extend SDK Checker Development Guide

## Coverity Desktop Analysis (Local Analysis and Coverity Desktop Plug-ins)

- Coverity Desktop Analysis: Using Desktop Analysis tools to find, manage, and fix software issues
  from your desktop.

  Desktop Analysis: User Guide
- Coverity Desktop for Eclipse: Using Eclipse-based IDEs to find, manage, and fix software issues
  from your desktop.

  Coverity for Eclipse, Wind River Workbench, and QNX Momentics: User Guide
- Coverity Desktop for Microsoft Visual Studio: Using the Microsoft Visual Studio IDE to find,
  manage, and fix software issues from your desktop.

  Coverity Desktop for Microsoft Visual Studio: User Guide
- Coverity Desktop for IntelliJ IDEA: Using IntelliJ IDEA to view, manage, and fix software issues
  from your desktop.

  Coverity Checker Reference

## Reference books (Coverity Platform, Coverity Analysis, and Coverity Desktop)

- Coverity Commands: Understanding the commands used to set up and run analyses and to perform
  other important tasks.

  Coverity Checker Reference
- Coverity and Sigma Checkers: Understanding the checkers that find issues in your source code,
  modeling library functions/methods, understanding security issues, and
  getting remediation advice. End users need to understand the issues found by
  checkers. Administrators can enable and disable the checkers that are used
  to analyze source code. Developers can improve analysis results by creating
  models that simulate the behavior of library functions/methods.

  - Coverity Checker Reference

    - Checker enablement and option defaults by language
    - Software issues and impacts by checker
  - Sigma Checker Reference
- Security Directives Reference
