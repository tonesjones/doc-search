# Assessing security of unfamiliar source code

Sometimes, security analysts need to evaluate a product’s source code for software
security. Coverity's Point and Scan application supports such users by allowing them to
perform analysis on a given target without any knowledge of the source to be examined.
They can simply specify the location of the source files and where they want to upload
results; Point and Scan does the rest. After scanning the code, it returns summary
information about the files it was able to scan, the files it could not scan, and the
files it ignored. Filters are available to narrow results, and you can examine
individual issues by opening files and looking for flagged issues.
