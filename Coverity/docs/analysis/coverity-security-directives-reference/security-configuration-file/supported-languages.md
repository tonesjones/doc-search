# Supported languages

Each configuration file applies to a *single language category*. An analysis can
employ more than one configuration file.

The following languages are supported by the configuration file: C, C++, Objective-C,
Objective-C++, C#, Java, JavaScript, .NET, and Visual Basic.

The configuration file's `language` field specifies the language category
that this configuration file supports. See Top-level value.
