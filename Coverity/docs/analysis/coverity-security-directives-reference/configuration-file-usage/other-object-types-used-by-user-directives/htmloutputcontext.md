# HtmlOutputContext

**Used by these directives:**
`method_with_servlet_sinks_on_input`,
`method_with_servlet_sinks_on_output`

An `HtmlOutputContext` value describes the lexical context that precedes
an HTML fragment.

An `HtmlOutputContext` can be specified using one of the following field
names:

- html_attribute_value_where_name_is_from_param
- html_prefix
