# About this guide

The Coverity Compliance Guide contains information to help you configure and use Coverity
Compliance Filtering. This guide assumes the following personnel will be involved in
these activities:

- The architect or quality manager who configures the product by creating and
  maintaining filtering policies. Relevant chapters for the architect/quality
  manager to read are: Coverity Compliance Filtering Overview, Regulating issue creation, and the `cov-manage-findings` command.
- The developer who uses Coverity Connect issue scores to prioritize development
  tasks. The relevant chapter for the developer to read is Using scores to prioritize development tasks. The developer might
  also get some benefit from reading Coverity Compliance Filtering Overview.

You can find the complete documentation set for Coverity products under the root
installation directory of Coverity Platform and Coverity Analysis:

```
<coverity_product_install_root>/doc/
```
