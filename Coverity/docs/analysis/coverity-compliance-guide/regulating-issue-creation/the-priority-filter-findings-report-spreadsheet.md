# The priority filter/findings report spreadsheet

The set of filtering policies you create for a particular stream is called a *priority
filter*. A sample priority filter is provided in the Coverity Analysis
installation directory at
<install_dir/doc/examples/findings-report-sample-spreadsheet.xlsx.
This sample is also pictured below.

Note that the sample contains a sample priority filter (on the Priority
Filter tab) as well a sample *findings report* (distributed across
the Filtering Report, Directory Distribution
Report, and Standards Distribution Report
tabs):

  
 [image: image]   

You can create you own priority filter by copying and editing the sample. You can
alternatively create a priority filter by generating a findings report.
