# Update or remove a priority filter

To update a priority filter, edit the entries on the Priority
Filter tab of the spreadsheet and re-upload it to Connect.

To remove a priority filter, edit the Priority Filter tab by
deleting all entries in columns B (Path), C
(Compliance), and D (Score), and
re-upload it to Connect.
