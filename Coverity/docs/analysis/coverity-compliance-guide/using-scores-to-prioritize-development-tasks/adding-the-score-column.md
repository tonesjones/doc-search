# Adding the Score column

Coverity Connect views allow you to sort a column by clicking on the column head. In
order to sort by score in Coverity Connect, you must first add the
Score column to one of your views:

1. Display the view to which you want to add the Score
   column.
2. Open the view settings:

     
    [image: image]
3. On the Columns tab, enable the
   Score checkbox and click
   OK:

     
    [image: image]   

   The Score column is available only on views of type
   Issues: By Snapshot.
