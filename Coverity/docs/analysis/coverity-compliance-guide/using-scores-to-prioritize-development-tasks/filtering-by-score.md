# Filtering by score

To filter a view by score:

1. Display the view that you want to filter.
2. Open the view settings:  
    [image: image]
3. On the Filters tab, specify a value for the
   Score filter and click OK, for
   example:  
    [image: image]   

   The value can be a single digit (0–9), a range (for example 5–7), less than
   a value (for example <5), or greater than a value (for example
   >5).

   Note: The Score filter is available only on
   views of type Issues: By Snapshot.
