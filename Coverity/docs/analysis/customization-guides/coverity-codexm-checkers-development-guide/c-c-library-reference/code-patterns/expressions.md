# Expressions

Patterns in this section belong to the `expression` class.

Expression patterns match expressions in the target code.

Many statements in C or C++ code contain expressions.
The patterns in this section match specific kinds of expressions.

Remember:
The patterns shown in the Literals and
Operators sections are expressions, too.
