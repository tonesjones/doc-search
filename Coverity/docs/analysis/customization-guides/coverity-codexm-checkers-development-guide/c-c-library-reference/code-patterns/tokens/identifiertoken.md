# identifierToken

An identifier.

An identifier might be a user-defined identifier (for example, `"iterations"`),
a preprocessor identifiers (for example, `"ifdef"`),
a language keyword (for example, `"friend"`, `"operator"`),
or a compiler-specific keyword (for example, `"_Pragma"`).
