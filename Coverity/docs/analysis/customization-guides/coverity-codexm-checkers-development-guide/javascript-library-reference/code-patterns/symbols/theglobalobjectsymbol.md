# theGlobalObjectSymbol

Matches the global object.

This pattern only matches nodes of type `symbol`.

## Properties

`theGlobalObjectSymbol` does not expose any new properties.

**Inherits properties from:**

- symbol

## Example

The JavaScript `window` object is the global object in the browser.
