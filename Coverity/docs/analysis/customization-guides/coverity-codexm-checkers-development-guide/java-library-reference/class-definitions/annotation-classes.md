# Annotation classes

Annotation classes match annotation constructs in the target code.
Annotations add metadata that can be used to help manage code, specify run-time behavior, and for a variety
of other purposes.

When used with Coverity, in particular, an annotation can specify how Coverity Analysis should treat an object;
for example, a call to a particular function.
