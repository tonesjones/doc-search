# CodeXM character set

Characters in a CodeXM source file are limited to the original 95 ASCII characters that can be typed or printed.

This set includes the uppercase and lowercase letters from A to Z, the ten digits, and 33 special characters in common use.
Extended characters such as letters with accents are not supported.
