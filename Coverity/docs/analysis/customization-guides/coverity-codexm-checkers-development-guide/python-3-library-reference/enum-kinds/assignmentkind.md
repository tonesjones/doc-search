# assignmentKind

The type of an assignment statement.

`assignmentKind` defines the following values:

| Name | Description |
| --- | --- |
| `` `augmented` `` | Augmented assignment using one of the following operators: `+=`, `-=`, `*=`, `/=`, `|=`, `&=`, `%=`, `^=`, `>>=`, or `<<=` |
| `` `simple` `` | Simple assignment using the `=` operator |
