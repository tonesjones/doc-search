# Attribute classes

CodeXM attribute classes match attribute constructs in the target code.

Attributes add metadata that can help manage code, specify run-time behavior, and be used for a variety of other purposes.

When used with Coverity, in particular, an attribute can specify how Coverity Analysis should treat an object; for example, a call to a particular function.
