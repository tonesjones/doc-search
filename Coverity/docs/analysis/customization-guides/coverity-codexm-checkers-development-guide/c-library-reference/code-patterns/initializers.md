# Initializers

CodeXM patterns in this section belong to the `initializer` class—or the `ctorinit` class, in the case of the constructor initializers.
They match initializers in the target code.

In many cases, an initializer can look the same as an assigment statement. However, many languages treat initialization as its own, special case.
The CodeXM language libraries treat initialization in this way, as well.
