# Identifying vulnerable data

Coverity lets you manage how checkers treat incoming or outgoing data that is
potentially insecure. It also provides checkers that examine how source code treats
sensitive data.

*Trust settings* are meant especially to monitor the flow of data that might be
tainted and possibly malicious. Similar settings monitor the flow of *sensitive
data* such as user passwords, credit-card information, medical information, and
so on.
