# STL construct patterns

- `STL_container` — Match an expression that denotes an instance
  of an STL container. Member functions are provided that match invocations of
  corresponding member functions on the container..
- `STL_iterator` — Match an expression that denotes an instance
  of an STL iterator. Member operators are provided that match applications of
  operators to the iterator.
