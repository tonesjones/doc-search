# Variable kind patterns

There are several pattern types that match uses of specific kinds of variables. Some of
the more important are next.

Table 1. Patterns for variables

| Parameter | Usage |
| --- | --- |
| `LocalVar` | use of local variable |
| `StaticVar` | use of a variable with static storage duration |
| `GlobalVar` | use of a variable with global scope |

See Variable reference expression patterns for more information.
