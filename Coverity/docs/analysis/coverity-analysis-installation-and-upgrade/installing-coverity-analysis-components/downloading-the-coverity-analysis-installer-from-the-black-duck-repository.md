# Downloading the Coverity Analysis installer from the Black Duck repository

In order to facilitate automated installer downloads, the Coverity Analysis installer is
available from the Black Duck Community repository. To obtain
access to the repository:

1. Log in to Black Duck Community at <https://community.blackduck.com/s/>.
2. Navigate to the Software Licenses page.
3. Click the View/Request Docker Registry Credential
   button.

   [image: image]
4. Email is sent to your Black Duck Community account email address with further
   instructions.
