# Coverity SCM support

The following table lists the supported Source Control Management (SCM) systems for
Coverity.

The minimum system requirements are the same as those defined for Coverity Analysis. For
more information, see Coverity Analysis.

Browser requirements are the same that are defined for Coverity Connect.

Table 1. Coverity supported SCM systems

| Supported SCM systems | SCM version | Supported OS | Notes |
| --- | --- | --- | --- |
| Git | Any version currently supported by the vendor | Linux and Windows |  |
| Perforce | Any version currently supported by the vendor |
| Plastic | 6.0.16.975-6.0.16.x (where x is greater than 975) |
| SVN | 1.14 |
