# Getting started with Coverity Analysis

Coverity Analysis is primarily for administrators (and power users) who need to set up
and run analyses of code bases. You can get started with analyses of your source code by
using the GUI-based Point and Scan application or by using the command line. For
details, see the following documentation:

- Running analyses using the GUI-based Point and Scan application is the easiest
  way to get up an running quickly with quality, security, and test analyses.
