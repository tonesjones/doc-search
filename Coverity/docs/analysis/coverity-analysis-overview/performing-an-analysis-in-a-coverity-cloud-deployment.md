# Performing an analysis in a Coverity cloud deployment

For a scan performed by the Coverity Scan Service within the cloud, you can
configure options that determine how a scan is performed. The sections that follow cover
the following topics:

- Introduction to Coverity cloud
  deployment
- Languages supported by the Thin Client
- Installing client software
- Using the Black Duck Bridge CLI to integrate Thin Client analysis into pipelines
- Creating a project and a stream
- Performing an analysis: in-cloud vs on-prem
- Creating a Coverity configuration file
- Specifying an asynchronous
  or synchronous analysis
- Setting up scan workflows
- Initiating a scan
- Preparing to initiate Scan Service analyses from the full client
- Viewing scan status and downloading scan logs and
  reports

Note: For information on the Thin Client CLI used on a client system in a Coverity
cloud deployment, including how to install and set up the Thin Client, see Coverity 2026.6.0 Cloud Deployment Administrator and User Guide.
