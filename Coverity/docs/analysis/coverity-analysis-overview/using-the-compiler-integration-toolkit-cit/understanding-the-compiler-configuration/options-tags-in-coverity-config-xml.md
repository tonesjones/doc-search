# <options> tags in 'coverity_config.xml'

The following options control how the command line from your compiler is translated by Coverity tools.

- Tags for native preprocessing
- Tags for skipping compilations
- Tags that influence translation
- Tags for transforming the native command line to the Coverity compiler
- Tags for phases of command-line transformations
- Tags for internally passing information from 'cov-build'
- Tags for handling response files
- Tags for processing commented lines in response files
- Tags for directing which groups the options are applied to
