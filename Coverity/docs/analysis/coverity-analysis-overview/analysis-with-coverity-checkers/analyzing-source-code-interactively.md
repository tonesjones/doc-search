# Analyzing source code interactively

Coverity Analysis can analyze applications that are written
in a number of programming languages (see Coverity language support).

After installing and deploying Coverity Analysis, you can run an analysis and
commit a snapshot of the resulting defects to Coverity Connect. This
section covers post-installation procedures. For more information about deployment and
analysis options for a production environment, see Coverity Analysis overview.
