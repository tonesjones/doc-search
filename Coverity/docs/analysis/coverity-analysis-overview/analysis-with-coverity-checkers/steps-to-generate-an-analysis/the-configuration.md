# The configuration

Before running an analysis, you typically generate a one-time configuration for your
native compiler or interpreted language (such as JavaScript).
However, depending on your use case, generating a compiler configuration might not be necessary if you use the Coverity CLI.
See "Using the Coverity CLI" in the Guide to the Coverity 2026.6.0 Point and Scan UI and the Coverity CLI.

Use the `cov-configure` command to generate the configuration.
This command is described in the Coverity 2026.6.0 Command Reference.
The configuration generated by `cov-configure` will be used when you perform the
capture step of the analysis process.

Important:
You need to run `cov-configure` a separate time for each compiler or scripting language that you intend to analyze.

The configuration provides information about the language of the source files to capture and analyze.
It also provides settings that are used to emulate your native compiler, its
options, definitions, and version. A correct configuration allows the Coverity Analysis
to properly translate the arguments of the native compiler and to parse the source code
into a form that is optimized for efficient analysis during the capture step of the
analysis process.

Note:
For language support information, see the "Coverity language support" table.
