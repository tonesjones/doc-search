# Viewing issues

After you commit the results of an analysis, you can use Coverity Connect
to explore the results and view specific details.

The steps for viewing issues are straightforward:

1. Log in to the Coverity Connect web site that is used by your project.

   The interface displays one or more projects.
2. Click the name of the project you want to explore.

   The interface displays a panel that lists the issues that were found by the analysis.

   Figure 1. Coverity Connect issues list
   [image: Coverity Connect panel displaying results of an analysis]
3. Click a particular issue.

   Below the panel that lists the issues found, the interface displays a panel
   that shows the source code responsible for the issue you clicked, along with details about that issue.

   Figure 2. Coverity Connect issue details
   [image: Coverity Connect panel displaying details about an issue]

For more information, see "Finding issues",
"Managing issues", and
"Triaging issues" in the Coverity Platform 2026.6.0 User and Administrator Guide.
