# Using the Black Duck Bridge CLI to integrate Coverity full Analysis into pipelines

The Bridge CLI can be used to integrate Coverity static analysis into CI/CD pipelines
using a full Coverity Analysis client to perform the analysis.

For information on using the Bridge CLI to integrate full Coverity Analysis into CI/CD
pipelines, refer to ["Using Black Duck Bridge CLI with Coverity"](https://docs.blackduck.com/r/bridge/latest/bridge-cli-guide/using-bridge-cli-with-coverity.html).
