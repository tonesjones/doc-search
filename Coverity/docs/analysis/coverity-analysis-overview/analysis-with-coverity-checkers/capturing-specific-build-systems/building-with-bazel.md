# Building with Bazel

This section describes the requirements, platform support, and processes for building
with Bazel™, a software tool for the automation of building and testing software. The
overall workflow consists of the following steps:

- Review requirements and limitations
- Enable the build
- Perform the build
- Analyze the code and commit defects

The rest of this chapter explains each of these steps.
