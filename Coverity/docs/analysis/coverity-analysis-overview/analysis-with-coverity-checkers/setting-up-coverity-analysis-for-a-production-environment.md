# Setting up Coverity Analysis for a production environment

You can deploy Coverity Analysis alone in a centralized (server-based) build system or in
combination with Coverity Desktop, which allows developers to run local
analyses of source code from their desktops or through their IDEs. This section covers
the server-based deployment model. For information about the combined deployment model,
see Coverity
Desktop Analysis
2026.6.0 User Guide.

In this section:

- The central deployment model
- Coverity Analysis deployment considerations
- Integrating Coverity Analysis into a build system
- Using TLS/SSL with Coverity Analysis
- Using remote worker jobs to manage resource constraints
- Using a network file system (NFS) with Coverity Analysis
- Coverity Analysis updates
