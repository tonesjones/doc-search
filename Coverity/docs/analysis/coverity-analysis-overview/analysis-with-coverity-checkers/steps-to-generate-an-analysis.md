# Steps to generate an analysis

Running a Coverity Analysis proceeds by certain steps.
Setting up a configuration might happen only once per source project.
Other steps are likely to occur every time you wan to reassess your code base.

1. Prerequisites
2. The configuration
3. The capture
4. The analysis
5. The commit
6. Viewing issues
