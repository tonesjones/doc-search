# Running a security analysis on an Android mobile application

You can perform a security analysis on Android applications that are written in Java and
Kotlin. This analysis runs the Android application security checkers. For details, see
the Android Security type in "Checker enablement and option defaults by language" in the Coverity 2026.6.0 Checker Reference.

The workflow for the Android application security analysis mostly follows the typical
pattern (see The capture: Examples).
The main differences are described in the sections that follow.
