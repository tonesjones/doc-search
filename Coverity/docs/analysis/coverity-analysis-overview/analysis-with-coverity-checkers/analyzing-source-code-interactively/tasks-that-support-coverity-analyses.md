# Tasks that support Coverity analyses

To support the procedures described in Analysis with Coverity Checkers, Coverity Analysis administrators sometimes decide to perform one or
more of the tasks described next.

In this section:

- Enabling or disabling checkers
- Using custom models to improve analysis results
- Using Coverity Analysis configuration files in the analysis
