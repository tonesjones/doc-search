# Using the Black Duck Bridge CLI to integrate Thin Client analysis into pipelines

The Bridge CLI can be used to integrate Coverity static analysis into a CI/CD pipeline
using a supported version of Scan Service (Thin Client) to perform the analysis.

For information on using the Bridge CLI to integrate Thin Client (Scan Service) analysis
into a CI/CD pipeline, refer to ["Using Black Duck Bridge CLI with Coverity"](https://docs.blackduck.com/r/bridge/latest/bridge-cli-guide/using-bridge-cli-with-coverity.html).
