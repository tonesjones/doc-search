# Thin Client language support

Coverity Thin Client is supported in the following operating
environments:

- Linux ARM 64-bit
- Linux Intel 64-bit
- macOS ARM
- macOS Intel
- Windows Intel 64-bit

Depending on the operating environment, Thin Client supports the languages specified in
Table 1.

Table 1. Thin Client language support

| Language | Operating system and architecture | Thin client support? |
| --- | --- | --- |
| Apex | All | yes |
| C/C++ | All | yes |
| Objective-C/C++ | Linux Intel 64-bit  macOS ARM  macOS Intel  Windows Intel 64-bit | yes |
| C# | Linux Intel 64-bit  Windows Intel 64-bit | yes |
| Dart | All | yes |
| Go | All | yes |
| Java | All | yes |
| JavaScript/TypeScript | All | yes |
| Kotlin | Linux Intel 64-bit  macOS ARM  macOS Intel  Windows Intel 64-bit | yes |
| PHP | All | yes |
| Python | All | yes |
| Ruby | All | yes |
| Swift | All | yes |
| Visual Basic | Linux Intel 64-bit  Windows Intel 64-bit | yes |

Note:

Entries with "All" for the operating system indicate that the corresponding language
is supported on all of the operating systems:

- Linux ARM 64-bit
- Linux Intel 64-bit
- macOS ARM
- macOS Intel
- Windows Intel 64-bit
