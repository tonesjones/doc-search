# Performing an analysis: in-cloud vs on-prem

You can configure the analysis to be performed either locally or in the cloud by creating
and editing a configuration file and/or using CLI command options to define where the
analysis occurs.

Depending on the deployment, the analysis can occur on either the client or in the cloud
using Scan Service.

Running the analysis locally on the client requires the full Coverity Analysis
installation on the client system.
