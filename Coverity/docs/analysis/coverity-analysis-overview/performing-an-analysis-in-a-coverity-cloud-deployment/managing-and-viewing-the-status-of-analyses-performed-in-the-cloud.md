# Managing and viewing the status of analyses performed in the cloud

In the Coverity Connect UI, the Scan List view enables you to view the status of analyses
performed in the cloud, providing visibility into currently running analyses, past
completed analyses, and failed analyses. This view presents scan job information
available at a glance as well as analysis logs and status reports. You can download logs
and reports for completed and failed scan jobs. The Scan List view also provides event
annunciations for some events such as unexpected halts.

This section describes the Scan List view of the Coverity Connect UI as it relates to
viewing the status of Coverity Analysis scan jobs performed by Scan Service in the
cloud. For overall information on using the Coverity Connect UI, refer to "Coverity Connect usage" in the
Coverity Platform 2026.6.0 User and Administrator Guide.

In this section:

- Opening the Scan List view
- The Scan List view
- Cancelling a scan
- Downloading logs and reports
- Annunciations
