# Opening the Scan List view

Open the Scan List view from the Coverity Connect UI as follows:

1. Log into the cloud-based Coverity Connect UI.
2. To open the Scan List view, in the Connect UI, click on the View icon [image: image] ,
   then select Scan List > All Scans.
   The Scan List view opens for all scans.
