# Installing client software

This chapter provides instructions for installing Coverity client software on any client
system that connects with a Coverity cloud deployment.

Each Coverity Connect user that needs to perform an analysis in the cloud needs to
provide a Coverity client. As a user who needs to perform Coverity scans, you need to do
one of the following:

- Install the Thin Client on
  your client system, or
- Install the full Coverity Analysis
  client on your client system, or
- Reference the Thin Client URL in your CI/CD pipeline.

For information on referencing a Thin Client URL in a CI/CD pipeline, refer to "Setting up and managing Thin Client
versions in the Connect UI" in the Coverity 2026.6.0 Cloud Deployment Administrator and User Guide.
