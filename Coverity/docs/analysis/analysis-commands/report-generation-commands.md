# Report-generation commands

This chapter describes the commands for generating reports to indicate whether your code base is compliant
with one of the various standards used in software development and other fields.

Note:
This chapter uses the term "coding standard" in a general sense.
Some standards that Coverity supports, such as OWASP, have general application;
others, such as MISRA, are designed for specific industries.

- `Coverity CERT report`
- `CVSS report`
- `Coverity DISA ASD STIG report`
- `Hyundai report`
- `Coverity Integrity report`
- `MISRA report`
- `OWASP Web Top 10`
- `Mobile OWASP Top 10`
- `PCI DSS`
- `Security report`
- `bd-integrity-reportbd-generate-integrity-reportBDSIR`
