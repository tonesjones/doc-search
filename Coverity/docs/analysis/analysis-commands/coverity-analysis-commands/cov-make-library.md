# cov-make-library

Create a user model file from C/C++, Objective-C, Objective-C++, C#, Go, Java, and
Visual Basic source code.

Note: User written models for Go and Kotlin are deprecated as of 2026.3.0. A future release will
remove support for running `cov-make-library` to customize analysis of Go
or Kotlin code.
