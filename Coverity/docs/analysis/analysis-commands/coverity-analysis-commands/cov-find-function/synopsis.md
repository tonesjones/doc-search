# Synopsis

```
cov-find-function 
   --dir <intermediate_directory>
   [ --apex | --cpp | --cs | --cuda | --dart | --fortran | --go | --java | --javascript | --kotlin | --objc |--php |--python2 | --python 3 | --ruby | --rust | --scala | --swift | --text-files | --typescript | --vb]
   [--exact]
   [--include-builtins]
   [--model-file <file.xmldb>]
   [--module <module>]
   [--output <directory>]
   [--save]
   [--show]
   [--subdir]
   [--use-emit]
   [SHARED_OPTIONS]
   <name>
```

**[SHARED_OPTIONS]**:

```
    [--debug]
    [--ident]
    [--info]
    [--tmpdir <tmp>]
```
