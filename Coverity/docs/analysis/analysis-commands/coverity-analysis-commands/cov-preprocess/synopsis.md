# Synopsis

```
cov-preprocess 
   --dir <intermediate_directory> 
   [--diff]
   [--diff-only]
   [-if <source_file>]
   [--native]
   [--no-lines]
   [--no-retranslate]
   [--output-file <output-file>, -of <output_file>]
   [--tu <translation_unit_id(s)>] 
   [SHARED_OPTIONS] 
   <files>
```

**[SHARED_OPTIONS]**:

```
   [--config <coverity_config.xml>] 
   [--debug]
   [--ident]
   [--info]
   [--tmpdir <tmp>]
   [--verbose <level>]
```
