# Synopsis

```
cov-link 
   --dir <intermediate_dir>
   {--collect | <link_file>...} 
   [--compile-arg <arg> | --compile-arg-regex <regex> | --no-compile-arg <arg> |
    --no-compile-arg-regex <regex> | --source-file-regex <source_file_regex>]...
   {{--output-dir <output_dir> | --output-file <output_file>}}
   [SHARED_OPTIONS]
```

**[SHARED_OPTIONS]**:

```
    [--ident]  
    [--verbose <level>]
```
