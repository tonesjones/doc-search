# Synopsis

```
cov-blame
    --dir <intermediate_directory>
    --preview-report <filename>
    [--scm <scm_type>]             
    [--scm-tool <scm_tool_path>]
    [--scm-project-root <scm_root_path>]
    [--scm-tool-arg <scm_tool_arg>]
    [--scm-command-arg <scm_command_arg>]
    [--no-triage-filters]
    [--owner-assignment-rules <RULE1>[,<RULE2>...,<RULEn>]] 
    [--stop-after <limit>]
    [SHARED_OPTIONS]
```

**[SHARED_OPTIONS]**:

```
    [--debug]
    [--ident]
    [--info]
    [--tmpdir <tmp>]
    [--verbose <level>]
```
