# Environment variables

$PAGER
:   The program through which to pipe output. The $PAGER
    variable is ignored if the output is not a terminal. If
    $PAGER is not set, the `cov-help`
    command looks for the `less` or `more`
    commands in paths set by the $PATH environment
    variable.
