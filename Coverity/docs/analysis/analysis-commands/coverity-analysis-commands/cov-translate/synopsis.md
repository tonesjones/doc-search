# Synopsis

```
cov-translate --dir <intermediate_dir> 
   [--add-arg <arg>]
   [--add-arg-no-file <arg>]
   [--auto-diff]
   [--chase-symlinks]
   [--clean-preprocesse]
   [--cygpath <path>]
   [--cygwin]
   [--dryrun]
   [--emit-cmd-line-id]
   [--emit-complementary-info]
   [--emit-parse-errors]
   [--emulate-string <regex>, -s <regex>]
   [--encoding <enc>]
   [-E]
   [--fail-stop]
   [--force]   [--no-emit]
   [--no-emit-complementary-info]
   [--no-headers]
   [--no-parallel-translate]
   [--no-preprocess-next]
   [--parallel-translate <number_of_processes>]
   [--preinclude <file.h>]
   [--preprocess-first]
   [--preprocess-next]
   [--print-native]
   [--record-only]
   [--redirect stdout|stderr,<filename>]
   [--run-compile]
   [--timings] 
   [SHARED_OPTIONS]
   <compile-command>
```

**[SHARED_OPTIONS]**:

```
   [--config <coverity_config.xml>]
   [--debug]
   [--debug-flags <flag> [, <flag>]
   [--ident]
   [--info]
   [--tmpdir <tmp>]
   [--verbose <level>]
```
