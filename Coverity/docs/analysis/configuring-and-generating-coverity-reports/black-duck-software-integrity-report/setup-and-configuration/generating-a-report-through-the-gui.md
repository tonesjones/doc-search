# Generating a report through the GUI

Click Create Report to start the data collection process. The
report generator will access each analysis tool server, collect the data, and then
compose the detailed results and PDF files.

1. *Optional*, load an existing .yaml file from the File > Open Configuration... menu.
2. In the Connection page, if using username and password for
   Authentication, fill in the
   Password field.
3. Click Create Report to generate the report.
4. In the Save Detailed Data dialog, enter the name and
   location of the .zip file.
5. In the Save Report dialog, enter the name and location of
   the .pdf file.
6. In the Report Generation Completed dialog, optionally open
   the PDF file.
