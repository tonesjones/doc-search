# DISA ASD STIG Report

The DISA ASD STIG report has an additional key for specifying the version to use:

```
disa-stig:
    # DISA-STIG version
    # default version: V4
    version: V5
```

| Key | Class Type | Description | Default | Required |
| --- | --- | --- | --- | --- |
| `version` | String | The version of the YAML file's schema | "V4" | Yes |
