# Locale schema element

The locale schema should include the following key:

| Key | Class Type | Description | Default | Required? |
| --- | --- | --- | --- | --- |
| `locale` | String | Sets the language or locale in which the report will be generated.  The following locale settings are available:   - `en_US` (English) - `ja_JP` (Japanese) - `ko_KR` (Korean) - `zh_CN` (Simplified Chinese) | en_US | No |
