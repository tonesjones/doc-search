# Coding standards and compliance reports

With Coverity Analysis, you can generate reports that indicate whether your code base
is compliant with one of the various standards used in software development and other fields.
Coverity Connect provides further ways to manage the content of these reports.

Note:
This guide uses the term "coding standard" in a general sense.
Some standards that Coverity supports, such as OWASP, have general application;
others, such as MISRA, are designed for specific industries.

This guide first describes how to configure report generators.
That section is followed by descriptions of the various kinds of reports that Coverity makes available.
