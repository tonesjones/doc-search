# Requirements

Coverity Software Integrity Report version 2026.6.0 is compatible with
Coverity Connect version 2026.6.0. It is incompatible with prior
versions of Coverity Connect. Similarly, an older version of Coverity Software Integrity
Report is incompatible with Coverity Connect version 2026.6.0.
