# Metrics

If a listing file has been requested a table will be presented with some metrics of each
program unit and procedure. This table shows the number of (non-comment) source lines,
(non-blank) comment lines, statements and maximum construct nesting. The number of
source lines, comment lines, and statements are split up into a total as read in, and
the number not read from include files.

In the totals the lines and statements of the include files are counted only once for
each include file.

The program metrics shows the number of program units, (sub)modules, subprograms, module
procedures, internal procedures and source files analyzed.
