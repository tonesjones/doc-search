# Specification of procedure interfaces

You can make the analysis more complete by defining the interface for all procedures
which have not been included in the analysis, such as system procedures and third party
procedure packages. There are two ways to specify procedure interfaces, namely apply­ing
the traditional FORTRAN 77 syntax or using the Fortran 90/95 syntax features.
