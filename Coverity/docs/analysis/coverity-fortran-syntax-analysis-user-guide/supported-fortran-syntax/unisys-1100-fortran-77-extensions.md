# Unisys 1100 Fortran-77 extensions

- Records beginning with ”#” or ”@” are skipped.
- Though the number of continuation lines is unlimited for the Unisys Fortran
  compiler Coverity Fortran Syntax Analysis can read a maximum of 999 continuation
  lines.
- `DEBUG` packets are supported with the restrictions as described
  for IBM VS Fortran.
