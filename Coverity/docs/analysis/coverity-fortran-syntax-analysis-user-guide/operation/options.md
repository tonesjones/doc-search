# Options

We distinguish the following categories of options:

- options to control configuration selection and defect generation,
- options to tune the program-unit analysis,
- options to tune the global program analysis,
- options to tune the output,
- library options,
- miscellaneous options.

The options that can be specified are summarized hereafter.
