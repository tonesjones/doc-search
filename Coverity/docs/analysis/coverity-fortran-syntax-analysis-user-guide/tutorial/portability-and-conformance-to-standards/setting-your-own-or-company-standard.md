# Setting your own, or company standard

Advanced users can create a custom configuration file, which can enable just the specific
language extensions supported by the compiler(s) in use and/or those whose use is
deter­mined to meet code-quality standards. A custom configuration file is used by
supplying its name as an argument to the `--configuration` option.
