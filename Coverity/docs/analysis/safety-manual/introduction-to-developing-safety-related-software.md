# Introduction to developing safety-related software

This manual is of special interest to Coverity customers who are developing
safety-related software.

Coverity
:   Coverity is a tool used to find, manage, and fix software issues within source code. Issues
    are found "statically" by Coverity, as a result of analysis on source code.
    Issues discovered by Coverity can be related to the general quality or
    security of the software that it analyzes. As such, Coverity should be
    considered an integral part of comprehensive testing and verification
    activities for safety-related development. Of note, Coverity can be used to
    determine whether the code is compliant with MISRA standards, including
    MISRA C 2004, MISRA C++ 2008, MISRA C 2012, MISRA C 2023, MISRA C 2025, and MISRA C++
    2023. A list of MISRA rules and directives covered by Coverity is available
    in the Coverity 2026.6.0 Checker Reference ("MISRA rules and directives").

Note: Coverity verification and validation activities for intermediate release versions are
equally robust to those versions that go through third-party evaluation. The certificate
for the Coverity Tools (Connect, Static Analysis, Desktop) is valid until
11-25-2025.
