# Applicable standards and scope

**Coverity shall not be used as the sole means of determining whether a product or
system is safe.**

The analysis takes place on source code only. It cannot detect issues that might arise
dynamically as the program runs and then cause a safety hazard. The analysis is not
guaranteed to find all software defects, nor will it find defects in third-party code
for which source code is not made available.
