# Standards compliance

ASIL
:   ASIL D: The tools have been qualified to be used in safety-relevant development
    up to ASIL D.

IEC 61508
:   T2: Coverity tools can be classified as T2.

ISO 26262
:   The Tool Impact (TI) and Tool Error Detection (TD) shall be defined by each
    project using the tool.

ISO/SAE 21434
:   Road vehicles – Cybersecurity engineering.
