# Installing client software

Thic chapter describes how to install Coverity client software on any client system that
connects with a Coverity cloud deployment.

Each Coverity Connect user that needs to perform an analysis in the cloud needs to
provide a Coverity client. As a user who needs to perform Coverity scans, you need to do
one of the following:

- Install the Thin Client on your client system.
- Install the full Coverity Analysis client on your client system.
- Reference the Thin Client URL in your CI/CD pipeline.

For information on using a default Thin Client URL in a CI/CD pipeline, refer to Managing supported Coverity Tools and Thin Client versions in the Connect UI.

For instructions on creating a Coverity configuration file and creating commands to
perform analyses for a stand-alone project or in a CI/CD pipeline, refer to "Performing an
analysis in a Coverity Cloud deployment" in the Coverity Analysis 2026.6.0 User and Administrator Guide.
