# Image properties

## IMAGE-PULL-SECRETS

Replace `<IMAGE-PULL-SECRETS>` with the image pull secret of the
CIM-TOOLS image (stateful set) in a Coverity cloud deployment. Create a new secret
if you are executing the image in a new namespace.

## IMAGE-NAME

Replace `<IMAGE-NAME>` with the name of the CIM-TOOLS (stateful
set) image from the Coverity cloud deployment.
