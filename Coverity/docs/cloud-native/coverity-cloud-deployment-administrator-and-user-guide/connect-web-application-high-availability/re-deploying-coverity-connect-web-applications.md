# Re-deploying Coverity Connect Web applications

Re-deploying Coverity Connect Web applications uses the "recreate deployment" strategy
which terminates all existing pods before creating new ones. For information on
"recreate deployment", refer to the Kubernetes documentation, [Deployments](https://kubernetes.io/docs/concepts/workloads/controllers/deployment/).
