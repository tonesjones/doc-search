# Troubleshooting guidance

The following sections provide troubleshooting guidance.

- Scan service failure due to expired internal CA certificate
- Chart failure upgrading to 2026.3 or newer Helm chart with AI-Assisted Triage Plug-in enabled
- Downloading a scan log using the Connect API
- Inspecting pod logs for errors
- Expired or node-locked license
- Debugging database connectivity
- Problem with volumes
- Microsoft Azure PostgreSQL database extensions fail
- Missing secret or configmap
- Ingress: the SAML URL uses http instead of https
- List and verify ingress
- NGINX HTTP error 413: Request Entity Too Large
- NGINX HTTP error 504: Gateway Timeout
- Image pull issues
- Pods fail to schedule
- Missing the cim-tools pod
- Read-only file system error
