# Coverity client support matrix

If Scan Service is deployed in the cloud, end users/programmers can install either Thin
Client or full Coverity Analysis client on client systems. If only Coverity Connect is
deployed in the cloud, you must install the full Coverity Analysis client on any client
system that connects to the cloud deployment.
