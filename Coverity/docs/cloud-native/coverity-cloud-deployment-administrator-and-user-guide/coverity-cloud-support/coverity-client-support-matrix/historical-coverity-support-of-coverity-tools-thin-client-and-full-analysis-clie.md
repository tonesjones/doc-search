# Historical Coverity support of Coverity Tools (Thin Client) and full analysis client

For Coverity releases that support multiple versions of Coverity Tools (Thin
Client) and full analysis client, the following table identifies past, present and
predicted future client versions supported for each Coverity version. This table is an
evolving rolling range of Coverity Tools/Thin Client versions that are
supported by each Coverity release version.

Table 1. Historical Coverity support of Coverity Tools (Thin Client) and full analysis
client

| Coverity version | Current client support | Predicted future client support |
| --- | --- | --- |
| **2026.6.x** | 2024.12.0 — 2026.6.0 | Through 2027.12.x. |
| **2026.3.x** | 2024.9.0 — 2026.6.0 | Through 2027.9.x. |
| **2025.12.x** | 2024.6.0 — 2026.6.0 | Through 2027.6.x. |
| **2025.9.x** | 2024.3.0 — 2026.6.0 | Through 2027.3.x. |
| **2025.6.x** | 2023.12.0 — 2026.6.0 | Through 2026.12.x. |
| **2025.3.x** | 2023.9.0 — 2026.6.0 | Through 2026.9.x. |
| **2024.12.x** | 2023.6.0 — 2026.6.0 | Through 2026.6.x. |
