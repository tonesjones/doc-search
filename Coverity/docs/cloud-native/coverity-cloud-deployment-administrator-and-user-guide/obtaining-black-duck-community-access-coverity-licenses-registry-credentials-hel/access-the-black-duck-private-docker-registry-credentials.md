# Access the Black Duck private Docker registry credentials

Once the Black Duck Docker private registry credentials are assigned, in Black Duck Community, you
can access and copy the Black Duck Docker registry login credentials as follows:

1. Login to Black Duck Community at <https://community.blackduck.com/s/>.
2. Navigate to Licenses > Coverity.
3. Click on View/Request Docker Registry Credential to open
   the license pop-up. This pop-up contains copy buttons to copy the credentials.
   You will need these to login to the Black Duck registry.
