# Obtain your Coverity licenses

To use Coverity, you will need time-limited node-unlocked Coverity licenses from
Black Duck. To obtain the licenses:

1. Open the Black Duck Community website at <https://community.blackduck.com/s/>.
2. Select Support > Support Home.
3. Click Submit a Ticket.
4. Request the following as node unlocked licenses:

   - Platform license for Coverity Connect. The license is a
     `license.dat` file.
   - SAVE license for Analysis. You need this license if you are deploying Scan
     Service in the cloud. This Scan Service license is a
     `license.dat` file.

   Important: Both the Platform and SAVE licenses
   must be node unlocked; you must specifically request node unlocked licenses for
   a Coverity cloud deployment. By default, Coverity licenses are node
   locked.

When the licenses are available, each license file that you download is a compressed
file. To access the corresponding `license.dat` file, you must extract
the compressed file.
