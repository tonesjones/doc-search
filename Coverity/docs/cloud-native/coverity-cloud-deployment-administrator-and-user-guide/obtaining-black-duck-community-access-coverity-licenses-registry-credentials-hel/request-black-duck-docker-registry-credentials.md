# Request Black Duck Docker registry credentials

Obtain Black Duck docker registry credentials to provide access to download Black Duck
images:

1. Login to Black Duck Community at <https://community.blackduck.com/s/>.
2. Navigate to Licenses > Coverity.
3. Click View/Request Docker Registry Credential.

   [image: image]
4. When access to the Black Duck private repository is granted, continue with the
   next section to download and save the images.
