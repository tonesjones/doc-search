# Problem with volumes

If you have a volume issue:

- There might be a problem with the Helm chart. For information on the volume keys,
  see `cim.cimtools.volume` in cnc Helm chart: Helm keys.
- There might be a problem with an installation script, or installation scripts were
  not used.
