# Upgrade considerations

For any upgrade to a new release, you need to:

- Consider feature changes in the new version(s).
- If you are upgrading by more than one version, changes are cumulative.
- Stop using removed Helm keys.
- Update your chart to support renamed Helm keys.
- Start using new Helm keys as needed.

The following sections contain either release-specific upgrade considerations or tables
that list Helm keys added, removed, or renamed. When upgrading from an earlier release,
