# Using this document with other Coverity documents

This document is intended for administrators who are deploying Coverity in Kubernetes
containers.

For Coverity users auch as programmers who need to run code scans, refer to the following
guide to create a configuration file and run analyses.

- Coverity Analysis 2026.6.0 User and Administrator Guide

For further information that was developed for classic Connect, but is also useful for
Coverity cloud, see the following documents:

- Coverity Platform 2026.6.0 User and Administrator Guide
- Coverity 2026.6.0 Command Reference
- Coverity 2026.6.0 Installation and Upgrade Guide
