# Setting up ARM64 support

As of the 2023.9.0 release, ARM64 is supported so that you can deploy Coverity cloud on
ARM64 machines. Deployment varies as described in these sections, however Coverity
behavior is the same on ARM64 as on AMD64.

This support is tested in the following environments:

- Amazon AWS
- Google GCP
- Microsoft Azure

Currently, OpenShift is not supported in an ARM64 cluster.
