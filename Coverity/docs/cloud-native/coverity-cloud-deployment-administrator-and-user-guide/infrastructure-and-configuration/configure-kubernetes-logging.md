# Configure Kubernetes logging

Configure Kubernetes logging as described in the cloud provider and Kubernetes
documentation.

For further information on Kubernetes logging, refer to:

- For Amazon AWS, see: <https://aws.amazon.com/solutions/implementations/centralized-logging/>.
- For Microsoft Azure, see: <https://docs.microsoft.com/en-us/dotnet/architecture/cloud-native/monitoring-azure-kubernetes>.
- For Google GCP, see <https://cloud.google.com/logging/docs>.
- For Red Hat OpenShift, refer to the Red Hat documentation.
