# Specifying ARM64 node pools

ARM64 uses node pools that consist of ARM64 hardware. When you create an ARM64 cluster,
you need to specify and create ARM64 node pools. All other resources are unchanged. The
following sections identify properties needed to specify ARM64 hardware in AWS, Azure
and GCP node pools.

Note: The availability of ARM64 machines is different from region to
region and provider to provider. Verify the availability of ARM64 machines in the region
in which you are deploying.
