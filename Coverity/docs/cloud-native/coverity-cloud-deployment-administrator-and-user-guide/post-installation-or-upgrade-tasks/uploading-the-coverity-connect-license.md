# Uploading the Coverity Connect license

In the Coverity Connect UI for the Connect instance, upload the unique Connect Platform
license.

For more detailed information about uploading a Connect license, refer to "Coverity Connect license
information" in the Coverity Platform 2026.6.0 User and Administrator Guide.
