# Configuring SAML

Configure SAML (Security Assertion Markup Language) using the Coverity Connect UI as
follows:

Note: Coverity Connect must be up and running.

1. With Coverity Connect up and running, start a Coverity Connect UI session.
2. Create a new SAML configuration as described in "Creating a SAML
   SSO configuration" and other sections within "Configuring Coverity
   Connect to use SAML" in the Coverity Platform 2026.6.0 User and Administrator Guide.
3. On the Authentication and Sign In page, change the
   authentication method to SAML.
4. (optional) Check the box Create SAML users automatically on sign
   in. The Authentication and Sign In page will
   look like this:
