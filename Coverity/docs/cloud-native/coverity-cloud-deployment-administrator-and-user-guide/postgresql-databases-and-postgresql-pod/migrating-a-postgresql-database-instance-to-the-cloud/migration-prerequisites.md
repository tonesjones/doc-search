# Migration prerequisites

This chapter outlines how to migrate data from an existing on-premises PostgreSQL
database to a new PostgreSQL database instance in the cloud.

You must meet the following prerequisites before you migrate the database:

- The PostgreSQL database to be migrated is currently on-premises.
- You have created the cloud infrastructure and created a PostgreSQL database instance
  in the cloud are as described in Infrastructure and configuration.
- You have created all relevant secrets and ConfigMaps as described in Create TLS certificate, keystore, and secrets.

The remainder of this chapter points you to resources that enable you to migrate your
current database to the new PostgreSQL database instance in the cloud.
