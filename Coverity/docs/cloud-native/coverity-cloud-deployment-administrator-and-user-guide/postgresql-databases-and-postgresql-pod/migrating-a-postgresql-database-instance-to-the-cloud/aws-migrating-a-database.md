# AWS: migrating a database

For information on migrating a PostgreSQL database to the Amazon Web Services (AWS),
refer to the following Amazon documentation: <https://aws.amazon.com/dms/>.

- For migration information using AWS Database Migration Service (AWS DMS), refer
  to:<https://aws.amazon.com/dms/>
- For information on the `pg_dump` and
  `pg_restore` commands, refer to the Amazon documentation:
  <https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/CHAP_PostgreSQL.html>.
