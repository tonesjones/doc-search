# Obtaining Black Duck Community access, Coverity licenses, registry credentials, Helm chart, and client software

The sections in this chapter describe how to:

- Request access to Black Duck Community. See Request access to Black Duck Community.
- Request Coverity Connect and Coverity Analysis node-unlocked licenses from Black Duck Support. See Obtain your Coverity licenses.
- Request Black Duck Docker registry credentials from
  Black Duck Support. See Request Black Duck Docker registry credentials.
- Access and copy the Black Duck Docker registry login
  credentials. See Access the Black Duck private Docker registry credentials.
- If you will be using the full Coverity Analysis client on a client system, download
  the Coverity Analysis software from the private Black Duck Docker registry. See Coverity client installer and documentation files.
- Download the Coverity client installer files and documentation files as needed from
  the Black Duck private docker registry. See Coverity client installer and documentation files.
- Download the Helm chart from the Black Duck public
  Docker registry. See Downloading the Helm chart from the Black Duck public Docker registry.
- Obtain open source images as needed. See Open source container images.

For requirements, recommendations, and supported versions, refer to Coverity cloud support.
