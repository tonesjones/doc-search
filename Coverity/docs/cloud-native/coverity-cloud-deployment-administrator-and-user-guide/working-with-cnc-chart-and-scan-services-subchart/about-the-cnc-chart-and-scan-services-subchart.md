# About the cnc chart and scan-services subchart

The Coverity cloud deployment uses a top-level parent `cnc` chart and a
`scan-services` subchart, as well as global Helm keys. The next
sections introduce the `cnc` chart and `scan-services`
subchart, global Helm keys, and how to work with these charts and keys. For additional
information on Helm charts, subcharts, and global keys, see also <https://helm.sh/docs/chart_template_guide/subcharts_and_globals/>.
