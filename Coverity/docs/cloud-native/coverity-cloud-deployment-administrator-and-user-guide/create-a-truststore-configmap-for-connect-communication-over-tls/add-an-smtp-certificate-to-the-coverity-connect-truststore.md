# Add an SMTP certificate to the Coverity Connect truststore

To configure email notification and delivery in a Coverity Connect cloud deployment,
refer to the section "Configuring email notification and delivery" in the Coverity Platform 2026.6.0 User and Administrator Guide. For SSL-enabled mail server setup, you will
need to add the mail server's certificate to a ConfigMap.
