# Managing and interpreting metrics

The following steps outline at a very high level how to use this chapter to manage and
interpret metrics

1. Set up metrics as described in this chapter.
2. Refer to the metrics descriptions in this chapter for metrics descriptions, how
   to interpret metrics, and how to resolve issues that the metrics expose. This is
   especially important if you find performance issues.
3. We recommend monitoring Metrics for several weeks to establish baselines.
4. Continue to monitor and watch for anomalies that deviate from the baselines.
