# Connect UI System Totals list

Some system values that can be displayed as metrics can also be found in the System
Totals list in the Coverity Connect UI on the Help > System Diagnostics > Overview page.

These system values include streams, projects, triage stores, users, user groups,
component maps, and database size.

For example:

```
System Totals: Data grabbed on 10/25/23, 23:32:27
Streams          76
Projects         71
Triage Stores    75
Users            5
User Groups      0
Component Maps   2
Database Size    1.14 GB
```
