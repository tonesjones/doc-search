# AWS: Using EBS persistent storage as MinIO PVC

If you are deploying MinIO and using AWS EBS persistent storage as MinIO
PersistentVolumeClaim (PVC), install the AWS EBS CSI driver EKS addon. Refer to <https://docs.aws.amazon.com/eks/latest/userguide/eks-add-ons.html>.
