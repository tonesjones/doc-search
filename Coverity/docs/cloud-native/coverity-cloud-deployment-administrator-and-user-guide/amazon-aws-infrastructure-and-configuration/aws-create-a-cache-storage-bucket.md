# AWS: Create a cache storage bucket

You can set up caching in many different ways, for example using an Amazon ElastiCache
database for Redis. See the relevant Amazon and Redis documentation for information on
setting up caching and Redis.

- For requirements when creating a cache storage container, see: Create and configure a cache storage bucket
- Redis documentation: <https://redis.io/learn/create/aws/redis-on-aws>
- For AWS caching information: <https://docs.aws.amazon.com/whitepapers/latest/s3-optimizing-performance-best-practices/using-caching-for-frequently-accessed-content.html>

If you are using Amazon ElastiCache for Redis, set up the cache for Redis as described in
the following Amazon documentation:

- For information: <https://docs.aws.amazon.com/AmazonElastiCache/latest/red-ug/WhatIs.html>
- For setup: <https://docs.aws.amazon.com/AmazonElastiCache/latest/red-ug/GettingStarted.html>
