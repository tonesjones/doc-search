# Deploy Connect and Scan Service with onPrem OCI Redis and MinIO

This scenario deploys, in a Kubernetes cluster in the cloud, Coverity Connect and Scan
Services, using OCI (Open Container Initiative) Redis and MinIO. Using OCI onPrem Redis
and MinIO greatly reduces the effort needed to configure and deploy the Scan Services.
The following steps outline this deployment and refer to more detailed procedures within
this document:

Important: These are Administrator procedures.

Important: If you are NOT planning to use OCI onPrem Redis
and MinIO, use the scenario: Deploy Connect and Scan Service
