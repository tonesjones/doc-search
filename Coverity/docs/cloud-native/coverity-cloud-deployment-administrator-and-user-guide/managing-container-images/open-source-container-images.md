# Open source container images

The following table identifies open source container images that might be deployed in
Coverity cloud. Download any required open source container image from the resource such
as DockerHub, or as documented by the company that develops the image.

Table 1. Open source container images

| NGINX ingress container image | Description |
| --- | --- |
| `nginx:1.27.4` | Ingress container image. |
| `pgpool:4.6.0` | The Bitnami Pgpool-II container image for PostgreSQL read replicas.  Pgpool-II supports multiple read-only PostgreSQL database replicas.  See: [Bitnami package for Pgpool-II](https://app-catalog.vmware.com/bitnami/releases/d12ff66f-b586-43bf-b274-461112c0a643/overview) |
