# Changing the default Coverity Tools version for CI/CD pipelines

Changing a default Coverity Tools version changes the `default` Coverity
Tools artifact version that is available for use in CI/CD commands.

Note:

You must be a Connect administrator to change the default version of Coverity
Tools.

See also Default Coverity Tools version and CI/CD pipelines.

The default version is available for both CI/CD and end users, however the actual
`default` functionality is for CI/CD commands only.

You can change the Coverity Tools default version to another version as follows:

1. In the Connect UI, select Configuration > Configure Coverity Tools. The Available Coverity Tools pane opens,
   listing all available versions of Coverity Tools.
2. In the row for the Coverity Tools version you want to set as default, click in
   the Actions field, then click Set
   default in the menu.

   In the Available Coverity Tools list, a check mark appears
   in the Default column, identifying the new default
   version.
