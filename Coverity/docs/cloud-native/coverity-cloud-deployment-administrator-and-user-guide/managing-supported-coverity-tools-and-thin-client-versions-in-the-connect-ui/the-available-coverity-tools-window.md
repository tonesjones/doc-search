# The Available Coverity Tools window

The following image shows the Available Coverity Tools window with:

- Five available versions of Coverity Tools, available to CI/CD as Coverity Tools
  artifacts or to end users as Thin Client installer files..
- The Default column which identifies the Coverity Tools artifact version that is set
  as the `default` version. The default version is available for both
  CI/CD and end users, however the actual `default` functionality is
  for CI/CD commands only. This list has no default.
- The Actions column in which, if you click on the three dots for a version, displays
  a menu of actions available for that Coverity Tools version.

The sections that follow describe the Actions that you can perform within this
window.
