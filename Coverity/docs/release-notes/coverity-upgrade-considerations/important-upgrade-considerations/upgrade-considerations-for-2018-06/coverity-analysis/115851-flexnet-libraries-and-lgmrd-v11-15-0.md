# 115851 FlexNet libraries and lgmrd v11.15.0+

We have upgraded the `lmgrd` and `lmuilt` libraries on all
platforms. Customers are recommended to upgrade `lmgrd` and
`lmutil` to v11.15 in order to fix several security vulnerabilities.
The `lmgrd` and `lmutil` libraries can be found in the
Coverity Analysis bin folder.
