# Upgrade considerations for 2024.9

For information about deprecated and dropped support, other updates, known issues, and
fixed bugs, see "Coverity 2024.9.0 Release Notes" (and the sections for associated hot
fixes) in the Coverity 2026.6.0 Release Notes Archive.

For the list of Sigma checkers disabled by default when running Coverity Analysis 2024.9,
see ["Checkers disabled in Sigma when running Coverity Analysis"](https://documentation.blackduck.com/bundle/coverity-docs-2024.9/page/checker-ref/checkers/S/sigma._checkers.html#d100634e144) in the [*Coverity 2024.9.0 Checker
Reference*](https://documentation.blackduck.com/bundle/coverity-docs-2024.9/page/webhelp-files/checkerref_start.html).

CAUTION:

When you upgrade Coverity Analysis, all previous settings are
overwritten. All checkers listed in the [" Sigma checks disabled by default in Coverity
2024.9"](https://documentation.blackduck.com/bundle/coverity-docs-2024.9/page/checker-ref/checkers/S/sigma._checkers.html#SIGMA_checkers__section_disabled_sigma_checkers) table in the [*Coverity 2024.9.0 Checker Reference*](https://documentation.blackduck.com/bundle/coverity-docs-2024.9/page/webhelp-files/checkerref_start.html)
will be disabled by default in Coverity Analysis 2024.9, regardless of their enablement
status in previous installations.
