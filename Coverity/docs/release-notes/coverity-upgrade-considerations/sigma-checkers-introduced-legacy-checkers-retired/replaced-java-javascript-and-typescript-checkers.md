# Replaced Java, JavaScript, and TypeScript checkers

The following Coverity Analysis checkers for Java, JavaScript, and TypeScript have been
replaced by Sigma checkers for Java, JavaScript, and TypeScript.

Table 1. Coverity Analysis checkers for Java, JavaScript, and TypeScript replaced by Sigma
checkers for Java, JavaScript, and TypeScript

| Checker name | Language |
| --- | --- |
| CONFIG.DWR_DEBUG_MODE | Java |
| CONFIG.JAVAEE_MISSING_SERVLET_MAPPING | Java |
| CONFIG.JSONWEBTOKEN_NON_EXPIRING_TOKEN | Javascript, Typescript |
| CONFIG.REQUEST_STRICTSSL_DISABLED | Javascript, Typescript |
| CONFIG.SEQUELIZE_ENABLED_LOGGING | Javascript, Typescript |
| CONFIG.SEQUELIZE_INSECURE_CONNECTION | Javascript, Typescript |
| CONFIG.SPRING_SECURITY_REMEMBER_ME_HARDCODED_KEY | Java |
| JSONWEBTOKEN_IGNORED_EXPIRATION_TIME | Javascript, Typescript |
| JSONWEBTOKEN_UNTRUSTED_DECODE | Javascript, Typescript |
