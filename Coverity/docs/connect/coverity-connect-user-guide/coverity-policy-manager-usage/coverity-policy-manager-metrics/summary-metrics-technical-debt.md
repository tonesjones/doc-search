# Summary metrics: technical debt

The technical debt summary metric is built into Coverity Policy Manager.
Administrators can create additional summary metrics, as needed.

You will see a label when adding a summary metric to a heatmap, status report, or trend report.
Note that Summary metrics provide
no filters. Instead, their contributor metrics can be filtered.

Table 1. Coverity Policy Manager technical debt metrics

| Summary Metric | Label | Available To | Filters | Primary Segmentation | Secondary Segmentation |
| --- | --- | --- | --- | --- |
| Technical Debt | Technical Debt | Heatmaps, Status Reports, Trend Reports | (No Filters) | None, Child Nodes, Component, Contributor Only Summary metrics offer the Contributor segmentation property. It is never available to reports that include other metrics. |

For more detail on this topic, see Summary metrics.
