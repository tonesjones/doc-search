# Using Coverity Policy Manager hierarchies

Coverity Policy Manager allows you to create, edit, share, duplicate, and delete Coverity
Policy Manager heatmaps, reports, and dashboards. Creating and editing consists
of specifying the metrics, filters and/or
split-by and group-by options, policies (for heatmaps only), and other properties to use and display.

Navigation
:   For guidance with navigation to hierarchies, see Shared navigation and Main Menu tools.
