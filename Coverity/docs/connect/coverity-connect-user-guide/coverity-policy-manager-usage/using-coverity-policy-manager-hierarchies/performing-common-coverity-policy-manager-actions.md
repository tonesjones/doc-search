# Performing common Coverity Policy Manager actions

High-level views (such as All
Hierarchies) provide a menu that you can use to perform the same sort of
actions that Coverity Connect views support (see View management for
Coverity Connect). Though the particulars (such as filters and column names) differ
between Coverity Policy Manager and Coverity Connect, the functionality of each menu
item is largely the same.

    This option allows you to generate a new heatmap, report, or dashboard. You
    can find it by clicking the section title in the left-side Hierarchy view
    pane (for example, HEATMAPS or DASHBOARDS), then clicking the down arrow on
    the right side of the item.

    Note that you can also create a new report by selecting the

At the level of a particular hierarchy (for example, the Java Projects hierarchy), you
can use Coverity Policy Manager heatmap, report, and dashboard views to perform the
actions described in Table 1. The
following features support these actions:

Action Menu
:   Figure 3. Example: action menu
      
     [image: image]

    This menu supports common actions. You can open this menu by mousing over any
    heatmap, report, or dashboard listed in the left-side pane and clicking the
    down arrow on the right side of the item.

Table 1. Common actions

| Action | Description |
| --- | --- |
| Create, Edit Settings | To set up Coverity Policy Manager dashboards, reports, and heatmaps, see the following:  - Setting up Coverity Policy Manager dashboards. - Setting up Coverity Policy Manager heatmaps. - Setting up Coverity Policy Manager status reports. - Setting up Coverity Policy Manager trend reports |
| Share | Selecting users and/or groups with which to share your view of a Coverity Policy Manager dashboard, report, or heatmap. |
| Duplicate | Making a copy of a Coverity Policy Manager dashboard, report, or heatmap. |
| Delete | Deleting a Coverity Policy Manager dashboard, report, or heatmap. Note that this action deletes the item from all hierarchies, not just the hierarchy from which you are deleting it. See Views. |

You can also print a dashboard, heatmap, or report to file and print out a report. You
use the printer icon ( [image: image] ) in the chart for this purpose.

For an example of the printer icon in a chart, see Figure 1.
