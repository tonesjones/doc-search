# Setting up Coverity Policy Manager dashboards

You can create, edit, share, duplicate, and delete one or more dashboards.

Figure 1. Example: Dashboard Edit Settings Window
  
 [image: image]

To create a new dashboard, click the main DASHBOARDS label and
from the drop-down list, choose Add New Report. To add items to
the new dashboard, click the gear-shaped Properties icon.

Table 1. Dashboard Properties

| Property | Description |
| --- | --- |
| Name | Unique name for a Coverity Policy Manager dashboard. |
| Description | Description of the dashboard. |
| Layout | Layout in which to display columns of selected heatmaps or reports. The window provides multiple layout options. |

You can delete a chart from the dashboard by clicking it in the Edit Settings window,
then clicking the Remove chart button.

Figure 2. Example: Dashboard Chart Deletion
  
 [image: image]

For additional information about creating, editing, sharing, duplicating, and deleting
dashboards, see Performing common Coverity Policy Manager actions.
