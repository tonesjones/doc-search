# Coverity Policy Manager overview

Coverity Policy Manager charts (reports and
heatmaps) use metrics (and filters on metrics) to get information about
data that is stored in the Coverity Connect database. For example, a chart might display
the number of outstanding, high-impact issues found in a portion of the code base that
is associated with a certain Coverity Connect project. Charts get their structure from a hierarchy that is set up by a Coverity
Policy Manager administrator.

After an administrator configures one or more hierarchies, it becomes possible to
navigate to them through the Main Menu (see Figure 2) and then
set up and view Coverity Policy Manager heatmaps, reports, and dashboards. (Permissions pertaining to
viewing and managing Coverity Policy Manager apply; see Coverity Policy Manager roles and permissions).
