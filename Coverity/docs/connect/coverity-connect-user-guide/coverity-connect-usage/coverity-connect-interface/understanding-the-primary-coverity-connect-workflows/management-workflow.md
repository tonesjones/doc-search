# Management workflow

This workflow applies to users within a given organization that are primarily interested
in viewing all issues within a given stream or
group of streams within a given project or component, and not necessarily within a
specific snapshot. This is typically used by project leads, team managers, directors,
and so forth, to get a gauge on the status (or the history) of a given software
project:

1. Find, organize, and view issues within a stream, project, or component (see Finding issues). For the management workflow, a helpful view type
   is 
   Issues: Project Scope
   .
2. Examine the triage states of a group of defects (see Triaging issues).
3. View and organize Coverity Connect dashboards and charts (see Monitoring issues).
