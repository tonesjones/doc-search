# Email notifications use cases

The following scenarios illustrate the use of Coverity Connect's email notifications.
These scenarios provide a high-level view of how you might combine view and notification
options to track various software issue data. These scenarios cannot cover every use
case, because of the large number of possible configurations, but describe several
potential solutions.
