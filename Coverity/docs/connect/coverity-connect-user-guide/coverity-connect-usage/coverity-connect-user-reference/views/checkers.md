# Checkers

Grouping an Issues: By Snapshot view by Checker is the encouraged
workflow. Checker views can be used to look at the number of
issues found by specific checkers in the selected project.

- By default, Coverity Connect provides the following
  Checkers view:

  - All in Project: This view is not
    filtered.
