# Issues: Project Scope

Use Issues: Project Scope views to get a historical overview of
all the issues that have ever been detected in the selected project, including those
that have been fixed. Double clicking on an issue will lead to an Issues: By
Snapshot view so that the source may be viewed.

- This view type is designed for users whose primary tasks fall under the Coverity
  Connect "management workflow". The
  scope of the All In Project view is set so that all CIDs
  in the current project are returned. You cannot edit the scope in views of this
  view type, however you can edit all of the other settings or create a new view with different filter
  settings.
