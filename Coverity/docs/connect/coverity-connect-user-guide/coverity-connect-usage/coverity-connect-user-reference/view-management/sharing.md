# Sharing

This View menu option allows you
to share a view with a user or group. You need to supply the user name or group name.
Coverity Connect will display the shared view at the end of their list of views (for the
View type). This feature avoids the need for users to re-create the view. However, these
users cannot delete the view. Instead, the user who shares the view can unshare it by
removing any user name or group name from the Sharing pop-up
window for the view.

Additionally, you can control the display of the views that are shared with you in the
Preferences window. For more information, see Preferences.
