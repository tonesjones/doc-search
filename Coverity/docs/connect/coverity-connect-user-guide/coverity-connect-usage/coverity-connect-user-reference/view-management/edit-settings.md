# Edit Settings

The Edit Settings menu option allows you to edit and/or or
duplicate a complete view within one window. This includes applying filters, selecting
display columns, creating a snapshot scope, and so forth. It is displayed by selecting
the Gear icon ( [image: image] ) in the Main menu, or
by selecting the menu name in the pulldown next to the view's name in the View
panel.
