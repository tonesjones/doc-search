# Triage attributes

The Triage pane provides a number of attributes by default. Coverity
Connect administrators can add and modify others. For information about using the
attributes to triage a CID, see
Triaging issues.

Note: Coverity Connect allows an administrator with appropriate permissions to create and
modify attributes and attribute values. For more information, see Configuring triage attributes.
