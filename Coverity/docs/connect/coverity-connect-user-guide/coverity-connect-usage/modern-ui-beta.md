# Modern UI (beta)

The modern UI is an updated interface that improves how you work with Coverity Connect. It provides faster workflows, clearer navigation, and better performance.

The modern UI offers several key benefits:

- Navigate quickly with an updated page layout and streamlined menus.
- Complete triage tasks faster with improved issue views.
- Load pages and data faster with improved performance.
- Switch between the modern UI and clasic interface as needed.

The modern UI is available in phases. Each release adds new features and workflows.

The following feature is available in the 2026.3 release:

- Issue triage workflow

Additional features will become available in future releases. All other workflows remain
available in the classic interface.

You can access both the modern UI and the classic interface. This allows you to transition to
the modern UI at your own pace.
