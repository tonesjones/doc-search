# Coverity Platform overview

Coverity Platform supports the following components:

Coverity Connect
:   Developers, managers, and leads of software development teams use Coverity
    Connect to understand, manage, and fix issues found by Coverity Analysis and
    third-party tools.

    Administrators set up and manage Coverity Connect for end users through
    Configuration screens that are accessible from the
    Configuration menu, located in the toolbar.

    For details, see Coverity Connect usage and Coverity Connect administration.

Coverity Policy Manager
:   Leaders of software development teams use Coverity Policy Manager charts to
    monitor issues found by Coverity Analysis and third-party tools.

    Coverity Policy Manager administrators set up and
    maintain Hierarchies that support charts created by Coverity Policy Manager
    end users.

    For details, see Coverity Policy Manager usage and Coverity Policy Manager administration.

Coverity CERT report generator
:   Leaders of software development teams use the Coverity CERT report generator to
    create a formatted report on issues related to the SEI CERT standard in
    Coverity projects.

    For details, see Generating a CERT Report
    in Configuring and Generating Coverity Reports.

Coverity CVSS report generator
:   Leaders of software development teams use the Coverity CVSS report generator to create a
    formatted report on issues related to the CVSS standard in Coverity
    projects.

    For details, see Generating a CVSS Report
    in Configuring and Generating Coverity Reports.

Coverity DISA ASD STIG report generator
:   Leaders of software development teams use the DISA ASD STIG report generator to
    create a formatted report on issues related to the DISA Application Security
    and Development (ASD) STIG (DISA ASD STIG) in Coverity
    projects.

    For details, see Generating a DISA ASD STIG Report
    in Configuring and Generating Coverity Reports.

Coverity Hyundai report generator
:   Leaders of software development teams use the Hyundai report generator to
    create a formatted report on issues related to Hyundai Coding Standard rules in Coverity
    projects.

    For details, see Generating a Hyundai Coding Standard Report
    in Configuring and Generating Coverity Reports.

Coverity Integrity report generator
:   Leaders of software development teams use the Coverity Integrity report PDF-based
    charts to see the current impact of Coverity Connect issues. Administrators
    set up and run Coverity Integrity report generator to produce these reports.

    For details, see Generating a Coverity Integrity Report
    in Configuring and Generating Coverity Reports.

Coverity MISRA report generator
:   Leaders of software development teams use the MISRA report generator to create a formatted
    report on issues related to the MISRA standards in Coverity projects.

    For details, see Generating a MISRA Report
    in Configuring and Generating Coverity Reports.

Coverity Security report generator
:   Leaders of software development teams use the Security report generator to create a
    formatted report on security-related issues in Coverity projects.

    For details, see Generating a Security Report
    in Configuring and Generating Coverity Reports.

Black Duck Software Integrity report generator
:   Leaders of software development teams use the Black Duck Software Integrity report generator
    to create a formatted report on security-related issues in Coverity
    projects.

    For details, see Generating a Black Duck Software Integrity Report
    in Configuring and Generating Coverity Reports.

OWASP Web Top 10 report generator
:   Leaders of software development teams use the OWASP Top 10 report generator to create a
    formatted report on issues related to the OWASP Web Top 10 standard in
    Coverity projects.

    For details, see Generating a Coverity OWASP Web Top 10 Report
    in Configuring and Generating Coverity Reports.

Mobile OWASP Top 10 report generator
:   Leaders of software development teams use the Mobile OWASP Top 10 report generator to create a
    formatted report on issues related to the OWASP Mobile Top 10 standard in
    Coverity projects.

    For details, see Generating a Coverity Mobile OWASP Top 10 Report
    in Configuring and Generating Coverity Reports.

PCI DSS report generator
:   Leaders of software development teams use the PCI DSS report generator to create a formatted
    report on issues related to the Payment Card Industry Data Security Standard
    (PCI DSS) in Coverity projects.

    For details, see Generating a PCI DSS Report
    in Configuring and Generating Coverity Reports.

To see how Coverity products work together, see Coverity Help Center.
