# Monitoring issues

The following charts provide insight into the current and evolving state of issues in
your code base:

- Dashboards: The Quality and
  Security dashboard links open to charts with high-level
  information about issues in a project. The links are located in the top-left area of
  the Coverity Connect window (see Figure 1).

  The Test Advisor
  dashboard is no longer available. Test Advisor has reached end-of-life and is no
  longer available as of the 2021.9.0 release.
- View-level charts: Some Coverity Connect views contain charts that provide more granular information about
  issues in a given view.
