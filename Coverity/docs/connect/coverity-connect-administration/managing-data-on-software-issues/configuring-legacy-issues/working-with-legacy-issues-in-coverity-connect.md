# Working with legacy issues in Coverity Connect

Coverity Connect provides the ability to assign the legacy attribute to individual
issues, as you would triage any other attribute. The legacy attribute doesn't appear in
the triage panel by default, but can be added by completing these steps:

1. Navigate to the Configuration > Attributes menu.
2. Click on Legacy in the left pane.
3. In Attribute Details, click
   Edit.
4. For Display, select On (Shown in triage
   panel).
5. Click OK and Done to exit from
   the Attributes menu.

Now you can select an issue's legacy status directly in Coverity Connect's triage
panel. You can also update the legacy status of multiple issues at once by highlighting
all the issues to be updated and selecting the new legacy value in the triage panel.
