# Working with projects and streams

You create a stream to support issue data on a portion of your code base. Each stream is
organized into a project, which can support multiple streams. You can create one or more
projects in Coverity Connect.

You must create a stream before you can commit issue data to Coverity Connect. To add
issue data to a stream, you first need to run an analysis on some part of your code
base, then commit the resulting issue data to the stream, for example, by using Coverity
Analysis.
