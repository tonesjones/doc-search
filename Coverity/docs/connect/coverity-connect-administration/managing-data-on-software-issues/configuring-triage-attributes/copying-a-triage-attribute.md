# Copying a triage attribute

You can make a copy of any attribute. Except for the name of the new attribute, all the
properties of the copy will match those of the attribute you copied.

**To copy an attribute:**

1. Select Configuration > Attributes.
2. Select the attribute to copy.
3. Click Duplicate.
4. Edit the copy, as needed.

   For guidance, see Editing triage attributes.
5. Click Create to save your changes and exit.
