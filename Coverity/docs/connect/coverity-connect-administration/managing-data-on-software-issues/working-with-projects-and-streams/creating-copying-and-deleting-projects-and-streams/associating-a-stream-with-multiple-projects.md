# Associating a stream with multiple projects

You can use stream links to associate a single stream with more than one project. A
stream link is a reference that points to a stream. A stream link inherits all groups
(and associated roles) that are assigned to the stream to which it is a link and to the
project with which that stream (not the stream link) is associated.

**To create a stream link:**

1. Select Configuration > Projects & Streams.
2. Select a stream to which you want to create a stream link.
3. Click +Link.
4. Select a Project from the drop-down list and click
   Create.
5. Click Done to save your changes and exit.
