# Associating an analysis license with a project

Coverity Connect projects are automatically associated with your default analysis
license, however you may want certain projects to use different license files.

**To select an analysis license file:**

1. Select Configuration > Projects & Streams.
2. Select the project with which you want to associate the analysis
   license.
3. In Project Details, click
   Edit.
4. Use the Analysis License File drop-down to select your
   preferred license file.
5. Click OK to save your changes and exit.
