# Editing projects and streams

The Projects & Streams menu lists all of the projects and
streams that are in Coverity Connect.

**To edit a project or stream:**

1. Select the project or stream that you want to edit from the list in the
   Projects & Streams menu.

   This action opens the edit fields and tabs for the project or stream.

   You can filter the projects and streams. See Using search filters to find projects and streams.
2. Click Edit or use the tabs to modify the project or
   stream.

   - Editing projects: For information about editable project properties, see
     Setting up projects.
   - Editing streams: For information about editable stream properties, see
     Setting up streams.

     Note: Stream links are not editable. For details, see Associating a stream with multiple projects.
3. Click Done to save your changes and exit.
