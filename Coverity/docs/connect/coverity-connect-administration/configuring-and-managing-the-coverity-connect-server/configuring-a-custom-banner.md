# Configuring a custom banner

You can configure a banner and custom message to display at the top of the Coverity
Connect GUI. The following image shows an example of such a banner:

[image: image]

**To configure a custom banner:**

1. On the Coverity Connect menu bar, choose Configuration > System.
2. On the left of the Configuration - System dialog box,
   scroll down and select Custom Banner.
3. Input the text of your message into the Banner Message field.

   You can format your text using the Markdown markup language. These are the
   supported Markdown flavors:

   - the original markdown.pl
   - GitHub flavored Markdown
   - CommonMark
4. Choose a color for your banner and text using the Banner Type
   menu.

   These are the menu choices:

   - Info – Grey banner, black text
   - Alert – Yellow banner, dark yellow text
   - Warning – Pink banner, red text
5. Use the Enabled checkbox to enable or disable your banner as
   appropriate.

   Note: When enabled, the banner is displayed to all users at all
   times. Users cannot dismiss the banner.
