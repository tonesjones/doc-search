# Integrating with other (non-JIRA) bug tracking systems

Coverity Connect can be configured to export issues to other bug tracking systems.
Currently this option supports the Bugzilla bug tracking system.

Note: If both JIRA and Bugzilla are configured to receive issues exported from the same
project, those issues will only be exported to JIRA.
