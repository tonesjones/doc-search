# Changing the URL for Email notifications

You can change your hostname by specifying the cim.rootcontext
property in the <install_dir>/config/cim.properties file.
For example:

```
cim.rootcontext=http://hostname:port
```

This URL will be used to generate hyperlinks in emails generated by Coverity Connect. If
you specify a hostname that is only available on your company intranet, keep in mind
that your users will only be able to click on these links from within the intranet.
