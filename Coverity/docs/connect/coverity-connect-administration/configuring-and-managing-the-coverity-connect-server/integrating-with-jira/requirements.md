# Requirements

Before configuring Coverity Connect to integrate with your Jira instance, be sure that
you have all of the following:

- An Atlassian-supported version of Jira Software
- A currently supported version of Coverity Connect (see the Supported versions of Coverity product components section in the Coverity 2026.6.0 Installation and Upgrade Guide)
- Your Jira URL, username, and API token
- The Jira project(s) to which your CIDs will be exported
