# Integrating with Jira

Coverity Connect allows you to export defects found by Coverity Analysis to an existing
Jira instance. When configured, any CID can be easily added to a specified Jira project,
with various fields automatically generated.

Note: If multiple defect export methods are configured, then the first one in this order is
selected: export-defect-handler, URL, or Jira.
