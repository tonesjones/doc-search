# Adding a SAML SSO Configuration

Note: To create or administer SAML configurations, you need to have Manage server
parameters permission.

**To add an SAML SSO configuration:**

1. On the Coverity Connect menu bar, choose Configuration > System.
2. At the left of the Configuration > System dialog, locate the SAML Configuration
   choice, and click to highlight it.

   If no SAML configuration has been configured yet, the pane displays No
   SAML server configured, and prompts you to add a
   configuration.

     
    [image: image]
3. On the bottom left, below the list of configuration choices, click
   Add to add a new SAML configuration.

   The pane now shows the choices for specifying a new SAML configuration. See SAML SSO configuration parameters.

   Only one SAML configuration can be active at a time. Once you have added a
   configuration, the Add button is disabled once again.

   You can edit the fields of the current configuration. You also have the option of
   deleting the current configuration altogether.
