# Removing an SAML SSO configuration

**To remove a SAML SSO configuration:**

Note: You cannot remove a SAML SSO configuration until there are no more users configured
for SAML SSO.

1. At the left of the Configuration > System dialog, locate the SAML Configuration
   choice, and click to highlight it.
2. In the list of configurations that appears below SAML
   Configuration, click to highlight the configuration you want to
   remove.
3. Click Delete.

   Tip: The Disabled check box for a SAML SSO
   configuration provides a way of disabling the configuration without removing it
   completely from your Coverity Connect setup.
