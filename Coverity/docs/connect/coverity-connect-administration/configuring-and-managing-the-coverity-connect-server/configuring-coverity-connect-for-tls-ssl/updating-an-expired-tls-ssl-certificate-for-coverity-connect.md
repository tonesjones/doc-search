# Updating an expired TLS/SSL certificate for Coverity Connect

This section explains how to update the TLS/SSL certification used by the Coverity Connect web interface (version 2024.12.0 and subsequent versions).
It provides step-by-step instructions for three common scenarios, with explanations suitable for users who have never managed TLS/SSL certificates or Java keystores before.
Both Windows and Linux environments are covered. By following the appropriate steps, your new certificate will be installed and
Coverity Connect configured to use it, ensuring HTTPS access to Coverity Connect.
