# Updating a custom coding standard

Updating a file for a standard in the list of available custom standards replaces that standard with
another file of either the same standard or a new standard.

Notice:
You cannot update a built-in standard.

**To update a custom standard:**

1. In the Coverity Connect GUI on the
   Configuration → Standards screen,
   select the standard to update (replace), then click Update.
2. To select the new standard, in the pop-up window click Choose File.
   In the finder, browse for the file then click Open to confirm the selection.
3. At the confirmation prompt, either click Update to update
   the standard file with the new standard file, or Cancel
   to retain the original standard.

   If you click Update, the updated file replaces the old
   file in the list of standards.
