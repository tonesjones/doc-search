# Hiding or restoring a standard

Standards on the Configuration → Standards page
can be hidden so that they are not used. Hidden standards can be restored for use.

To hide a standard, select the standard to hide, then click Hide.
The standard will be listed as (hidden), and it will no longer be shown in the usual views:
Issues: By Snapshot, Issues: Project Scope,
and Policy Manager.

To restore or unhide a hidden standard, select the standard to restore, then click
Unhide. The standard will be listed and available for use.
