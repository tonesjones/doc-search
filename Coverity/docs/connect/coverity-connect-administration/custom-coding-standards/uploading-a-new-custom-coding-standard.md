# Uploading a new custom coding standard

To upload a new custom coding standard from your local system to the Coverity Connect GUI:

1. Click +Standard.
2. In the pop-up, click Choose File.
3. In the finder, select the new standard's JSON file, then click
   Open to confirm the selection.
4. At the confirmation prompt, observe any warnings, verify the selected file, then
   select either Add to add the selected new standard or
   Cancel to exit without any changes.
5. In the Configuration - Standards window, verify that the
   new custom coding standard is listed.
