# Renaming a custom coding standard

Notice:
You cannot rename a built-in standard.

**To rename a custom coding standard:**

1. In the Coverity Connect GUI on the
   Configuration → Standards screen,
   select the standard to rename, then click Rename.
2. In the pop-up, enter the new name, then click Rename to
   rename the standard or Cancel to exit without
   renaming.
3. In the Configuration → Standards window,
   verify the standard name.
