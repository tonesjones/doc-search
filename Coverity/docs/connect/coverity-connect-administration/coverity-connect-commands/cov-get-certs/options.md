# Options

--host <server-host>
:   The server hostname, of which Coverity Connect is a client.

--port <server-port>
:   The host server's HTTPS connection port.

--certs <cert_file>
:   The name of the certificate file.

    This defaults to the Coverity Connect Java truststore
    (at <Coverity Connect install directory>/jre/lib/security/cacerts).

    Normally you don't need to use this option.
