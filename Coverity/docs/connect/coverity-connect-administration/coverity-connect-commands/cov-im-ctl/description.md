# Description

The `cov-im-ctl` command performs various operations, including
starting or stopping Coverity Connect.

On Windows systems, when Coverity Connect is installed as a service, the
cov-im-ctl.exe program is often unnecessary because
Coverity Connect starts and stops automatically when the system boots up or shuts
down. When Coverity Connect is installed as a service, any administrator can use
this command.

When Coverity Connect is not installed as a service, only the user who installed
Coverity Connect is able to use this program to start or stop it.
