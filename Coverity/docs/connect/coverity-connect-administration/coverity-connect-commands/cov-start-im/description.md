# Description

The `cov-start-im` command starts Coverity Connect.

On Windows systems, when Coverity Connect is installed as a service, the
cov-start-im.exe program is often unnecessary because
Coverity Connect starts automatically when the system boots up.

When Coverity Connect is installed as a service, any administrator can use this command.

When Coverity Connect is not installed as a service, only the user who installed
Coverity Connect is able to use `cov-start-im` to start it.
