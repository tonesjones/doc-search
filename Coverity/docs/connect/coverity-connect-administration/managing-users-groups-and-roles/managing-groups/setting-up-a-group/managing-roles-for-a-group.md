# Managing roles for a group

When you select a group from the Users & Groups menu, the
Roles tab will display any roles that are currently assigned
to the group at each level (global, component, project, stream, component map, and
triage store). You can use this tab to view role assignments at all levels, or add,
edit, and remove roles for the selected group at the global level.

Note: You can edit roles at a lower level (by project, stream, component map, or triage
store) from the respective Configuration menu.

For information about roles, including role and permission definitions, see Roles and role-based access control.

**To manage a role for a group:**

1. Select a group from the list of groups.
2. Click the Roles tab for the group.

   1. In the Roles tab, ensure that you've selected the
      Global level from the Show pull-down
      menu.
   2. Select Global in the list and click
      Edit in this tab.
   3. Assign one or more roles to the group.
3. Click OK to save your changes.

Note: **Removing a role from a group:** To remove a role
assignment from a group, click Edit in the
Roles tab, and deselect the role that you want to remove.
Then apply your changes.
