# Assigning a user to a group

A user can belong to one or more groups. Groups are an efficient way of assigning roles
to a user. The user inherits the roles of the groups to which it belongs, unless
overridden at the user level (see Roles and role-based access control).

Note: If you want to assign multiple users to a group at once, you can follow the procedure
in Assigning one or more users to a group.

**To assign a user to a group:**

1. Select a user to display the Group Memberships tab for the
   user.
2. Click Edit, and start typing in Select group to
   add. Select one or more groups from the drop-down menu in the
   tab.

   For example, you might select the Administrators group.
   You might need to scroll down the list.
3. Click OK to save your changes and exit.

Note: To remove a user from a group, select the group, and click
Remove.
