# Deleting a user

**To delete a user:**

1. Disable the user account, see Disabling a user account.
2. Assign all issues in the disabled account to active users.
3. Once the disabled account is empty, delete the account.
4. Navigate to Configuration > Users & Groups.
5. Select each user to delete.
6. Click Delete.

   Click Delete in the confirmation window.
7. Click Done to save your changes and exit.
