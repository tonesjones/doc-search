# Desktop Analysis usage tracking

You can use Coverity Connect to get information on the defects found specifically by
Desktop Analysis users. You may wish to know, for example, how many defects are detected
and fixed locally, before ever being committed to the server. See the Coverity
Desktop Analysis
2026.6.0 User Guide for information on tracking Desktop Analysis
usage data.
