# Monitoring and diagnosing Coverity Connect performance

This section provides information about tools that you can use to monitor the performance
of your system. It is highly recommended that you establish a monitoring schedule or
policy within your organization so that you can continually record performance numbers.
This way, you can track system performance trends over time to assess the health of the
system.

Additionally, this section provides tools that will help you diagnose issues if you
suspect that there is a degradation in performance.

In this section:

- Linux monitoring and diagnosis tools
- Windows monitoring and diagnosis tools
- System performance reference
- Presenting Coverity Connect application metrics in open-source data acquisition and monitoring software
