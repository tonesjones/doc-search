# Installing Coverity Platform components

This part of the guide is for administrators who run the Coverity®
Platform installer, the name of the tool that installs and upgrades Coverity Connect.

Note: Upgrade procedures are described in Upgrading Coverity Connect, which not
only provides steps to perform the upgrade, but also includes important upgrade notes on
new features that might affect your upgrade.

In this section:

- Downloading the Coverity Platform installer from the Black Duck repository
- Installing Coverity Connect
- Coverity Platform installer modes
- Advanced installation options
- Post-installation notes
- Installing Coverity Reports
- Coverity Reports installer modes
