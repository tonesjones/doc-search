# Upgrading Coverity Desktop

This section describes the basic upgrade procedures for Coverity Desktop for Eclipse and Wind River, Coverity Desktop for Microsoft
Visual Studio, and Coverity Desktop
for IntelliJ and Android Studio. Prior to upgrading to the latest version,
consult Important upgrade considerations for a list of important
product changes that may affect your Coverity Desktop workflow.

For general installation procedures, see Installing Coverity Desktop components.

The 'Classic' variant of the Coverity Desktop plug-ins is no longer supported. If you are
upgrading from Coverity Desktop Classic, you must uninstall it completely from your IDE,
and then install the current Coverity Desktop version.
