# Coverity Connect administration

Administrators set up and manage Coverity Connect for end users through Configuration
screens that are accessible from the Configuration menu, located
in the toolbar.

End users view, triage, monitor, and fix issues found by Coverity Analysis and third party
tools. For details about end usage, see Coverity Connect usage and
Coverity Connect user reference.

For installation instructions, information about supported platforms, and licensing
options, see Installation, product licenses, and supported platforms.

Coverity Connect also supports an API for creating Web services that communicate with the
Coverity Connect database. For details, see the Coverity Platform 2026.6.0 SOAP Web Services API Reference and the Coverity Platform 2026.6.0 REST Web Services API Guide.

In this section:

- Configuring and managing the Coverity Connect server
- Configuring and managing the database
- Client-side TLS/SSL certificate management
- Set up Coverity Connect to use a context path
- Managing users, groups, and roles
- Managing data on software issues
- Configuring automatic owner assignment
- Custom coding standards
- Configuring Coverity Connect enterprise clusters
- Configuring a server to support Code Sight
- Server administration for Desktop Analysis
- Coverity Connect URL construction
- Exported defect output
- Suppressing built-in views for new users
- Changing the date format display in Coverity Connect
- Configuring Coverity Desktop through Coverity Connect
