# Integration with Jenkins automated builds

Note:
As of Coverity 2025.3.0, support for the Coverity Jenkins plug-in has been removed.
For Jenkins integration, please use the new Bridge-based plug-in, the
[Black Duck Security Scan Plugin for Jenkins](https://docs.blackduck.com/r/bridge/latest/bridge-cli-guide/using-black-duck-security-scan-pipe-for-coverity.html).
