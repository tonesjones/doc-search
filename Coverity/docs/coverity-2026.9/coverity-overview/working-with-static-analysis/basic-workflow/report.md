# Report

During the *report* stage, the manager or Dev/Ops can look at many different
projects, releases, and so on, in order to examine dashboards and trends, and to create
reports. Possible actions include:

- View and organize dashboards and charts in Coverity Connect.
- Generate reports:
  - Coverity CERT Report
  - Coverity CVSS Report
  - Coverity DISA ASD STIG Report
  - Hyundai Coding Standard Report
  - Coverity Integrity Report
  - Coverity MISRA Report
  - OWASP Web Top 10 Report
  - Mobile OWASP Top 10 Report
  - PCI DSS Report.
  - Security Report
  - Black Duck Software Integrity Report
- Report on output from the Coverity Policy Manager as code is tested for adherence to
  policies for code security and quality.
