# Preface

This guide introduces Coverity®, a Static Application Security
Testing (SAST) and issue management tool.

- It describes Coverity's advantages as a testing solution, explains how it works,
  describes the roles and workflows involved, and summarizes the ways in which you can
  customize or extend your analysis.
- It lists and describes all the books in the Coverity Doc set and provides
  information about where to go for additional help.

This guide focuses on the use of Coverity as a standalone product. You can also use
Coverity as a part of [Black Duck Polaris™ Platform](https://docs.blackduck.com/r/polaris/black-duck-polaris-platform/polaris-product-overview.html). This book does not describe
that use case.
