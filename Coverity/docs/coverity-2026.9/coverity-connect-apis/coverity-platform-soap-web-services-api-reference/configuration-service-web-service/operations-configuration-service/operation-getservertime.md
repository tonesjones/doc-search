# Operation: getServerTime

## Name

getServerTime

## Description

Retrieves the current date and time from the server.

## Output (Literal)

The output of this operation is the argument getServerTimeResponse having the
structure defined by the following table.

| Name | Type |
| --- | --- |
| return | dateTime |
