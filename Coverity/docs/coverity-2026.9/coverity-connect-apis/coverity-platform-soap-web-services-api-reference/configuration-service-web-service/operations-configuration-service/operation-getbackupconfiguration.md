# Operation: getBackupConfiguration

## Name

getBackupConfiguration

## Description

Retrieve the schedule for automated backup of the Coverity Connect database.

## Output (Literal)

The output of this operation is the argument getBackupConfigurationResponse having
the structure defined by the following table.

| Name | Type |
| --- | --- |
| return | backupConfigurationDataObj |
