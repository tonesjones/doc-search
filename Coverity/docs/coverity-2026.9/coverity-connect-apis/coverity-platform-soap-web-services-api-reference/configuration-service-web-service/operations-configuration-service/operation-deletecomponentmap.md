# Operation: deleteComponentMap

## Name

deleteComponentMap

## Description

Delete a component map.

## Parameters

componentMapId
:   **Type:** 
    componentMapIdDataObj

    | Field name | Type | Description |
    | --- | --- | --- |
    | name | string | Required. Name of the component map to delete or update. |

## Remarks

To retrieve a list of component maps, see getComponentMaps().
