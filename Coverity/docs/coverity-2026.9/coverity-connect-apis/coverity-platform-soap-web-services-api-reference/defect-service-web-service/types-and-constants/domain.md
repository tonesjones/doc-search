# Domain

| Checker Domain | Description |
| --- | --- |
| STATIC_C | Applies to checkers that run static analyses of C/C++ source code. |
| STATIC_JAVA | Applies to checkers that run static analyses of Java source code. |
| STATIC_CS | Applies to checkers that run static analyses of C# source code. |
| DYNAMIC_JAVA | Applies to checkers that run dynamic analyses of Java source code. Coverity Dynamic Analysis checkers. |
| EXTEND | Applies to custom checkers created through the Coverity Extend SDK. |
