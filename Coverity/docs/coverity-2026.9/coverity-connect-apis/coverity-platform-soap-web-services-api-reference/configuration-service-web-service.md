# Configuration Service web service

## Name

Configuration Service

## Description

API for performing project, stream, user and group (both LDAP and local), role,
component/component map, project, attribute, triage store, and other configurations
(many of which are also possible through the UI and/or through the
`cov-manage-im` command). It also supports notifications and
expiration of unused streams.

## Type

SOAP
