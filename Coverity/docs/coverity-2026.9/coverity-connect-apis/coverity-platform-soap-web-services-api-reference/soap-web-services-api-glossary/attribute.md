# Attribute

Property of given CID used during the triage process to specify the state of the CID
(for example, its classification, severity, or the type of action that it requires).
Depending on its attribute type, an attribute can take a string value or a value from a
list of values. To retrieve a complete list, you can invoke getAttributes().
