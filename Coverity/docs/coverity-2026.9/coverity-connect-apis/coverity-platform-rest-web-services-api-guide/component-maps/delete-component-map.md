# Delete component map

Example DELETE request to delete the specified component map.

**cURL request**

```
curl --location \
--request DELETE "http://my_connect_host:8080/api/v2/componentMaps/my_component_map" \
--header 'Accept: application/json' \
--user my_username:my_password
```
