# Checker policies

The `checkerPolicy` resource provides endpoints for managing checker
policies in Coverity Connect.

This section presents a variety of example queries on the
`checkerPolicy` resource.
In each example, the request is formatted as a cURL request.

List all checker policies

Create a checker policy

Update a checker policy

Delete a checker policy

Download a checker policy

Get the global checker policy assignment

Create or replace the global checker policy assignment

Remove the global checker policy assignment

Get the project checker policy assignment

Create or replace the project checker policy assignment

Remove the project checker policy assignment

Compute the effective checker policy

Verify compliance against the effective checker policy
