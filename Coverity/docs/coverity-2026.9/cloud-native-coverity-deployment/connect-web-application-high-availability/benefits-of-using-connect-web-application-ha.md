# Benefits of using Connect Web application HA

HA is good for environments with high volumes of commits. For example:

- Good for lots of concurrent users
- High throughput of commits
- High throughput of REST APIs
- High throughput of Coverity reports

Customers with the following constraints or issues can benefit from using Coverity
Connect web application HA:

- Too many commits are queued, and commits are not processed in time.

For further information on Connect Web application high availability, see Connect Web application high availability.
