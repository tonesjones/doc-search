# enabling-oci-redis

## Integrated Bitnami Redis chart

The following excerpt from the `cnc` chart
`values.yaml` file contains default values that can be used to
setup Redis storage management. By default, these Helm keys are commented. If you
enable onPrem (OCI) Redis, uncomment the following Helm key rows by replacing the
`#` symbol with a space to preserve 2-space YAML indentation.

For further Bitnami OCI Redis information, refer to <https://github.com/bitnami/charts/blob/main/bitnami/redis/README.md>.

Starting in the 2026.9 release, the on-cluster Redis deployment uses official Docker
Hub images instead of Bitnami-packaged images. Update existing Redis image
references and metrics exporter configuration as shown in the following example.

```
                # onPrem helm overrides for open-source sub-charts
                # redis:
                #   global:
                #     security:
                #       allowInsecureImages: true
                #
                #   fullnameOverride: "cache-redis"
                #   architecture: standalone
                #
                #   image:
                #     registry: registry-1.docker.io
                #     repository: redis
                #     tag: "8.6.4"
                #
                #   auth:
                #     enabled: true
                #     existingSecret: <REDIS_PASSWORD_SECRET_NAME>
                #     existingSecretPasswordKey: <REDIS_SECRET_PASSWORD_KEY>
                #
                #   metrics:
                #     enabled: true
                #     image:
                #       registry: registry-1.docker.io
                #       repository: oliver006/redis_exporter
                #       tag: "v1.86.0"
                #
                #     command:
                #       - "/redis_exporter"
                #
                #     args:
                #       - "--redis.addr=rediss://127.0.0.1:6379"
                #       - "--redis.password=$(REDIS_PASSWORD)"
                #
                #     extraEnvVars:
                #       - name: REDIS_PASSWORD
                #         valueFrom:
                #           secretKeyRef:
                #             name: <REDIS_PASSWORD_SECRET_NAME>
                #             key: <REDIS_SECRET_PASSWORD_KEY>
                #
                #   volumePermissions:
                #     image:
                #       registry: registry-1.docker.io
                #       repository: alpine
                #       tag: "3.21.7"
                #
                #   kubectl:
                #     image:
                #       registry: registry-1.docker.io
                #       repository: alpine/kubectl
                #       tag: "1.36.2"
                #
                #   sysctl:
                #     image:
                #       registry: registry-1.docker.io
                #       repository: alpine
                #       tag: "3.21.7"
                #
                #   master:
                #     persistence:
                #       enabled: false
                #     resources:
                #       limits:
                #         cpu: "0.5"
                #         memory: 1.1Gi
                #       requests:
                #         cpu: "0.5"
                #         memory: 1.1Gi
                #
                #   tls:
                #     enabled: true
                #     autoGenerated: true
                #     certFilename: "certificate.pem"
                #     certKeyFilename: "key.pem"
                #     certCAFilename: "ca.crt"
                #     authClients: false
                #
                #   commonConfiguration: |-
                #     save ""
                #     appendonly no
                #     maxmemory 1gb
                #     maxmemory-policy noeviction
```

Important:
When Redis authentication is enabled, configure
`redis.auth.existingSecret` and
`redis.auth.existingSecretPasswordKey` to use a customer-managed secret. For upgrades, these settings preserve the existing Redis password and prevent the Redis subchart from generating a new password.

Note:
The official `oliver006/redis_exporter` image requires explicit
`command`, `args`, and, when authentication is enabled,
`extraEnvVars` settings. Without these settings, the metrics exporter container will not start correctly.
