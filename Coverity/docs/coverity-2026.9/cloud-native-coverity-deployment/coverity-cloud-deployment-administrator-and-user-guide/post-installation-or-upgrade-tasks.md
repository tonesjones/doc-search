# Post installation or upgrade tasks

After you install or upgrade Coverity Cloud, you might need to do one or more of the
following:

- Log into the Coverity Connect UI
- Upload a Coverity Connect license
- Configure SAML
- Configure LDAP
- Configure Jira
- Add the Bugzilla certificate
- Configure Kerberos
