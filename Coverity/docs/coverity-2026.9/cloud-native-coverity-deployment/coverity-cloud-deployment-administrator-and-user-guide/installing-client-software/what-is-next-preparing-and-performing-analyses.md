# What is next? preparing and performing analyses

Once you have set up your cloud environment, you need to set up your local environment so
that you can perform analyses. This includes several taska such as creating a Coverity
configuration file, `coverity.yaml`. To prepare and perform analyses,
refer to the chapter Performing an analysis in a Coverity cloud deployment in
the Coverity Analysis User and Administrator Guide.
