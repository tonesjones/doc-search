# Enabling Coverity metrics through Helm overrides

Coverity is able to generate and expose time-series metrics data that enables you to
monitor the performance of your Coverity scans. During Coverity deployment, you must set
Helm keys to enable this feature. For information on setting Helm keys for metrics
during a deployment, refer to Metrics.
