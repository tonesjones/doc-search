# Access privileges

The following sections identify access privileges required to install and manage a
Coverity cloud deployment.

- Kubernetes client user privileges
- Amazon AWS account privileges
- Google GCP administrator privileges/roles
- Microsoft Azure administrator privileges/roles
- Coverity permissions to manage Scan Services resources
