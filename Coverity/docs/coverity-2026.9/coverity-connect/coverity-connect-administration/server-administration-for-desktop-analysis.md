# Server administration for Desktop Analysis

Coverity Connect requires specific configuration in order to provide analysis summary
data to Desktop Analysis users. This chapter describes the administrative tasks required
to enable proper communication with Desktop Analysis.

Note: The `Developer` role is required for using Desktop Analysis.
