# Configuring triage stores after upgrading from version 6.0 or 6.0.1

All triage store configurations from version 6.0 or 6.0.1 are retained after the upgrade.
However, the Roles menu is new in version 2026.9.0. After upgrading to version 2026.9.0 from
version 6.0 or 6.0.1, you can assign roles manually,
as needed.
