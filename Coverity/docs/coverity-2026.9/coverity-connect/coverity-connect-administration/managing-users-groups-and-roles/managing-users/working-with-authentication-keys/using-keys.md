# Using keys

After creating an authentication key, `cov-manage-im`,
`cov-commit-defects`, and `cov-run-desktop` will
accept the `--auth-key-file` option for connecting to Coverity Connect,
rather than requiring `--password`.

See the command reference for `cov-manage-im`,
`cov-commit-defects`, and
`cov-run-desktop` in the
Coverity Command Reference for more information.
