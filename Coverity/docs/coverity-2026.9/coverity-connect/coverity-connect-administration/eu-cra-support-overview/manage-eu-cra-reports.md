# Manage EU-CRA reports

Review, download, or delete generated EU-CRA artifacts from the Reports
tab.

Generate an EU-CRA artifact. For more information,
see Generate EU-CRA artifacts.

Open the **Reports** tab to review the status or download the completed
artifact. The reports displayed depend on where you open the **Reports** tab:

- The project-level **Reports** tab displays reports generated for all streams
  in the selected project.
- The stream-level **Reports** tab displays reports generated for the selected
  stream.

The **Reports** tab displays the following information for each artifact:

- Status
- File Name
- Format
- Type
- File Size
- Created By
- Created
- Finished

1. Open the **Reports** tab at the appropriate
   scope:
   - To view reports for all streams in a project, open
     the project-level **Reports** tab.
   - To view reports for a specific stream, open the
     stream-level **Reports** tab.
2. Select the artifact that you want to manage.
3. To download a completed artifact, click the download icon for the
   artifact.
4. To delete an artifact, click the delete icon for the artifact.

   Note: You cannot delete an artifact while generation is in progress.
