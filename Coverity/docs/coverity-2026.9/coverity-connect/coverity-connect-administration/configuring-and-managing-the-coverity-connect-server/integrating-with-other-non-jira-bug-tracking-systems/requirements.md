# Requirements

This integration requires Bugzilla 4.x or 5.0. The integration utilizes the Bugzilla
XML-RPC API. Ensure that XML-RPC is enabled. Please refer to the Bugzilla Administration
Guide on how to enable the XML-RPC API for Bugzilla.
