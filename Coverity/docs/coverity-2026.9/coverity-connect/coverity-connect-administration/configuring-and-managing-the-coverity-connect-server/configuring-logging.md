# Configuring logging

Coverity Connect automatically logs system event information to the cim.log file.
You can increase the amount of information that Coverity Connect records
to this file by enabling additional logging options to work with Coverity Support on an
issue. Coverity recommends that you leave all of the logging options un-enabled and only
enable them by request from Support.
