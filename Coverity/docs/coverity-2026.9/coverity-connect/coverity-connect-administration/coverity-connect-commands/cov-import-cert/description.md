# Description

`cov-import-cert` allows you add the certificate into the user's own
truststore,in order to allow authentications between a coordinator and a subscriber.

If the truststore does not exist, Coverity Connect creates one.

For more information, see
"Configuring Coverity Connect enterprise clusters" in the
Coverity Platform User and Administrator Guide.
