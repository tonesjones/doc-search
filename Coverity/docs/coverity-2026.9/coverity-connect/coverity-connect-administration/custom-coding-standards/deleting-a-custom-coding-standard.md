# Deleting a custom coding standard

Notice:
You cannot delete a built-in standard.

**To delete a custom coding standard:**

1. In the Coverity Connect GUI, on the Configuration → Standards screen,
   select the standard to delete, then click Delete.
2. At the confirmation prompt, either click Delete to delete
   the standard or Cancel to retain the standard.
