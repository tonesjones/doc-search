# Upgrading instances that use an embedded database

Important: All upgrades must be performed using one of the upgrade
options in the Coverity Platform installer. Do not perform an upgrade manually. For
example, do not use command line techniques to backup an existing instance and then
restore it to a new, upgraded instance.

Before using the installer, determine the type of upgrade, as described in Choosing the type of upgrade.

For standalone deployments, see Performing the upgrade: standalone deployments.

For clustered deployments, see Performing the upgrade: clustered deployments.
