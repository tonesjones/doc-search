# Coverity Platform installer modes

You can complete the series of installation steps using either a graphical or console
(command-line) interface. Alternatively, you can run the silent installer to complete the
installation from the command line in a single step.

Note: If Coverity Connect is deployed in the cloud, refer to Coverity Cloud Deployment Administrator and User Guide for information on Coverity Connect
deployment.

In this section:

- Selecting an installer mode
- Coverity Platform graphical installer
- Coverity Platform silent installer
