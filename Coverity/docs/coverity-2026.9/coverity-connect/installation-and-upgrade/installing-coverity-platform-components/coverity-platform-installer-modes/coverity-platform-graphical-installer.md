# Coverity Platform graphical installer

The Coverity Platform installer (see Selecting an installer mode) provides
options for completing the most common Coverity Connect installation and upgrade use cases:

- Fresh install
- In-place upgrade
- Backup-and-restore upgrade
- Intermachine upgrade
- Upgrade preparation

For detailed instructions on all Coverity Connect upgrades, including external database
upgrades, see "Upgrading Coverity Connect"
in the Coverity Installation and Upgrade Guide.
