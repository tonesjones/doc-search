# Columns

This settings window allows you to specify which columns to display in a given view,
typically so that you can see the most important data by which you are filtering a view
(see Filters). By default, Coverity Connect only displays a subset
of the columns that are available to a view. To help you determine which columns to
display, Coverity Connect provides a description of each column that you can select for
a given view.
