# Finding a project from the landing page

Use search, sort, and filters on the Projects page to locate a project and open its
Streams View.

1. Open the Projects page in the modern UI.
2. **Optional:** 
   In the search field, enter part of the project name.

   The search is case-insensitive and matches any substring of the project
   name.
3. **Optional:** 
   Change the sort order to surface the most relevant projects.

   Available sort options include Latest Scan, Project Name and Stream Count.
4. **Optional:** 
   Select Add filters and apply one or more filters, such
   as Last Scan or Stream Count.

   Multiple filters are applied using AND logic. Applied filters appear as chips
   in the toolbar.
5. Review the project cards.
6. Select the project name or the Active Streams count to open that project's
   Streams View.
