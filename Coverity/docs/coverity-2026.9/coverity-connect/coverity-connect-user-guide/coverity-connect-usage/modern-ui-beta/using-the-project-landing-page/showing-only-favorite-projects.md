# Showing only favorite projects

Mark projects as favorites and use the Favorites tab to view only the projects you
use most often.

1. Open the Projects page.
2. Find the project you want to favorite.
3. Select the favorite toggle on the project card.
4. Select the Favorites tab.
5. Confirm that only favorited projects are displayed.

Favorite state persists across page reloads.
