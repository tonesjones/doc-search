# Refining the project list with filters

Apply one or more filters to narrow the project list to the items most relevant to
you.

1. Select Add filters.
2. Select a filter category such as Last Scan or Stream Count.
3. Choose the desired filter values.
4. Review the applied filter chips in the toolbar.
5. **Optional:** 
   To remove a single filter, select the filter chip and click the X icon. To
   reset all filters, select Clear Filters.

The project list updates to show only projects that match all applied filters.
Multiple filters use AND logic.
