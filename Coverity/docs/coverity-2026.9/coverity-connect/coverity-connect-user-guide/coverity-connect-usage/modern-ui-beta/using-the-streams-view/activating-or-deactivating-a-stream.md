# Activating or deactivating a stream

Toggle a stream's active status to control its visibility in the default Streams View.

You must have the `Manage Stream` permission for the stream.

1. In the Streams View, locate the stream you want to activate or deactivate.
2. Select the active toggle on the stream card:

   - Toggling off deactivates the stream and marks it as outdated. The stream is hidden from the default Streams View, which shows only active streams.
   - Toggling on reactivates the stream and restores it to the active stream list.
3. **Optional:** 
   To view deactivated streams, click on All Streams
   tab.

Note: Activating or deactivating a stream does not affect its snapshots, defects, or role assignments. The action is recorded in the server usage log for auditing purposes.
