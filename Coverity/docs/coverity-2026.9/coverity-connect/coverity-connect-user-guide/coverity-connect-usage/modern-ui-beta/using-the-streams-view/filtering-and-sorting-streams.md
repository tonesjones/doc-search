# Filtering and sorting streams

Use search, sort, and filter controls to narrow the streams list to the items most relevant to you.

You must be viewing the Streams View for a project.

Sort streams

1. Select a sort option:

   - Latest scan (default) — most recently analyzed streams appear
     first.
   - Stream Name (a → z) — alphabetical ascending order.
   - Stream Name (z → a) — descending order.
   - Open issues — by issue count.
2. **Optional:** 
   Select the sort direction (ascending or descending). Once you click
   Open issues, the results are sorted in descending
   order. Once you click Latest scan, the results are sorted
   in ascending order.

Filter streams

3. Locate the filter controls above the stream cards.
4. Apply one or more filters:

   - Last scan — specify a date range to focus on recent or stale
     streams.
   - Security impact — select Very High, High, Moderate, Low, Very Low
     and None to show streams with issues of that severity.
   - Open issues — specify a number of issues and range.
   - Quality impact — select High, Medium, or
     Low.
5. Review the applied filter indicators.
6. **Optional:** 
   To remove a single filter, clear the individual filter value. To reset all filters, select Clear all.

Search for a stream

7. Select the search input field above the stream cards.
8. Type part of the stream name.

   The stream list filters dynamically to show only matching streams.
9. **Optional:** 
   To restore the full list, clear the search field.

Note: Search, filter, and sort settings persist for your current browser session and are retained if you navigate away and return to the Streams View.
