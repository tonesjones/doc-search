# Viewing streams in a project

Browse all streams in a project from the Streams View and navigate into a stream to view
its issues. Each card shows the stream name, last scan date, open issues, and issue
breakdown by security and quality impact.

You must have view access to the project.

1. Open the Projects page in the modern UI.
2. Select the project name to open that project.
3. Select the Streams tab.

   The Streams View displays all streams you have access to as cards. Each card shows the stream name, last scan date, outstanding and newly detected issue counts, and issue breakdown by security and quality impact.
4. **Optional:** 
   To view issues for a specific stream, select the stream name or an issue count value on the card.

   The Issues tab opens with the selected stream filter applied.
5. **Optional:** 
   To switch to a different stream while viewing issues, use the stream breadcrumb combobox in the page header to select another stream.
