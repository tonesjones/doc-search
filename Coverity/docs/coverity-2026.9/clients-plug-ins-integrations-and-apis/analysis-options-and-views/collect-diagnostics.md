# Collect Diagnostics

This menu option opens the Collect
Diagnostics view,
which helps you create a zip file of diagnostic information for the current project.

Figure 1. Collect Diagnostics menu
[image: image]

To create the diagnostics zip file:

1. Navigate to Tools > Coverity > Collect Diagnostics for Coverity Support.
2. Click the check boxes to select which diagnostics items you want to include.
3. Click the Zip up selected files... button.
4. Save the zip file to the desired location.
