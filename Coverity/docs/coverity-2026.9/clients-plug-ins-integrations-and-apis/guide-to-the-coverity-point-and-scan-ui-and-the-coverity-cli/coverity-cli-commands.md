# Coverity CLI commands

The following commands are used by the Coverity command-line interface (CLI).
The overall process is described in the Guide to the Coverity Point and Scan UI and the Coverity CLI.

- `coverity analyze`
- `coverity capture`
- `coverity commit`
- `coverity help`
- `coverity list`
- `coverity scan`
- `coverity setup`
- `coverity verify-compliance`

Note:
If you enter `coverity` without specifying a subcommand,
the Coverity CLI prompts you to enter the name of the subcommand to run.
