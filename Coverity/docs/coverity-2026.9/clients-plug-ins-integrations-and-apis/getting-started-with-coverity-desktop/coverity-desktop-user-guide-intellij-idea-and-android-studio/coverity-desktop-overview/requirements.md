# Requirements

Coverity Desktop for IntelliJ IDEA, JetBrains CLion, or Android Studio has the
following requirements (refer to the "Coverity Desktop" chapter of
the Coverity Installation and Upgrade Guide for supported IDE and Java version
numbers):

- Coverity Connect
  2026.9.0
- IntelliJ IDEA, JetBrains CLion, or Android Studio
- Java Runtime Environment

It is assumed that you have a functional knowledge of your IDE, as well as Coverity
Analysis, and Coverity Connect concepts. If you need more information, consult the
following Coverity product documentation:

For more information about Coverity Connect, see the Coverity Platform User and Administrator Guide.

For more information about Coverity Analysis, see the Coverity Analysis User and Administrator Guide.
