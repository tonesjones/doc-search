# Details view

The Details view allows you to manage an issue.

For example, you can assign an issue's classification, severity level, owner, or add a
comment. The Details view is not populated until you double click
an issue in the Issues view.

Note: The attributes described in this section represent the fields that are available to you by
default. It is possible that there are additional attributes and values created as
custom attributes in Coverity Connect.

Use the next/previous issue buttons at the top of the Details view
to display the next or previous CID in your list.
