# Checkers

The `Checkers` class declares a relationship between a specific checker
and a 
`CheckerSettings`
 object that holds settings to configure that checker.

<name_of_checker>?: CheckerSettings
:   The name of the checker that is configured by the `CheckerSettings`
    object.
