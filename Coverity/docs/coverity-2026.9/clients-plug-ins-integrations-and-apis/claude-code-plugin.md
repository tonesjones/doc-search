# Claude Code plugin

The Claude Code plugin integrates Claude Code with Coverity Connect and Sigma to
identify and remediate security findings during development.

The plugin uses Sigma to analyze code that Claude Code creates or modifies. The plugin
retrieves workflow configuration from Coverity Connect and applies it during analysis
and remediation.

For prerequisites, installation, setup, and authentication instructions, see Installing the Claude Code plugin.

For information about scan policies, guardrails, and Sigma scan configuration, see Agentic SAST workflows.
