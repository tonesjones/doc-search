# Installing Coverity Analysis tools

Coverity Desktop Analysis is included in the Coverity Analysis tool set. To install it, run the
installer and follow the on-screen prompts. When asked which installation mode to run,
choose "Desktop Analysis" mode. For additional information, see the Coverity Installation and Upgrade Guide.
