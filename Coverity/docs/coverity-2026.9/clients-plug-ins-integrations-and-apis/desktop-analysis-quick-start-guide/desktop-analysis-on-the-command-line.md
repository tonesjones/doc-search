# Desktop Analysis on the command line

The following sections will walk you through initial configuration and use of Desktop
Analysis from the command line. The process is broken down into the following general tasks:

- Create coverity.conf
- Add the "bin" directory to your PATH
- Run `cov-run-desktop --setup`
- Analyze a specific source file
- Review returned defects
