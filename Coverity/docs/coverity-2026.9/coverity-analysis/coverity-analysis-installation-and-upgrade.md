# Coverity Analysis: installation and upgrade

Information for installing, upgrading, and understanding platform and language requirements for Coverity Analysis.

- **Hardware requirements** provides hardware recommendations and considerations for
  running Coverity Analysis, including minimum requirements, disk usage, operating
  system considerations, and virtualized environments.
- **Installing Coverity Analysis** covers downloading the installer, selecting an
  installation mode, configuring license options, and installing from an archive
  file.
- **Supported platforms** provides matrices of supported operating systems and
  runtime environments for Coverity Analysis.
- **Supported languages, compilers, and frameworks** provides matrices of the
  languages, compilers, and frameworks supported by Coverity Analysis.
- **Upgrading Coverity Analysis** describes the standard upgrade procedure,
  including considerations for churn, preview and production checkers, and web
  application archive behavior.
- **Updating with incremental releases** covers how to apply incremental updates,
  run `cov-install-updates`, and roll back an update session if
  needed.
