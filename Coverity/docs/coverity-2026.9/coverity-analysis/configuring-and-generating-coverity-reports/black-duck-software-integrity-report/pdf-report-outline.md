# PDF report outline

The PDF report explains the data provided by the contributing tools in graphs and tables.
Text is provided to clearly explain each category of data and the methodology of the
report. The report is divided into the following sections:

Product Results
:   Shows a high level summary of issues found by each contributing
    tool.

Coverity Summary
:   Shows the results in terms of CWE vulnerabilities, OWASP Top 10 issues, and CWE/SANS Top 40
    issues. A Methodology section explains the Coverity tools and issue
    categories.
