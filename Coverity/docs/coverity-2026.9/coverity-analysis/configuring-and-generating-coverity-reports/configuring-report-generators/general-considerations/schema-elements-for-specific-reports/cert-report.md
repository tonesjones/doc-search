# CERT Report

The CERT Report has an additional key for specifying and defining target levels:

| Key | Class Type | Description | Default | Required? |
| --- | --- | --- | --- | --- |
| `target-level` | String | Specifies the compliance standards for calculating the report. The following values are available:   - F: Fully Compliant - L2: L2 Compliant - L1: L1 Compliant | F | No |

For more information about the CERT report configuration, see the "CERT report configuration file".
