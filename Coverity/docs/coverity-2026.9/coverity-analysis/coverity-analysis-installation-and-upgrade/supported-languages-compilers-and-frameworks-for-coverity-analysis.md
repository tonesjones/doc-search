# Supported languages, compilers, and frameworks for Coverity Analysis

In order for Coverity to capture your code base, you must use a supported compiler. Supported
compilers are listed in this chapter. For a listing of supported Coverity features per
language, see the section "Coverity
language support" in the Coverity Analysis User and Administrator Guide.

In this chapter:

- C/C++ compilers
- C++23 (ISO/IEC DIS 14882:2023) language
  support
- C# compilers
- CUDA compilers
- Go compilers
- Java compilers
- Rust compilers
- Visual Basic compilers
- Third-party compilers
- Frameworks
