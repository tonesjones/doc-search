# Files without SCM data

It is possible that some files which are compiled when building your project will not
have SCM data associated with them. Most commonly, this occurs for one of the following reasons:

- The file was newly created, and has not yet been checked into SCM.
- The file belongs to the underlying operating system, or other related system files. For
  example, C++ templates for STL exist in system header files which are typically
  not under SCM control.
- The file was automatically generated by the build, and was not checked into SCM. For
  example, C sources generated using the `yacc` utility might not
  have SCM data if only the `yacc` grammar files are kept under
  SCM.
