# Finding third-party licenses

Coverity Analysis and Coverity Static Analysis for Java include
third-party software. For the terms of the associated licenses, see the files in the
<install_dir>/doc/licenses subdirectory. Some of this
software is covered by the Lesser GNU Public License (LGPL). Coverity will provide
materials on demand, including source code for components covered by the LGPL, as
required by the terms of the LGPL.
