# Using the Compiler Integration Toolkit (CIT)

The Compiler Integration Toolkit (CIT) consists of the following files in order to
construct a native compiler configuration:

- The compiler configuration file
- A compiler switch file
- Compatibility header
  files
- Custom translator script

In this section:

- Creating a Compiler Integration Toolkit (CIT) configuration for a new compiler
- Creating a compiler from an existing Compiler Integration Toolkit (CIT) implementation
