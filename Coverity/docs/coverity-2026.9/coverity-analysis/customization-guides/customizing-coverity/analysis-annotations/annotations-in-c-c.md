# Annotations in C/C++

This section describes Coverity Analysis annotations for C/C++ code.

For C and C++ code, there are three kinds of annotations:

- *Code-line annotations* modify the
  analysis of a particular line of code.
- *Function annotations*
  modify the analysis of a function.
- *Pragmas* are in-line
  annotations to note deviations from a compliance standard.
