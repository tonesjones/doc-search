# nullKind

Enumerates the possible values for a literal null pointer value.

## Details

The following values are defined:

| Name | Description |
| --- | --- |
| `` `0` `` | Zero |
| `` `NULL` `` | The value `NULL` |
| `` `nullptr` `` | The value `nullptr` (C++ only) |
