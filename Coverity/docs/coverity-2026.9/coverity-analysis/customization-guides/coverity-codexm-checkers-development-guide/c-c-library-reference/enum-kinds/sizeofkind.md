# sizeofKind

Specifies whether the operand passed to `sizeof()`
is an expression or a type.

## Details

The following values are defined:

| Name | Description |
| --- | --- |
| `` `sizeofExpr` `` | The operand is an expression. |
| `` `sizeofType` `` | The operand is a type. |
