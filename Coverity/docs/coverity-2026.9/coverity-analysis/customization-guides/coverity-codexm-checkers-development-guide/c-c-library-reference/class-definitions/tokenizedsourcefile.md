# tokenizedSourceFile

A source code file in token form.

## Properties

Every `tokenizedSourceFile` has the following properties:

| Name | Type | Description |
| --- | --- | --- |
| `isInSystemHeader` | `bool` | Whether the file is in a system header. |
| `tokens` | `list<token>` | The tokens that comprise this file. |
