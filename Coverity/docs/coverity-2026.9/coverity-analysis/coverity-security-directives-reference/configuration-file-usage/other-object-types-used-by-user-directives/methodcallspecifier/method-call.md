# method_call

A `method_call MethodCallSpecifier` explicitly names the method and an
input and output of that method.

## Fields

The `method_call MethodCallSpecifier` has the following fields:

`method_call`
:   Specifies a MethodName value.

`input`
:   Specifies a ParamIn value to pass to
    `method_call`.

`output`
:   Specifies a ParamOut value for
    `method_call` to return.
