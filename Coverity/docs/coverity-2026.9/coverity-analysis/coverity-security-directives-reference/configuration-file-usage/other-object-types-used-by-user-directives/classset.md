# ClassSet

**Used by these directives:**
`class_like_print_writer_for_servlet_output`

**Used by these objects:**
`MethodSet`

A `ClassSet` describes a set of classes from the program. You can specify
a `ClassSet` using one of the following field names:

- named
- matching
- with_super
- with_annotation
