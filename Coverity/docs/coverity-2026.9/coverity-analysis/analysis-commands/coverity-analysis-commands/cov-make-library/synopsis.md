# Synopsis

```
cov-make-library 
    [C/C++ standard related options]
    [--all]
    [--checker-option <option-setting>] 
    [--classpath <directories_or_jar_files>]
    [--compiler <compiler>] 
    [--compiler-opt <compiler_option>] 
    [--concurrency]
    [--disable <CHECKER>]
    [--disable-default]
    [--disable-webapp-security]
    [--enable CHECKER] 
    [--enable-cgo-for-go-models] 
    [--framework]
    [--make-dc-config]
    [--output-file <model-file>]
    [--quality] 
    [--reference <referenced_assembly>] 
    [--security] 
    [--security-file <license file>]  
    [--webapp-security] 
    [SHARED_OPTIONS]
    <sources>
```

**[SHARED_OPTIONS]**:

```
    [--config <coverity_config.xml>]  
    [--debug]
    [--ident]
    [--info]
    [--tmpdir <tmp>]
    [--verbose <level>]
```
