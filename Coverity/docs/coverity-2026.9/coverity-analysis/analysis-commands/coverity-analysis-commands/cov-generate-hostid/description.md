# Description

The `cov-generate-hostid` command outputs the host id information needed for
node-lock licensing. If you need assistance, please open a Support case by logging in to the [Black Duck Community site](https://community.blackduck.com/s/contactsupport).
You will need to provide the
output of the `cov-generate-hostid` command if you need help with licensing.
