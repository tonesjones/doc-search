# Synopsis

```
cov-import-results 
    --dir <intermediate-director> 
    [--append <filename>] 
    [--<lang>] 
    [--no-banner] 
    [--output-tag <name>] 
    [--strip-path <path>]
    [SHARED_OPTIONS]
```

**[SHARED_OPTIONS]**:

```
    [--debug]
    [--ident]
    [--info]
    [--tmpdir <tmp>]
```
