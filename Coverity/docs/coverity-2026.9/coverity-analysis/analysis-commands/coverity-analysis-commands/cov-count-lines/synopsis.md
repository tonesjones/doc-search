# Synopsis

```
cov-count-lines
    [--code-identity-file <filename>]
    [--file <filename>]
    [--list <file-list>]
    [--search <path>]
    [--search-extensions <list of extensions>]
    [--third-party-regex <regex>]
    [SHARED_OPTIONS]
```

**[SHARED_OPTIONS]**:

```
    [--debug]
    [--ident]
    [--info]
    [--tmpdir <tmp>]
    [--verbose <level>]
```
