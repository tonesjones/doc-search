# Synopsis

```
cov-extract-scm 
    --scm <scm_type>
    --output <output_file>
    --input <input_file> 
    [--get-baseline-code-version]
    [--get-modified-files]
    [--error-threshold <percentage>]
    [--get-baseline-code-version]
    [--get-modified-files]
    [--log <log_path>]
    [--ms-delay <int>]
    [--scm <scm_type>]
    [--scm-command-arg <command_arg>]
    [--scm-param]
    [--scm-project-root <root_path>]
    [--scm-tool <tool_path>]    
    [--scm-tool-arg <tool_args>]
    [SHARED_OPTIONS]
```

**[SHARED_OPTIONS]**:

```
    [--debug]
    [--ident]   
    [--verbose <level>]
```
