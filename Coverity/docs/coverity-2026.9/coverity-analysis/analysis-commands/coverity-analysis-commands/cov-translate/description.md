# Description

This feature translates the native compiler command line given and invokes the Coverity
compiler with the translated command line. The translation is done according to the
configuration generated by the `cov-configure` command.

Note: If you change the set of compilation options used by your build process, delete the
<intermediate_directory> and capture a full build from
scratch. Otherwise, the translation units captured using the old options will remain in
the emit. The new translation units will not replace the old translation units due to
the changed compilation options.
