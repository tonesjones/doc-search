# Synopsis

```
cov-import-scm 
    --dir <intermediate_directory>
    --scm <scm_type>
    [--error-threshold <percentage>]
    [--filename-regex <regex>]
    [--log <log_path>]
    [--ms-delay <int>]
    [--scm <scm_type>]
    [--scm-command-arg <command_arg>]
    [--scm-param]
    [--scm-project-root root_path]
    [--scm-tool <tool_path>]  
    [--scm-tool-arg <tool_arg>]  
    [SHARED_OPTIONS]
```

**[SHARED_OPTIONS]**:

```
    [--debug]
    [--ident]
    [--verbose <level>]
```
