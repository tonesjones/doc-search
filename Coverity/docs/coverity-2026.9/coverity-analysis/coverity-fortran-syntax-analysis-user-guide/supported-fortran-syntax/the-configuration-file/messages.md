# MESSAGES

In the section ”messages” you can redefine messages. You specify the numbers of the
messages which you want to suppress or of which you want to change the severity. Each
message number, followed by the severity level flag within apostrophes, must be
specified on a single record. See The usage of language extensions
for a precise description. You also can specify `suppress=’all’` to
suppress all diagnostic messages.
