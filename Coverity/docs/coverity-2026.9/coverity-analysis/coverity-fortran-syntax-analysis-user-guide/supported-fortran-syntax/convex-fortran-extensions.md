# Convex Fortran extensions

- The `VAX-FORTRAN` extensions are enabled by default (Convex
  Fortran `-vfc` option). To disable these options, or enable the
  Sun Fortran extensions, adapt the configuration file.
- The `INCLUDE` line and the `#include` preprocessor
  directive are supported.
- The `OPTIONS` directive is accepted, but the options specified
  will have no effect.
- The `C$DIR` compiler directive is treated as comment.
