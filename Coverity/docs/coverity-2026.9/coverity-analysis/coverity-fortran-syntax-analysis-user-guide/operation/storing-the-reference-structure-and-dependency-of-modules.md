# Storing the Reference structure and dependency of modules

Beside presenting the reference structure (call tree) and the dependency tree of modules in the
listing file Coverity Fortran Syntax Analysis can store the reference structure and the
module dependencies in XML format in separate output files by specifying a filename in
the IDE or enabling the reference structure and module dependencies file options. See
also Reference structure in XML format and Display of module dependencies in XML format.
