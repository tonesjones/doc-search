# Payload Parameters

Payload parameters are specified in the HTTP header using `--data`.

| Parameter name | Description |
| --- | --- |
| target_username | **Required.** The username of the new owner of the views whose ownership you want to reassign (the target user). |
| target_ldap | **Required.** Address of the LDAP server that authenticates the target user. |
