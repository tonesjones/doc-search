# Description

**HTTP Method:** GET

**URI format:**
`/api/viewContents/`{type}`/v1/`{view_id}`?projectId=`{string
or
num}[`&rowCount=`{num}][`&offset=`{num}][`&sortKey=`{string}][`&sortOrder=`[`asc`|`desc`]]

Retrieve the contents of the specified table view in Coverity Connect.
