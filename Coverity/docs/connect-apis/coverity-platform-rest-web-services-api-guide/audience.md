# Audience

This guide assumes that you are familiar with the key concepts of Coverity Platform and
that you have the following background:

- Knowledge of Web Services
- An understanding of REST
- An understanding of XML
- Knowledge of a language that supports REST Web Services

- Examples: Perl, Python, C/C++, Java, C#.

For more on Coverity Platform, see the *Coverity Platform User and Administration
Guide*.
