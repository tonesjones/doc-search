# Delete triage attribute

Example DELETE request to delete the specified triage attribute.

**cURL request**

```
curl -X 'DELETE' \
  'http://localhost:8080/api/v2/triageAttributes/bbb?locale=en_us' \
  -H 'accept: application/json'
```
