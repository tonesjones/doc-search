# Delete a triage store

Example DELETE request to delete the specified triage store.

**cURL request**

```
curl --location \
--request DELETE "http://localhost:8080/api/v2/triageStores/abc" \
--header 'Accept: application/json' \
--user my_username:my_password \
```
