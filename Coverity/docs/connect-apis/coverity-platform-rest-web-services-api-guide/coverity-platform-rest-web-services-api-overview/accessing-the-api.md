# Accessing the API

Accessing the API requires the "Access Web services" permission. For more information
about permissions and roles, see the *Coverity Platform User and Administrator
Guide*.

Queries are authenticated with HTTP Basic authentication, using the username and password or
authentication key for a Coverity Connect user.

Note: The password is visible to watchers if the HTTP protocol is used.
