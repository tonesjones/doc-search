# Overview

The Coverity Web Services API allows you write Web applications or scripts that
communicate with Coverity Connect database.

The API uses SOAP (Simple Object Access Protocol) to provide access to some of the
functionality of the server. Access includes the creation, deletion, retrieval, and
modification of various objects (such as users, projects, streams, and so on) in the
database. SOAP uses XML to format and transport messages to and from the server.

  
 [image: image]   

You need to create applications or scripts that support API requests and handle responses
from the database. See Getting Started for related information.
