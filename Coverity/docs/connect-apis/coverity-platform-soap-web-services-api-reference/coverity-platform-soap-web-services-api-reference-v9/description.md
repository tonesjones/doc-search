# Description

The Coverity Platform Web Services API allows you write Web applications that communicate
with Coverity Connect (part of the Coverity Platform installation). The API uses SOAP
(Simple Object Access Protocol) to send requests to the server and receive responses to
those requests.

This API reference is for the latest version of Coverity Connect. For details, see API history.
