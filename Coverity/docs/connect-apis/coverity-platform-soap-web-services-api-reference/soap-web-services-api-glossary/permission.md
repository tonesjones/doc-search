# permission

Access rule intended primarily for administrative tasks, such as server
configuration, user and group creation and management, and so forth. A permission is
assigned indirectly to a user or group through a role with which the permission is
associated. To retrieve a list of permissions, see getAllPermissions(). See also Permission
Values.
