# Complex type: attributeValueSpecDataObj

## Description

Specification that indicates whether an attribute value is deprecated.

## Derived by

Restricting anyType

## Content model

Contains elements as defined in the following table.

| Component | Type | Description |
| --- | --- | --- |
| [image: image] |  |  |
| deprecated | boolean | Value of *true* if the specified attribute value is deprecated. Otherwise, *false*. |
| name | string | Name of the attribute value. |
