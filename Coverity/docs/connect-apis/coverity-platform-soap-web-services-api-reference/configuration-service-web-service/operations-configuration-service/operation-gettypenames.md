# Operation: getTypeNames

## Name

getTypeNames

## Description

Returns a list of all known defect types, as localizedValueDataObj.

## Output (Literal)

The output of this operation is the argument getTypeNamesResponse having the
structure defined by the following table.

| Name | Type |
| --- | --- |
| return | localizedValueDataObj |
