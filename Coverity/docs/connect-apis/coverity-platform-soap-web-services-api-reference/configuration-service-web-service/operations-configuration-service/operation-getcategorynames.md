# Operation: getCategoryNames

## Name

getCategoryNames

## Description

Retrieve all known checker category names, as localizedValueDataObj.

The output of this operation is the argument getCategoryNamesResponse having the
structure defined by the following table.

| Name | Type |
| --- | --- |
| return | localizedValueDataObj |
