# Operation: getSystemConfig

## Name

getSystemConfig

## Description

Retrieves system configuration properties, including properties of the database with
which this API communicates.

## Output (Literal)

The output of this operation is the argument getSystemConfigResponse having the
structure defined by the following table.

| Name | Type |
| --- | --- |
| return | configurationDataObj |
