# Operation: getSignInConfiguration

## Name

getSignInConfiguration

## Description

Retrieve sign-in settings. These configurations are identical to Sign In Settings (a
set of System Configuration settings) in the Coverity Connect UI.

## Output (Literal)

The output of this operation is the argument getSignInConfigurationResponse having
the structure defined by the following table.

| Name | Type |
| --- | --- |
| return | signInSettingsDataObj |
