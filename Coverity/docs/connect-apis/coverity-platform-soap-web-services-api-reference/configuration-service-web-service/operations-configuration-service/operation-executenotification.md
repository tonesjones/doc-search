# Operation: executeNotification

## Name

executeNotification

## Description

Initiates a view notification to preconfigured recipients. The view must belong to
the user who calls this operation.

## Parameters

viewname
:   **Type:** string

## Remarks

For details, see the "Email notifications" section of the *Coverity Platform Use
and Administration Guide*.
