# Operation: getLdapServerDomains

## Name

getLdapServerDomains

## Description

Retrieves the host name or host IP of one or more LDAP servers.

## Output (Literal)

The output of this operation is the argument getLdapServerDomainsResponse having the
structure defined by the following table.

| Name | Type |
| --- | --- |
| return | serverDomainIdDataObj |

## Remarks

See createLdapConfiguration().
