# Language

| Programming Language | Description |
| --- | --- |
| MIXED | The stream can contain results from any programming language. This is the recommended and default setting. Other values exist only for backward compatibility. Please note: In the Coverity Connect "Projects & Streams" Configuration dialog, the "Any" element of the Language drop-down is equivalent to "MIXED" in the Web Services API. |
| CSHARP | C# |
| CXX | C and/or C++ |
| JAVA | Java |
| OTHER | Languages other than C, C++, C#, and Java. |
