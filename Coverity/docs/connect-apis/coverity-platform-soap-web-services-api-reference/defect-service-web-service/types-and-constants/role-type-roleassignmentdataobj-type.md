# Role type (roleAssignmentDataObj.type)

| Role Type | Description |
| --- | --- |
| component | For applying specifed roleId at the component level. Example: The built-in Developer role. |
| global | For applying specified roleId at the top (global) level. Example: The Roles assigned when creating or updating users or groups take place at this level. |
| project | For applying specified roleId at the project level. |
| stream | For applying specified roleId at the stream level. |
| triageStore | For applying specified roleId at the triage store level. |
