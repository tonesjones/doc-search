# Date time (dateTime)

Valid SOAP formats for this type can include the date and time, or omit the time.
When specifying the dateTime, you will need to use a format that is supported by
your SOAP client library. The following come from SOAP request and response examples
in this guide.

*Example1*:2013-03-19

*Example2*:

2013-03-19T14:40

*Example3*:2013-03-19T14:40:32.022-07:00

- Date = 2013-03-19
- Time = T14:40:32.022
- Time Zone (UTC) = -07:00
