# IDE and Java version support

Coverity Desktop supports the following IDE and Java versions.

Table 1. Supported IDE and Java versions

| IDE | IDE version | Java version | Notes |
| --- | --- | --- | --- |
| Visual Studio | 2019-2022 |  | **Deprecation notices:**   - Support for IntelliJ-based IDEs 2022.3 is deprecated as of 2024.6 and will be removed in a future release. - Support for Android Studio version 2022.1 is deprecated as of 2024.9 and will be removed in a future release. - Support for all JetBrains IDE's and Android Studio is deprecated as of 2024.12, Switch to the Black Duck Code Sight plugin for continued support and updates. - Support for Eclipse 2023-03 is deprecated as of 2026.3 and will be removed in a future release. - Support for Eclipse 2023-06 is deprecated as of 2026.6 and will be removed in a future release. - Support for OS platform macOS 14 has been deprecated as of 2026.6.0 and will be removed in a future release. |
| Android Studio | 2022.1-2023.3 | Embedded JRE |
| Eclipse | 2023-03-2026-03 | Java 8,11,17,21,24 |
| IBM Rational Team Concert (bundled with Eclipse) | 2021-09-2024-09 | Java 8,11 |
| ARM Development Studio 5 (bundled with Eclipse) |
| WindRiver WorkBench | 4.0-4.15 |
| QNX Momentics | 7.0 |
| Intellij IDEA | 2022.3-2024.1 | Java 8,11,17 |
| CLion |
| RubyMine |
| PyCharm |
| PHPStorm |

Note: The "Java Version" column indicates the Java version required for Coverity Desktop to
run in the IDE. For information regarding supported Java compilers, see Java compilers.
