# Coverity Desktop for Wind River Workbench on supported platforms

Coverity Desktop for Wind River Workbench is supported on the following platforms.

Table 1. Wind River Workbench Plug-in platform support

| Host OS | Host OS or kernel version | Host CPU | Vendor IDE and version | Supported languages | Notes |
| --- | --- | --- | --- | --- | --- |
| Windows | Windows workstation releases: Windows 11. Windows server releases: Windows Server 2020 and higher. | x86_64 | WindRiver WorkBench 4.0-4.15 | C/C++, Java | **Deprecation notices:**   - Support for WindRiver 4.0-4.14 is deprecated as of 2022.6 and will be removed in a future release. - Support for Win32 Coverity plugins has been deprecated as of 2025.6.0 and will be removed in a future release. |
| Linux | Linux Kernel as supported by the Coverity tools |
