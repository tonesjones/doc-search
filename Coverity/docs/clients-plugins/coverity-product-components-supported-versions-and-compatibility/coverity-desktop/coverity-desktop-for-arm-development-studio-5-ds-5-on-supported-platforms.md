# Coverity Desktop for ARM Development Studio 5 (DS-5) on supported platforms

Coverity Desktop for ARM Development Studio 5 (DS-5) version 5.22+ is supported on the
following platforms.

Table 1. DS-5 Plug-in platform support

| Host OS | Host OS or kernel version | Host CPU | Vendor IDE and version | Supported languages | Notes |
| --- | --- | --- | --- | --- | --- |
| Windows | Windows workstation releases: Windows 11. Windows server releases: Windows Server 2020-2022. | x86_64 | 2021-09-2024-09 | C/C++ | **Deprecation notices:**   - Support for Eclipse 2021-09 is deprecated as of 2024.9 and will be removed in a future release. - Support for Eclipse 2021-12 is deprecated as of 2024.12 and will be removed in a future release. - Support for Win32 Coverity plugins has been deprecated as of 2025.6.0 and will be removed in a future release. |
| Linux | Linux Kernel as supported by the Coverity tools |
