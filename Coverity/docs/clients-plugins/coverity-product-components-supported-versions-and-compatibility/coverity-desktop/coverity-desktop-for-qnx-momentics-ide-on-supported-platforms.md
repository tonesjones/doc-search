# Coverity Desktop for QNX Momentics IDE on supported platforms

Coverity Desktop for QNX Momentics IDE is supported on the following platforms.

Table 1. QNX Momentics Plug-in platform support

| Host OS | Host OS or kernel version | Host CPU | Vendor IDE and version | Supported languages | Notes |
| --- | --- | --- | --- | --- | --- |
| Windows | Windows workstation releases: Windows 11. Windows server releases: Windows Server 2020-2022. | x86_64 | QNX Momentics 7.0 | C/C++, Java, JavaScript, PHP, Python, and Ruby | **Deprecation notices:**   - Support for Win32 Coverity plugins has been deprecated as of 2025.6.0 and will be removed in a future release. |
| Linux | Linux Kernel as supported by the Coverity tools |
