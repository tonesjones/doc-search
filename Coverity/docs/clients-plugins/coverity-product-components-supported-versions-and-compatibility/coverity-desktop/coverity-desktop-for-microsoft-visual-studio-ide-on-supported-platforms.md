# Coverity Desktop for Microsoft Visual Studio IDE on supported platforms

Coverity Desktop for Microsoft Visual Studio IDE is supported on the following
platforms:

Table 1. Coverity Desktop for Microsoft Visual Studio IDE platform

| Host OS | Host OS or kernel version | Host CPU | Vendor IDE and version | Supported languages | Notes |
| --- | --- | --- | --- | --- | --- |
| Windows | Windows workstation releases: Windows 11. | x86_64 | Visual Studio 2019-2022 | C/C++, C#, Java, JavaScript, PHP, Python, and Ruby | **Deprecation notices:**   - Support for Win32 Coverity plugins has been deprecated as of 2025.6.0 and will be removed in a future release. |
