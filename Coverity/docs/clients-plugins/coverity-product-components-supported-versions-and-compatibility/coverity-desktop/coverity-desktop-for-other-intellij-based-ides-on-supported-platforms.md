# Coverity Desktop for other IntelliJ-based IDEs on supported platforms

Coverity Desktop for other IntelliJ-based IDEs (such as RubyMine, WebStorm, PyCharm,
PhpStorm, and CLion) is supported for the following platforms.

Table 1. IntelliJ-based IDE Plug-in platform support

| Host OS | Host OS or kernel version | Host CPU | Vendor IDE and version | Supported languages | Notes |
| --- | --- | --- | --- | --- | --- |
| Windows | Windows workstation releases: Windows 11. Windows server releases: Windows Server 2020-2022. | x86_64 | CLion 2022.3-2024.1 PhpStorm 2022.3-2024.1  PyCharm 2022.3-2024.1  RubyMine 2022.3-2024.1  WebStorm 2022.3-2024.1 | C/C++, Java, JavaScript, PHP, Python, and Ruby | **Deprecation notices:**   - Support for all JetBrains IDE's and Android Studio is deprecated as of 2024.12, Switch to the Black Duck Code Sight plugin for continued support and updates. - Support for Win32 Coverity plugins has been deprecated as of 2025.6.0 and will be removed in a future release. - Support for OS platform macOS 14 has been deprecated as of 2026.6.0 and will be removed in a future release. |
| Linux | Linux Kernel as supported by the Coverity tools |
| macOS | macOS 15-26 macOS ARM 15-26 |
