# Looking at individual issues

## To examine an issue in the source:

1. In the main application window, click the stream name in the upper left-hand corner.
2. Log in to Coverity Connect.

   Coverity Connect displays a window whose upper pane shows a list of the files that were scanned.
3. Click a file name in the list to display the file's source and flagged issues in the bottom pane.
