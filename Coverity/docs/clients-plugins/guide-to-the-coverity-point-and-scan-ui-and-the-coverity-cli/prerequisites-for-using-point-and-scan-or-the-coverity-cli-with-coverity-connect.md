# Prerequisites for using Point and Scan or the Coverity CLI with Coverity Connect

If you want to save results to the Connect server:

- You must be an authorized user.
- You must have permissions to do the following:
  - Access Web services
  - Create projects
  - Create streams
  - Commit to streams

For more information, see the Coverity Platform 2026.6.0 User and Administrator Guide.
