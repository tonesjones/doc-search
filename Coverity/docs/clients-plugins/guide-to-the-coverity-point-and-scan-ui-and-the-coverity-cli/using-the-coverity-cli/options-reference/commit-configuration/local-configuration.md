# Local configuration

Use these values to define your local configuration.

| Key | Type | Description |
| --- | --- | --- |
| `format` | string | The format in which to save defects. Must be either `"html"` or `"json"`. |
| `path` | string | Names the directory (for `"html"` format) or the file (for `"json"` format) where defects will be saved. |
