# Coding standard deviation

Use these values for the `deviations` key of the resolved coding
standard configuration field.

| Key | Type | Description |
| --- | --- | --- |
| `deviation` | string | **Required:** For C, C++, Java: The name of the rule to deviate from. |
| `reason` | string | **Required:** For C, C++, Java: The reason for the deviation from the rule. |
