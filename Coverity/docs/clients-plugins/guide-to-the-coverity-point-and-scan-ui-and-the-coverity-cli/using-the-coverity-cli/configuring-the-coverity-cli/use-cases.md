# Use cases

The sections that follow describe some typical configurations to use with the Coverity CLI, and how different kinds of users might want to take advantage of
such customization.

In this section:

- Specify 'clean' and 'build' commands
- Specify where to commit scan results
- Specify how to analyze a project
- Enable Web application security
- Enable mobile Java Android security
- Example: Finding MISRA standard deviations and customizing a checker
