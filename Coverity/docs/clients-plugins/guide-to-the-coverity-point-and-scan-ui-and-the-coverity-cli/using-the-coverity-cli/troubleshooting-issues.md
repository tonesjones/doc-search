# Troubleshooting issues

This section provides guidance on how to troubleshoot issues you might encounter when you use the Coverity CLI to scan a project.
It also describes the facilities that the CLI provides to assist with this.

The facilities provided by the CLI to specifically assist with troubleshooting are as follows:

1. The Coverity CLI `coverity list` command
2. The Coverity CLI diagnostics JSON document
3. The Coverity CLI log file
