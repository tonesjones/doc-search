# Coverity CLI commands

The following commands are used by the Coverity command-line interface (CLI).
The overall process is described in the Guide to the Coverity 2026.6.0 Point and Scan UI and the Coverity CLI.

- `coverity analyze`
- `coverity capture`
- `coverity commit`
- `coverity help`
- `coverity list`
- `coverity scan`
- `coverity setup`

Note:
If you enter `coverity` without specifying a subcommand,
the Coverity CLI prompts you to enter the name of the subcommand to run.
