# API reference

The Coverity Platform REST Web Services API is available [here](https://docs.blackduck.com/r/coverity/latest/coverity-documentation/coverity-platform-rest-api-reference.html) on the documentation portal.

For the Coverity Platform REST Web Services API Guide, see Coverity Platform 2026.6.0 REST Web Services API Guide.

The Coverity Platform Scan Proxy Service API is available [here](https://docs.blackduck.com/r/coverity/latest/coverity-documentation/coverity-platform-scan-proxy-service-api-reference.html) on the documentation portal.

For the Coverity Platform SOAP Web Services API Reference, see Coverity Platform 2026.6.0 SOAP Web Services API Reference. Note that support for the SOAP API has
been deprecated and will be removed in a future release.
