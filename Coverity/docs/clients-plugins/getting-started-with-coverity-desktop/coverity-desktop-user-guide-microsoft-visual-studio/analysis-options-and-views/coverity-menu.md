# Coverity menu

You can configure analysis options, retrieve remote issues, and run local analyses from
the Coverity menu.

Figure 1. Coverity menu
[image: image]

This menu contains the following menu items:

- View Issues
  from Coverity Server
- Capture Build of
  Solution
- Analyze [Current
  Editor File | Modified Files | Entire Scope]
- Go Offline
- Windows
- Analysis
  Configurations...
- Collect Diagnostics for
  Coverity Support
- Coverity Plugin User
  Guide
- Coverity Help
  Center

CAUTION:

Coverity Desktop requires you to analyze a
Project or Solution. If you open your code at the folder level, Coverity capture and
analysis will not succeed.
