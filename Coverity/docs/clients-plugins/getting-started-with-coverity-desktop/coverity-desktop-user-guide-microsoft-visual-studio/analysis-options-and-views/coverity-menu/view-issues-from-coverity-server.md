# View Issues from Coverity Server

This item will switch the Issues view to Remote
Issues mode, and populate it with relevant issues downloaded from Coverity Connect. These are the most recent issues in the central streams
specified in the active Analysis Configuration.

See Issues view for additional information on
Remote Issues mode.
