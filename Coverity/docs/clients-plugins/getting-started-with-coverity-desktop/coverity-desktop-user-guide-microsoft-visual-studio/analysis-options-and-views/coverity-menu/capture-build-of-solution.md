# Capture Build of Solution

This option will attempt to build all of the source files in your current solution (based
on the Visual Studio active solution configuration), and will capture the build under
Coverity monitoring. Build settings can be configured under Coverity > Analysis Configurations...

Note: It is not necessary for you to capture the build up-front, as you will be prompted to
capture any unbuilt files on demand when running local analyses.
