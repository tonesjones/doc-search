# Intermediate Directory Details view

This view displays information about the intermediate directory associated with the most
recent build of your project. To access this view, navigate to Coverity > Windows > Intermediate Directory Details.

Figure 1. Intermediate Directory Details menu
[image: image]

This view also gives you the option to delete the intermediate directory, or delete your
source code from the intermediate directory.
