# Context menu

When you right-click on an issue in the
Issues view, the context menu is displayed. From this menu,
you can use the following options:

Sort By
:   Select an attribute for sorting the list of issues.

Show Columns
:   Select which columns to display in the Issues
    view.

View in Coverity Connect
:   Displays the issue in Coverity Connect via your default
    browser. This option is not available when the issue is only present
    locally, or if multiple issues are selected.

Copy
:   Copies the currently selected row so you can paste it as a text string into
    an email message, bug report, and so forth.

Set attribute
:   Defines an attribute value for Classification, Severity, Action, and so
    forth. This is a quick way to triage your issue without having to use the
    Details view. You can select multiple issues and set the triage value for
    all of the selected issues at the same time. If a value is greyed out, that
    means it is an invalid value for the Issue
    Kind(s) of the selected issues.
