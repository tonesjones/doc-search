# Compiler Configuration dialog

Figure 1. Compiler Configuration
[image: image]

To use a custom compiler configuration, add each of your required compilers by completing
the following steps:

1. Click Add...
2. Choose a new configuration name for the compiler.
3. Choose the appropriate compiler from the  Compiler type
   dropdown menu.
4. In the Compiler executable field, enter the command line
   name of the compiler.

   Note: For a compiler like Wind River Diab C, which has both C and C++ variants, just enter the
   name of the C compiler. The C++ compiler will be configured
   automatically.
5. Click OK to add it to the list of configured
   compilers.
