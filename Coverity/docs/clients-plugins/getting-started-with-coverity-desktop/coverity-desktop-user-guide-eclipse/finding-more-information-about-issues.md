# Finding more information about issues

Issues are reported by specific checkers. Prevent Desktop provides information about the
checkers and the types of issues they find. You can view this information by
right-clicking the checker name or event in the Issues view and
selecting Show Checker Help.

A help view opens that shows information about the checker. You can follow the links in
the help view for more detailed information.
