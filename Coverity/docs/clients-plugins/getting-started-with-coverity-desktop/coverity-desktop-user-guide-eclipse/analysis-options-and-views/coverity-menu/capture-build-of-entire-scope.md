# Capture Build of Entire Scope

This option will attempt to build all of the source files in your current Analysis
Configuration's scope, and will capture the build under Coverity monitoring. Build
settings can be configured in the Analysis Configurations dialog.

Note that it is not necessary for you to capture the build up-front, as you will be
prompted to capture any unbuilt files on demand when running local analyses.
