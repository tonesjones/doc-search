# Issue information

The top of the Details view describes the category of the issue
discovered by the Coverity Analysis checker and provides a description
of the issue. It also provides a cross reference to the industry standard [Common
Weakness Enumeration (CWE)](http://cwe.mitre.org/index.html). CWE is extremely useful for further research on
the impact of your issue. It provides detailed descriptions and examples of the issue
type.
