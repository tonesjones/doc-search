# Requirements

Desktop Analysis runs on all of the platforms and compilers supported for use with Coverity
Analysis (see the Coverity 2026.6.0 Installation and Upgrade Guide), except AIX.

Desktop Analysis requires a minimum of 1.5 GB of RAM. We recommend at least 4 GB of RAM
and 4 processor cores.
