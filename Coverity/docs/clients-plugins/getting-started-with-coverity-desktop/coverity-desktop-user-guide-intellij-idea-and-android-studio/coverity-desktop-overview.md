# Coverity Desktop overview

Coverity Desktop is a supplemental Coverity Analysis
tool that allows you to view and manage issues in your source code within IntelliJ IDEA,
JetBrains CLion, or Android Studio. Depending on the development environment, it can
analyze Java, C/C++, or Android source.

Coverity Analysis results are displayed in the Coverity Desktop plug-in, allowing you to assess the risk, and fix
issues in the IDE. Analysis results from your code base are displayed in the Coverity Desktop plug-in to help you find and report hard-to-spot
software defects and potential security vulnerabilities.

Coverity Desktop provides two analysis modes:

- Central Analysis
- Local Analysis

After Coverity Desktop displays your issue data, you can view the
issues for your project marked directly in the IDE's code editor view. Coverity Desktop provides two views: Issues and Details. Use these
views to navigate through your issues, to determine the impact of the issues on your
code, and to manage and update (*triage*) the state of
each issue.

Installation instructions and supported platform details are located in the Coverity 2026.6.0 Installation and Upgrade Guide.

Note: To view issue information, such as event messages and so forth, in Japanese, Korean, or
Chinese, you must make sure that the locale is set for Japan, Korean or Simplified
Chinese, respectively, in your Coverity Connect user preferences. For
more information, see the Coverity Platform 2026.6.0 User and Administrator Guide.
