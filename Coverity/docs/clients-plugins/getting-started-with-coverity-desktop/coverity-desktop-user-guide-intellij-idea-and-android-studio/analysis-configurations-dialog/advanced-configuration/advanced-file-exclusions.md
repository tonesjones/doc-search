# Advanced: File Exclusions

Figure 1. Advanced: File Exclusions
[image: image]

The File Exclusions tab lists any files or filepath patterns that
should be excluded from local analysis. To add a file exclusion, click the
Add (+) button and enter the file path or glob pattern to
exclude.
