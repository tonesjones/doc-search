# Streams

The Streams tab allows you to specify any relevant streams for
which you want to view and triage remote issues, as well as select a reference stream
and snapshot for local analysis.

Figure 1. Streams tab
[image: image]

Stream list
:   Specifies the streams that contain issues you want to view and/or triage.
    Click the Add button to open the Select
    Streams dialog, which displays a list of all available
    streams for you to choose from.

    Note: All selected streams should use the same triage store.

Select File Path Mapping...
:   This will take you to the File Path Mapping tab.

Reference Stream
:   Select the reference stream that the analysis configuration will use for
    local analysis.

Select Reference Snapshot...
:   This will take you to the Reference Snapshot tab.
