# Coverity menu

You can configure analysis options, retrieve remote issues, and run local analyses from
the Coverity menu.

Figure 1. Coverity menu
[image: image]

This menu contains the following menu items:

- View Issues
  from Coverity Server
- Analyze [Current
  Editor File | Modified Files | Entire Scope]
- Analysis
  Configurations...
- Collect Diagnostics for
  Coverity Support
- Coverity Plugin User
  Guide
- Coverity Help
  Center
