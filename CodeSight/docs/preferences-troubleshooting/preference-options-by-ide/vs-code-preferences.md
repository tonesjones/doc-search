# VS Code Preferences

[image: image] In Code Sight, to see the scanning preferences for VS Code, in the STATUS view click the settings icon that appears to the left of the Code Sight Settings label, or click the label itself.

At the top of the Settings panel, Code Sight displays a list of commonly used preference settings.

Figure 1. Code Sight preferences in VS Code  
 [image: Preference shortcuts in the VS Code Settings panel]

Analysis Settings
:   Rapid Scan Static
    :   Installation Location
        :   Lets you configure a system-local location for the Rapid Scan Static engine.

Environment Variables
:   Configure environment variables in your IDE.

Proxy Settings
:   Enable Code Sight to run with a proxy server.

Export Logs
:   Displays a button for saving the Code Sight log, for debugging purposes.

    The link to display this panel appears on the HELP view.
