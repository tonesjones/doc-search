# Eclipse Preferences

In Code Sight, Eclipse provides several different preference settings.

Figure 1. Preferences icon and label for Eclipse  
 [image: Clickable Preferences icon and label in the Code Sight interface for Eclipse]

To access the preferences for Eclipse, click the icon or label that appear above the Code Sight views. Eclipse displays its Preferences dialog.

Tip: You can also open the Eclipse Preferences dialog from the menu bar. Opening the Eclipse Preferences dialog depends on the operating system you use.

- In macOS: On the menu bar, choose Eclipse → Settings or Preferences. (The name of the menu choice can depend on which version of macOS is running.)
- In Windows or Ubuntu: On the menu bar, choose Window → Preferences.

Figure 2. Preference choices for Eclipse  
 [image: Preference choices for Code Sight running in Eclipse]

Analysis Settings
:   Set preferences for locally installed scan engines.

Environment Variables
:   Configure environment variables in your IDE.

General Settings
:   Set preferences for telemetry data collection, UI colors, and keyboard shortcuts.

Proxy Settings
:   Enable Code Sight to run with a proxy server.

Server Settings
:   Authenticate servers for your scan engines.

Troubleshooting
:   Save a log file to help with troubleshooting issues.
