# Visual Studio Preferences

In Code Sight, Visual Studio provides several different preference settings.

Figure 1. Preferences icon and label for Visual Studio  
 [image: Clickable Preferences icon and label in the Code Sight interface for Visual Studio]

To access the preferences for Visual Studio, click the Preferences label that appears above the Code Sight views (the icon itself is not clickable). Visual Studio displays its Options dialog.

Figure 2. Preference choices for Visual Studio  
 [image: Preference choices for Code Sight running in Visual Studio]

Authentication
:   Authenticate scan engines or export error logs.

Sources
:   Displays the servers currently configured for remote (Team View) issues, and lets you edit the configuration.

Rapid Scan Static
:   Displays a panel that lets you choose a custom, local location for the Sigma (Rapid Scan Static) scan engine.

Rapid Scan SCA
:   Displays a panel that lets you choose a custom, local location for the Black Duck®
    Detect (SCA) scan engine.

Proxy Settings
:   Enable Code Sight to run with a proxy server.

Environment Variables
:   Configure environment variables in your IDE.

Other
:   Displays the Telemetry panel.
