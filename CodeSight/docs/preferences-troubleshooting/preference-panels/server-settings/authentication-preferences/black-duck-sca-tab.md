# Black Duck SCA tab

Displays controls for configuring a Black Duck SCA (Open Source Analysis) server.

## Email / User Name panel

Figure 1. Black Duck SCA server authentication tab for IntelliJ: Email / User Name panel
  
 [image: Black Duck authentication tab for IntelliJ showing Email / User Name panel]

Email / User Name
:   Enter the name you use to log in to the Black Duck SCA server that you use.

Server URL
:   Enter the URL of the Black Duck SCA server that you use.

Configure Proxy
:   Click to display the Proxy Settings panel and update the proxy for Code Sight to use, if any.

Change Credentials
:   When you have updated other settings on this tab, click Change Credentials
    to display a panel where you enter the password for the Black Duck SCA server you chose.

## Password panel

Figure 2. Black Duck SCA server authentication tab for IntelliJ: Password panel
  
 [image: Black Duck authentication tab showing Password panel]

1. Use controls on this panel to enter the password for your Black Duck server.
2. When you have done so, click Change Credentials once again.

   If the credentials are valid, Code Sight says so, and displays a thumbs-up icon.
3. Click Done to complete the setup.
