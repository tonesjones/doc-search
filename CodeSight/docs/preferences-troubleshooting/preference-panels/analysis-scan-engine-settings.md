# Analysis (scan engine) settings

The scan engine settings let you configure a system-local location for the Rapid Scan Static and Rapid Scan SCA engines. For VS Code and IntelliJ, the Rapid Scan Static settings also let you turn on analysis while you type.

The UI varies, depending on which development environment you use.

## In Eclipse, IntelliJ, and Visual Studio

In Eclipse, IntelliJ (and other JetBrains IDEs), and Visual Studio, there is a separate panel for each scan engine:

Rapid Scan Static
:   Takes you to the Rapid Scan Static panel.

Rapid Scan SCA
:   Takes you to the Rapid Scan SCA panel.

## In Visual Studio Code

In VS Code, go to Code Sight Settings > Analysis Settings > Rapid Scan Static > Installation Location. The Rapid Scan Static installation location (VS Code) tab appears.
