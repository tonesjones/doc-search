# Rapid Scan Static settings (Eclipse, IntelliJ, and Visual Studio)

These settings affect the Rapid Scan Static engine.

Figure 1. Rapid Scan Static settings for IntelliJ
  
 [image: Rapid Scan Static panel in IntelliJ]

## Local install location (Optional)

To specify a local installation, enter a path in the text field.

If a local installation is already specified, click Choose to change that path, and then click Open
to make the change take effect.

## Scan as you type (IntelliJ only)

In Auto Scan mode, analyze code as you type
:   When on, Code Sight runs a single-file Rapid Static scan interactively, while you
    are editing the source.

    Default: Off
