# General Settings Panel / Telemetry Panel

The General settings panel includes the check box for enabling Telemetry in Code Sight data collection.
For the Eclipse and JetBrains (including IntelliJ) IDEs, it also links to preferences for the particular IDE,
which include interface colors and keyboard shortcuts.

Figure 1. General settings panel (the IntelliJ interface)
  
 [image: Controls on the General settings panel]

Visual Studio displays a telemetry panel that shows only the Telemetry check box.
(The highlighting and keyboard shortcut options appear on the Preferences drop-down menu,
not in this dialog.)

[image: image] In VS Code, the check box for telemetry appears on
the STATUS → Code Sight Settings panel.
