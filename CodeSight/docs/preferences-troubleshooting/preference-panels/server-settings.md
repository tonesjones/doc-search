# Server Settings

Preferences for Eclipse and IntelliJ (as well as other JetBrains IDEs) have a Server Settings panel with
links to Authentication preferences and Sources configuration for products that run on a
server. For Visual Studio, there are individual Authentication and Sources links
in the Code Sight
preferences.

Issues configured with server settings appear in Team View: see
Viewing Polaris issues on the server and
Viewing Software Risk Manager issues on the server.
