# Rapid Scan Static installation location (VS Code)

To specify the location of the Rapid Scan Static engine for VS Code, use the Rapid Scan Static → Installation Location
link that appears below “Code Sight > Config: Settings” on the Settings tab.

The Rapid Scan Installation Location tab lets you specify where to find the Rapid Scan Static executable.

Figure 1. Rapid Scan Installation Location tab for Code Sight in VS Code
  
 [image: Tab in VS Code for setting the location of Rapid Scan Static]

Click Change to see a text field with a drop-down list, where you can specify a different location.
After you have done so, click Apply.
