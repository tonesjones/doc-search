# Code Sight Standard Edition

The Code Sight Standard Edition installs and runs two “Rapid Scan” engines:
Rapid Scan Static and
Rapid Scan SCA.

Each of the Rapid Scan engines runs locally.

Attention:
Rapid Scan SCA requires internet connectivity: Please see the section “Connectivity and the Standard Edition”
in QuickStart for the Code Sight Standard Edition.
