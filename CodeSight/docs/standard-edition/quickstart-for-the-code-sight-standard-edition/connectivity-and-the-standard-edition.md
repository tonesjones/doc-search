# Connectivity and the Standard Edition

The Code Sight Standard Edition (CSSE) requires Internet connectivity.

To obtain the latest security information, Code Sight uses the Internet to connect to the Black Duck Software, Inc. security knowledge base.

Before you run the CSSE, make sure that the allowlist/safelist of your system’s firewall accepts the following domain names:

| Domain |
| --- |
| api.keygen.sh |
| codesight.blackduck.com |
| kg-licassist.siglic.blackduck.com |
| repo.blackduck.com |

Note:
These domain names are endpoint addresses, and are not navigable (clickable) URLs.
