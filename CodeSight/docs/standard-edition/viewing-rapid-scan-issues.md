# Viewing Rapid Scan issues

Issues reported by the Rapid Scan engines are now uniformly displayed across all
supported IDEs in the **Local View** tab.

- For all IDEs (including Eclipse, JetBrains IDEs, Visual Studio, and VS
  Code):

  - Rapid Scan issues will appear in the Local View tab, offering
    comprehensive visibility into detected vulnerabilities and
    compliance issues.
