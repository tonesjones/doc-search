# View dependencies: Black Duck SCA

For component analysis issues, the Contributing Details view takes the form of a
*dependency tree* that shows *direct* dependencies leading to *transitive*
dependencies culminating in detected issues.

In VS Code, the LOCAL VIEW can also display the *dependency tree* for an issue.

The dependency tree shows *direct* dependencies leading to *transitive*
dependencies that culminate in detected issues.

To see the dependency tree for an issue, click the expansion arrow to the left of the issue’s entry.
