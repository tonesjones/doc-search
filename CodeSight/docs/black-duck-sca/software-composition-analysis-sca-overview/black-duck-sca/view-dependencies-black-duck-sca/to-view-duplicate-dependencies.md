# To view duplicate dependencies

By default, Code Sight displays a single level of dependencies for Black Duck SCA issues.
To adjust this level, you can update the Component Dependency Duplication Sensitivity setting in your Black Duck server.

For further detail, please see [About component dependency duplication](https://documentation.blackduck.com/bundle/bd-hub/page/ComponentDiscovery/DependencyDuplication.html).
