# Code Sight QuickStart for Black Duck SCA customers

Here is information to help you quickly get started using Code Sight, if you are a Black Duck SCA customer.

## 1. If necessary, prepare the configuration

Code Sight can run Black Duck SCA without initial configuration, but it is best to make sure that
certain requirements are met, and you might want to specify the particular build tools being used.

See Black Duck SCA setup considerations
and Build tools and package managers.

## 2. Install Code Sight on your own system

Black Duck Code Sight is available on the Marketplace site for the IDE that you use.

If you need more detailed information, see the installation instructions for that particular IDE:

- Installing Code Sight in IntelliJ
- Installing Code Sight in Eclipse
- Installing Code Sight in Visual Studio
- Installing Code Sight in Visual Studio Code

## 3. Authenticate Black Duck SCA

In the Black Duck SCA tile of the Products and Licenses panel,
click Enable Black Duck SCA.

[image: Products and Licenses panel displayed on startup]

Enable Black Duck SCA displays the authentication controls for Black Duck SCA.
For full details, see To authenticate Black Duck SCA within Code Sight.

## 4. If necessary, install Black Duck SCA

If Black Duck SCA is already installed on your system, you are ready to run it.

If Black Duck SCA was not already installed, then click Install in the Black Duck tile.

Figure 1. Authentication: Prompt to install Black Duck SCA
  
 [image: Authentication: Black Duck SCA installation]

Note:
Installing Black Duck SCA can take a little while.

## 5. Start using Code Sight

see Software Composition Analysis (SCA) overview.
