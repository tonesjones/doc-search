# Polaris with Code Sight

Black Duck Polaris™ Platform is a cloud-based platform that delivers highly scalable Static Application Security Testing (SAST) and Software Composition Analysis (SCA)
for your enterprise.

This section describes how to set up Polaris and how to view issues that it reports.

Polaris can run scans both locally and remotely.

Local
:   Polaris can run static analysis (SAST) scans for
    local projects. Polaris can also run Black Duck SCA scans for local projects.

    Local scan
    results are displayed in the Local View tab.

Remote
:   For remote scans, Polaris runs both static analysis (SAST) and source code analysis (SCA) scans in the cloud.

    Remote Polaris issues are displayed in Team View.

For further information about the Polaris platform, see the Polaris
[Product overview](https://documentation.blackduck.com/bundle/polaris/page/documentation/c_product-overview.html).
