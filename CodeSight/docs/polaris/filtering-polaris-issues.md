# Filtering Polaris Issues

In IntelliJ, other JetBrains IDEs, Visual Studio, and VS Code, you can filter the
Polaris issues displayed in Team
View. Additionally, in VS Code and IntelliJ (as well as other JetBrains
IDEs), you can filter issues in Local View.

## Filters Overview

The criteria available for filtering may vary based on the specific setup of the
Polaris server, so this page does not list all
possible options.

- In VS Code, this will display an editor tab for filtering issues on the
  server.
- In IntelliJ and other JetBrains IDEs, this will present a filter view for the
  server.
- In Visual Studio, a similar filter view will be shown.

## List of Filters

While viewing issues in Team View, clicking the **Filters** icon [image: image] will present you
with various filtering options, including:

- **Owner**: Filter issues based on the individual or team responsible for
  addressing them.
- **Tool Type**: Select issues based on the type of analysis tool used, such
  as Static Application Security Testing (SAST) or Software Composition
  Analysis (SCA).
- **Triage Status**: View issues by their current triage status, indicating
  whether they need to be fixed, have not yet been triaged, or have been
  dismissed.
- **Severity**: Assess issues based on their severity level, helping
  prioritize remediation efforts.
- **Policy Violations**: Identify issues related to compliance with specific
  policies, allowing for focused attention on areas of concern.
- **Standard**: Filter issues based on recognized standards or guidelines
  relevant to security vulnerabilities.
- **Category**: Group issues by broad categories that align with common
  vulnerability types or areas of concern.
- **Issue Type**: Classify issues based on specific types of vulnerabilities
  or code quality concerns.
