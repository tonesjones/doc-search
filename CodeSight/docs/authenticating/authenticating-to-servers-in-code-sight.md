# Authenticating to Servers in Code Sight

After you install Code Sight, the plug-in prompts you to authenticate to the Black Duck Software, Inc.
server that your company hosts.

Under most circumstances, a system administrator or a teammate will provide the login credentials for
the Black Duck server that your company uses.

If the product you chose is a Coverity Analysis or Black Duck SCA (Black Duck Detect) engine
that has not already been installed on your system, use the
Products and Licenses panel to install it.
