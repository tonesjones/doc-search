# Authenticating and installing: Products and Licenses panel

The first time you run Code Sight, it displays a configuration page that lets you
choose which Black Duck Software, Inc. servers to use for authentication.

Figure 1. Products and Licenses panel for IntelliJ, and Visual Studio
  
 [image: Code Sight Configuration page displayed on startup]

(Example from IntelliJ)

In the tile for the scanning tool you want to use, click the Enable link.
Code Sight opens the authentication page for the Black Duck Software, Inc.
server that your company uses.
For the Code Sight Standard Edition, click Start Free Trial.

A couple of controls are particular to the Eclipse, JetBrains, and Visual Studio IDEs:

- [image: image] Click to display the
  Authentication preferences panel for the Black Duck Software, Inc.
  server that your company uses.
- Configure a Proxy server

  A shortcut to the Proxy Settings panel of the Preferences dialog.
