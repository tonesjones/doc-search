# To add a scanning tool that has not yet been authenticated

To add a scanning tool in Eclipse, a JetBrains IDE (including IntelliJ), or Visual Studio, use the
Status view → Products and Licenses panel.
In VS Code, this is a tab that is accessible from the STATUS view.

Click the tile for the scanning tool that is not yet active—or in VS Code, click the tool’s
Enable button.

Code Sight displays the Authentication Required page once again, so you can add your
account name, your password, and (if the tool does not run standalone) the URL of the
server that the tool will use.
