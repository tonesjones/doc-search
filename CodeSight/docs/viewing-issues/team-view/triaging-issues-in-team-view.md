# Triaging issues in Team View

You can triage issues that appear in the Team View by using the Black Duck Software, Inc. application’s browser interface.

**To triage a remote issue:**

1. In the Team View, click to highlight the issue to dismiss.
2. [image: image] In the Issue Details panel, click View in Server or its icon.

   This opens a browser for the application concerned:
   Coverity Connect, Coverity on Polaris,
   Polaris, or the Software Risk Manager.
3. In the web browser, use the application’s native controls to triage the issue.

   For more information, see the [Coverity Platform
   User and Administrator Guide](https://documentation.blackduck.com/bundle/coverity-docs/page/webhelp-files/covplatform_start.html),
   [Understanding
   Coverity on Polaris](https://documentation.blackduck.com/bundle/coverity-on-polaris/page/topics/c_polaris-overview.html),
   [Polaris User Guide](https://documentation.blackduck.com/bundle/polaris/page/documentation/c_product-overview.html),
   or [Getting Started with Software Risk Manager](https://documentation.blackduck.com/bundle/srm/page/user_guide/Getting-Started/getting_started_with_software_risk_manager.html).

## Triaging remote Coverity Connect issues in Visual Studio

In Microsoft Visual Studio, when you highlight a remote Coverity Connect issue, the Issue Details panel shows
a link labeled Triage this issue.

Figure 1. Triage link for details of a remote Coverity Connect issue in Visual Studio
  
 [image: For Coverity Connect, issue details include a link to display the Visual Studio Triage panel.]

Click the link to display a Triage panel, which has triage controls that are
comparable to those you can use in Coverity Connect.
