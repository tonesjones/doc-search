# Manual / Project Scanning

In Local
View, when Manual
(or **Project** in VS Code) scanning is the active scan mode, you can click an icon to
launch a scan for an individual file or for the entire source project.

The controls for manual scanning are not available when auto-scan is active.

To launch a scan, choose a scan configuration and then click the SCAN icon.

**In your IntelliJ, Eclipse, and Visual Studio:**

- [image: image] Click the SCAN icon or label to launch a scan of the type you chose.
- [image: image] While a scan is running, the SCAN icon changes to a red square.
  You can click the red icon to cancel the scan.

**In VS Code:**

- [image: image] Click the SCAN icon to launch a scan of the type you chose.
- [image: image] While a scan is running, the SCAN icon changes to an icon with an X.
  You can click the X icon to cancel the scan.
