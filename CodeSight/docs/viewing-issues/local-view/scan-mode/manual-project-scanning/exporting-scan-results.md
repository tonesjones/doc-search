# Exporting Scan Results

The Code Sight IDE plugin for VS Code enables users to save and export scan results
for the following supported scan types: Black Duck SCA, Coverity SAST, and Rapid Scan
Static.

## Managing Scan Results

The most recent scan results for each scan type are automatically saved in JSON
format in the `<project>/.codesight/scan_results` folder upon
completion of the scan.

Users can export the scan results to a specified location on their system while in
**Local View**. To do this, click the **...** icon and select **Export
Scan Results**.
