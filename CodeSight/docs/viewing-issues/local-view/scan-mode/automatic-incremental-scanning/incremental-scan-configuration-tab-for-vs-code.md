# Incremental Scan Configuration tab for VS Code

The Incremental Scan Configuration tab lets you enable a couple of VS Code
options.

Figure 1. Incremental Scan Configuration tab
  
 [image: Options for Incremental Scan in VS Code]

Code Analysis (Rapid Scan)
:   Optionally, analyze your code in real-time as you type
    :   When on, Code Sight runs a single-file Rapid Static scan interactively, while you are editing the source.
        Default: Off

Snippet Analysis
:   Shows controls for enabling Snippet Analysis.

Agentic Code Analysis
:   Shows configuration options for Signal AI scans.
