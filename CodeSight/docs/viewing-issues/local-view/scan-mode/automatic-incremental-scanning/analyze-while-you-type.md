# Analyze while you type

IDEs that support auto-scan mode have the ability to analyze code interactively, while you type.

The option for enabling this depends on the IDE you run:

- **In JetBrains IDEs, including IntelliJ**:

  This option appears as an Analysis preference.
  See Analysis settings for Eclipse, IntelliJ, and Visual Studio.
- **In VS Code**:

  [image: image] While Automatic Scan is active,
  click the Open Automatic Scan Configuration icon at the upper-right corner of LOCAL VIEW, in order to display the
  Incremental Scan Configuration tab for VS Code. This lets you choose to have code analyzed while you type,
  and to enable Snippet Analysis.

Note: Eclipse and Visual Studio do not support interactive scanning.
