# Scan mode

The IDEs that support Local View let you choose a *scan mode*.

In IntelliJ (and its JetBrains variants) and Visual Studio, buttons let you choose the scan mode.

Figure 1. Scan-mode buttons in IntelliJ
  
 [image: Buttons to choose the scan mode in IntelliJ]

In VS Code, choose the scan mode by clicking the Mode entry
at the top of the LOCAL VIEW, and then using the drop-down menu that appears.

Figure 2. Scan-mode choices in VS Code
  
 [image: Menu to choose the scan mode in VS Code]

Use the buttons or the menu to choose between auto-scan or manual scan mode.

For more information, see the following:

- Automatic / Incremental scanning
- Manual / Project Scanning
