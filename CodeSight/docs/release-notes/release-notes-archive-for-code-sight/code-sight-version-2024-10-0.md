# Code Sight version 2024.10.0

The salient update to the 2024.10.0 release is that Code Sight is now a product of Black Duck Software, Inc.
For more details, please see the first bullet item that follows.

## Enhancements

- Code Sight is now a product of Black Duck Software, Inc.
  The existing Synopsys Code Sight marketplace entries will be removed on March 31, 2025.

  New Black Duck Code Sight marketplace entries are available now.
  See the Installing Code Sight topics,

  If you are already a Code Sight user, please follow the instructions posted on
  this Black Duck Community page:
  <https://community.blackduck.com/s/article/code-sight-black-duck-migration-instructions>
  to manually reinstall Code Sight so that you can receive future updates.

  Thank you for bearing with us during this transition!

  —The Code Sight team
- Customers who use an IP safelist should add repo.blackduck.com (34.149.5.115) to this.

  The sig-repo.synopsys.com site at its old IP (34.110.245.127) will continue to be available through February 2025.
- Code Sight Standard Edition customers who use an IP safelist should add kg-licassist.lic.blackduck.com (34.49.211.228) to this.

  The kg-licassist.siglic.synopsys.com site at its old IP (35.190.73.170) will continue to be available through March 2025.

Code Sight now supports the following development environments:

- Android Studio 2024.2.1
- Eclipse 2024-09 (4.33)
- VS Code 1.93 and 1.94

## Discontinued support

Support for the following development environments has been discontinued:

- VS Code 1.86 and 1.87

Support for the following development environments has been deprecated, and will be discontinued in a future release of Code Sight:

- VS Code 1.88
