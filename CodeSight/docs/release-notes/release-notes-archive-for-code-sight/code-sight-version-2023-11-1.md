# Code Sight version 2023.11.1

This hotfix release corrects a few bugs that were interfering with Code Sight use.

## Bug fixes

- Fixed an issue in Visual Studio where proxy settings could not be edited.
  UD-12806
- Fixed an issue in Visual Studio where saved tokens generated on systems using an SSO configuration were not correctly authenticating.
  UD-12805
- Fixed an issue where Code Sight was not launching in 2023.3 JetBrains IDEs.
  UD-12760
