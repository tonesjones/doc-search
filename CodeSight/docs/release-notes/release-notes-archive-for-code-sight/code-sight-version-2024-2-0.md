# Code Sight version 2024.2.0

For users of IntelliJ IDEA and other IDEs in the JetBrains family, this release adds filtering for remote Polaris issues displayed in Team View.

## Enhancements

- For users of IntelliJ and other JetBrains IDEs, Code Sight adds the capability to filter Polaris issues in Team View.
  Supported filters include Owner, Tool Type,
  and Triage Status.

Code Sight now supports the following development environments:

- VS Code 1.86

## Bug fixes

- Fixed a bug where, in Visual Studio, the dependency tree for Open Source Analysis would not display transitive vulnerabilities correctly.
  UD-12983

## Discontinued support

Support for the following development environments has been discontinued:

- VS Code 1.80

Support for the following development environments has been deprecated, and will be discontinued in a future release of Code Sight:

- VS Code 1.81 and 1.82
