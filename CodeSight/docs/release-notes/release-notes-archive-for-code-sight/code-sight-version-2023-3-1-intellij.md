# Code Sight version 2023.3.1 (IntelliJ)

This version is a hotfix that corrects a couple of issues with the plug-in in IntelliJ.

## Bug fixes

- Fixed a bug where in IntelliJ 2023.1, Code Sight would throw an exception on startup because a referenced icon had been removed from that IntelliJ version.
  UD-11444
- Fixed a bug where IntelliJ would sometimes hang on startup due to a race condition.
  UD-11428
