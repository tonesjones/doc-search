# Code Sight version 2023.1.0 (JetBrains and VS Code)

Release 2023.1.0 applies to Code Sight in the JetBrains IDEs (IntelliJ, PhpStorm, PyCharm, RubyMine, and WebStorm) and in Visual Studio Code.

For static Code Analysis scans in this release, the Filter controls are replaced by a new Remote scanning mode, which
reports issues found on the server (either Coverity Connect or Coverity on Polaris) but not locally. In addition, the Details panel for static
analysis issues no longer shows the icons for issue provenance or for launching a new scan.

## Enhancements

- In IntelliJ and VS Code, issues from the server are now displayed by the Remote mode and are no longer merged with issues found locally by IDE scans.

  The Details panel for static analysis issues no longer shows the Status line that included icons for issue provenance or for launching a new scan.
  Use the Code Analysis view to launch scans, and the new Remote mode to view issues that were saved on the server but not
  detected locally.
- As of this release, the Polaris server is known as *Coverity on Polaris* in order to distinguish this service from the *Polaris* analysis service in the cloud.
- The IntelliJ and VS Code IDEs now support code analysis of Kotlin source. This requires Coverity Analysis 2022.12.0 or a newer version.
- In IntelliJ and its variants, the user can specify the location of the Rapid Scan engines already installed locally.
  When using Auto mode, the user can also enable Rapid Scan while typing.
- For each manual scan run in IntelliJ or VS Code, all the commands that are executed for a scan are logged in real time in a file.
  For each command that is executed, the working directory, command line, standard output, standard error, and exit code of the command are logged in the file.
  This information is available in the file saved by Export Logs.
  It is also available via the Scan Details message that appears while a scan is running and after the scan completes.
- In IntelliJ and Visual Studio Code, Code Sight telemetry has been disabled for all users except for Code Sight Standard Edition (CSSE) trial users.

Code Sight now supports the following development environments:

- Eclipse 2022-09 (4.25).
- Version 2022.3 of the JetBrains IDEs (IntelliJ, PhpStorm, PyCharm, RubyMine, and WebStorm).
- VS Code 1.72 and VS Code 1.73.

Code Sight now supports the following Black Duck product versions:

- Black Duck 2022.10.
- Coverity Analysis and Coverity Connect 2022.12.0.

Code Sight now supports the following platforms:

- macOS 13

## Bug fixes

- Fixed a bug where Code Sight would fail to start properly in IntelliJ 2022.3 and the other 2022.3 JetBrains IDEs on Windows.
  UD-10713
- Fixed a bug where IntelliJ and the other JetBrains IDEs would not refresh the Issues list after triage was applied to an issue.
  UD-10663
- Fixed a bug for IntelliJ and the other JetBrains IDEs, where Rapid Scan Static would sometimes scan the parent directory of the project instead of the current project.
  UD-10575
- Fixed an issue where if a `compiler_config_file` field was specified in coverity.conf, this information was not being passed
  to `cov-build` during build capture.
  UD-10416
- Fixed an issue where the Eclipse plug-in certificate had expired. It is now signed with a valid certificate.
  UD-10310
- Fixed a problem where issues detected by local scans could be mistakenly labeled “Location not confirmed”.
  UD-10241
- Fixed problems where multiple issue reports generated by automatic Rapid Scan Static scans would contain redundant data.
  UD-10199, UD-10517

## Discontinued support

Support for the following development environments has been discontinued:

- VS Code 1.65, 1.66, and 1.67

Support for the following development environments has been deprecated, and will be discontinued in a future release of Code Sight:

- Eclipse 2020-03 (4.15) through 2020-12 (4.18)
- JetBrains version 2021.1 (IntelliJ, PhpStorm, PyCharm, RubyMine, and WebStorm)
- VS Code 1.68, 1.69, and 1.70

Support for the following Black Duck product versions has been discontinued:

- Black Duck 2021.2.0
- Coverity and Coverity Connect 2021.03

Support for the following Black Duck product versions has been deprecated, and will be discontinued in a future release of Code Sight:

- Coverity and Coverity Connect 2021.06

Support for the following platforms has been discontinued:

- macOS 10.15
