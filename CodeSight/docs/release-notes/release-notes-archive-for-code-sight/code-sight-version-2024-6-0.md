# Code Sight version 2024.6.0

The main update for this release is enhancing the number of criteria for filtering Polaris issues.

## Enhancements

- For Polaris issues displayed in Team View, filtering now supports more criteria.
  In addition to the filters supported before (Owner, Tool Type, and Triage Status), you can now filter issues by
  Severity, Standard, Category, and Issue Type.
- In Eclipse, the Code Analysis view (static analysis) no longer has an Auto mode.

## Bug fixes

- Fixed a bug where out-of-date messages were displayed in the Notifications tab and did not work correctly.
  UD-13430

## Discontinued support

Support for the following development environments has been discontinued:

- Eclipse 4.24 (2022-06)
- IntelliJ (and other JetBrains IDEs aside from CLion) 2022.2

Support for the following development environments has been deprecated, and will be discontinued in a future release of Code Sight:

- VS Code 1.85
