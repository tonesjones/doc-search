# To uninstall the Code Sight plug-in from Eclipse

You can uninstall Code Sight whenever you wish.

1. In Eclipse, locate the About Eclipse dialog. This depends on the
   operating system you use. 

   - In macOS: On the menu bar, choose Eclipse →
     About Eclipse.
   - In Windows or Ubuntu: On the menu bar, choose Help →
     About Eclipse IDE.
2. In the *About Eclipse IDE* dialog, click Installation
   Details.
3. In the *Eclipse IDE Installation Details* dialog, scroll to locate the entry or
   entries for Black Duck
   Code Sight. If there is a single entry, click to highlight
   it. If there are two, then click and Cmd+click (macOS) or Ctrl+click (Windows) to
   highlight both.
4. At the bottom of the dialog, click Uninstall.
5. In the Uninstall dialog, click Finish.
6. As you did when you installed the Code Sight plug-in, when prompted
   click Restart Now to restart Eclipse so the change will take
   effect.
