# Prerequisites for installing Code Sight in Eclipse

Before you install the Black Duck Code Sight plug-in for Eclipse, you
should make sure your system is ready for it.

You should already have installed the following software:

- A supported version of Eclipse

  You can download Eclipse from
  <https://www.eclipse.org/downloads/>.

  Important:
  Eclipse C/C++ Development Tooling (CDT) is required to install Code Sight in Eclipse. If a connection to the Internet is open,
  Eclipse automatically downloads this dependency. If no Internet connection is available, please manually download and install the
  correct version of CDT for the version of Eclipse that you run.
  You can find CDT information and downloaders at <https://projects.eclipse.org/projects/tools.cdt>.
- A code project to work with

  For languages that Code Sight supports in this IDE, please see the
  Code Sight Support Matrix.

For information about managing which scan engines have been installed and authenticated, please see
Authenticating and installing: Products and Licenses panel and
Adding or removing a scanning tool from your Code Sight configuration.
