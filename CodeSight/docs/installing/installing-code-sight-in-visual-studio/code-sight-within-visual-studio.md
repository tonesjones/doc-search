# Code Sight within Visual Studio

Once installed in Visual Studio, the Code Sight interface appears in a few panels.

  
 [image: Code Sight controls inside Visual Studio]   

- In the code editor, icons indicate lines that have Code Analysis (SAST) issues or other findings.
  A line of code that has an SAST issue is highlighted and commented.
  Click More to see a pop-up panel that provides more detail.
- The status of running jobs is displayed in a panel of its own.
- The Code Sight view has various panels that appear at the bottom of the Visual Studio window.

Tip:
If you don’t see a Code Sight panels in the Visual Studio interface, go to the menu and choose
View → Other Windows and then click one of the
Black Duck Code Sight entries to choose the panel you want to see displayed.

## Details for SAST issues

To see issue details in Visual Studio, click the More link
that appears at the end of the code-line highlight.
