# Code Sight within IntelliJ

Once installed in IntelliJ, the Code Sight interface appears in a few panels.

  
 [image: Code Sight controls inside IntelliJ]   

- In the code editor, icons next to line numbers show Code Analysis (SAST) issues and other findings.
  Lines of code that have SAST issues are highlighted and commented.
- A number of tabs appear at the bottom of the IntelliJ window.
  - The Code Sight tab switches to the Code Sight display.
  - The Contributing Details tab switches to a display of details or dependencies for a particular issue, if one is selected.
    The Contributing Details display is a panel of its own.
