# Installing Code Sight

Here are instructions for installing Code Sight in the officially
supported development environments.

The Code Sight plug-in, or *extension,* is available for a number of integrated
development environments (IDEs). A particular IDE can run on one or more platforms; currently
supported platforms include Linux™, macOS®,
and Microsoft® Windows®.

Note:
Certain environments might be supported only in beta: For current information, see
Code Sight Release Notes and Known Issues.
