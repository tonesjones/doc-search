# To clean up the Code Sight configuration files (Visual Studio Code)

Code Sight saves information in a folder with a number of configuration files. After
you uninstall the plug-in, you might want to remove this.

Remove the Black Duck desktop/ folder.
The default location of this directory/folder depends on the operating system you are using.
See the following table:

| Platform | Location of Desktop directory/folder |
| --- | --- |
| Linux or Mac | /Users/<username>/.blackduck/desktop/ |
| Windows | C:\Users\<Username>\AppData\Roaming\BlackDuck\desktop\ |

Some sites might install the desktop\ folder in a custom location.
If it is not in the default location shown here, consult your system administrator.
