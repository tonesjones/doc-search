# To install the Code Sight extension in Visual Studio Code

You can install the Code Sight extension for Visual Studio Code via the web.

Make sure you have installed Visual Studio Code, along with a code project to analyze.

Attention: The steps to install Code Sight as an extension to Visual Studio Code are
*not the same* as the steps to install the Code Sight extension within Microsoft Visual Studio.

Note:
You can read through this page, or you can watch a brief
[interactive lesson](https://www.iorad.com/player/2157043)
about how to install Code Sight in VS Code.

1. Start Visual Studio Code.
2. [image: Extensions button for Visual Studio Code]  In the activity bar at the left of the VS Code window, click the Extensions button.
3. In the side bar → EXTENSIONS view, enter `code sight (security)` in the search field to locate the Code Sight extension.

   Tip:
   You can also find the Code Sight extension by searching the Visual Studio Code Marketplace,
   <https://marketplace.visualstudio.com/vscode>.
   The direct link to the Marketplace page for Code Sight is <https://marketplace.visualstudio.com/items?itemName=blackduck.code-sight-vscode>.
4. Click the Black Duck Code Sight entry to highlight it, and then
   click Install. 

   The VSIX installer installs the extension.
5. [image: image] In the left-hand sidebar, click the icon with the Black Duck logo
   to see the Code Sight controls and begin scanning your code.
