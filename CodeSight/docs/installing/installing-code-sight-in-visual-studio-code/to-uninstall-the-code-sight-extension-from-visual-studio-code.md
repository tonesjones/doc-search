# To uninstall the Code Sight extension from Visual Studio Code

You can uninstall Code Sight whenever you wish.

1. In Visual Studio Code, return to the extension controls by clicking the Extensions button.

   Figure 1. Extensions button
     
    [image: VS Code Extensions button]
2. In the side bar EXTENSIONS: INSTALLED view, click to highlight the Code Sight (Security) entry.

   Figure 2. Code Sight entry in the side bar
     
    [image: Disable and Uninstall buttons for Code Sight]
3. In the Code Sight (Security) panel, click the Uninstall button.

   [image: Uninstall button for Code Sight]

   The button area now displays a button labeled Restart Extensions.

   [image: Restart Extensions button]
4. Click Restart Extensions.

   This completes the uninstall by reloading VS Code.
