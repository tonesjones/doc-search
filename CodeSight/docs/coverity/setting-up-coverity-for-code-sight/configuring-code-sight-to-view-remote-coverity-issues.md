# Configuring Code Sight to view remote Coverity issues

To view remote issues, use Team View.

To configure Code Sight for viewing remote Coverity issues, there are a few steps to follow:

1. Specify a Coverity server when you authorize Coverity, or when you edit the server preferences.
   See Coverity on Polaris / Coverity Connect tab.

   Figure 1. Coverity server authentication tab for IntelliJ: Email / User Name panel
     
    [image: Coverity authentication tab showing Email / User Name panel]
2. After you have specified the server and your authentication key or password, click Configure Source.
3. In the Sources panel, click to highlight your Coverity server.
4. [image: image] Click the Edit icon.
5. In the Select a Source dialog, click to choose a Project and then a Stream whose issues you want to view.

   Figure 2. Select a Source for a Coverity server
     
    [image: 'Select a Source' dialog for Coverity sources in Team View]
