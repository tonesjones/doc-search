# Coverity Analysis

Coverity® Analysis is one of the engines that Code Sight can run to perform static analysis.

Compared to Rapid Scan Static, Coverity Analysis is meant to be comprehensive and detailed.

The Coverity solution includes both a static analysis engine, provided by Coverity Analysis, and management tools,
provided by either Coverity Connect or Coverity on Polaris.
The analysis engine scans your code and flags issues.
Management tools allow you to store results, to triage them, to fine-tune the testing configuration, to monitor trends, and to produce reports.
