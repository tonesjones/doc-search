# Contributing Details: Coverity (SAST)

For static analysis issues, the Contributing Details view shows the events in the execution
sequence that led up to the issue that was reported.

Figure 1. Contributing Details view for static analysis
  
 [image: Contributing Details view, static-analysis issues]

To see this view, click the Contributing code events > Open link
in the Issue Details panel.

Figure 2. Link to open the Contributing Details view
  
 [image: Link to open Contributing Details view]

Tip:
Depending on the IDE you are using, you might be able to show the Contributing Details view by using the
view or window controls as well as the Issue Details panel.
