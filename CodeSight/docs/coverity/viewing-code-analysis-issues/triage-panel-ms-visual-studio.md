# Triage panel (MS Visual Studio)

In Visual Studio, when you highlight a remote Coverity Connect issue in the Team View, Code Sight displays a
Code Sight Triage panel that lets you triage the issue.

Figure 1. Triage panel for issues in Coverity Connect
  
 [image: Screen shot of Triage panel in Team View]

If at first you don’t see the Triage panel, then in the Issue Details panel, you can click Triage this issue.

The Action drop-down menu lets you choose how to manage the issue.

The Triage panel supports all the fields that are available in the Coverity Connect interface,
including custom attributes.

The History section of the Triage panel shows actions that have previously been taken for this particular issue.
