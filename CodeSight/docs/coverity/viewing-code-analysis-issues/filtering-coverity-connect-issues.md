# Filtering Coverity Connect issues

In IntelliJ and in Visual Studio Code, you can filter the issues that a Coverity Connect server displays in Team View.

The criteria used for filtering can vary depending on the setup of the particular Coverity Connect server,
so this page does not enumerate the choices shown in the illustrations.

[image: image] while the Team View
is displaying issues from a Coverity Connect server, clicking the Filters icon displays an editor tab.
