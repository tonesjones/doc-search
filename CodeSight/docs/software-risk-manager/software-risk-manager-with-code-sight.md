# Software Risk Manager with Code Sight

Black Duck®
Software Risk Manager™ (SRM) is a complete *application security posture management* (ASPM) solution.
SRM enables you to set up policy-driven workflows to orchestrate application-security test tools like Coverity and Black Duck,
prioritize issues, and monitor compliance across your software assets.

This section describes how to set up the Software Risk Manager and how to view issues that it reports.

For more information about the Software Risk Manager, see the
[Getting Started with Software Risk Manager](https://documentation.blackduck.com/bundle/srm/page/user_guide/Getting-Started/getting_started_with_software_risk_manager.html).
