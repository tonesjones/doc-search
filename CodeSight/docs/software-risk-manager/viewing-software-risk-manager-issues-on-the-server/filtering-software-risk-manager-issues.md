# Filtering Software Risk Manager issues

In VS Code, you can filter the issues that a Software Risk Manager server displays in Team View.

The filters are available for Software Risk Manager 2024.3.0 and later releases.

The criteria used for filtering can vary depending on the setup of the particular Software Risk Manager server,
so this page does not enumerate the choices shown in the illustration.

[image: image] while the Team View
is displaying issues from a Software Risk Manager server, clicking the Filters icon displays an editor tab.
