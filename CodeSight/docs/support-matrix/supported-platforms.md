# Supported Platforms

These are the platforms on which Code Sight can run.

| Operating System | Versions |
| --- | --- |
| Linux (AMD64) | All Linux variants supported by the host IDE (Code Sight is now tested on Ubuntu® 22 and 24). |
| macOS (AMD64, ARM64) | 15, 26 |
| Windows (AMD64) | Windows 11 |

All supported IDEs can run on Windows, Linux, or macOS, except for Microsoft Visual Studio, which runs only on Windows.
