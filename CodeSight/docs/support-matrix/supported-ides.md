# Supported IDEs

These are the IDEs in which Code Sight™ can run,
and the platforms that support them.

| IDE | Versions | Platforms |
| --- | --- | --- |
| Android™ Studio | 2023.1.1 – 2025.1.1 | Windows®, Linux™, macOS® |
| CLion™ | 2023.2 – 2026.1 | Windows, Linux, macOS |
| Cursor™ | Based on supported versions of VS Code | Windows, Linux, macOS |
| Eclipse™ | 2023-09 (4.29) – 2026-06 (4.40) | Windows, Linux, macOS |
| GoLand™ | 2025.1 – 2026.1 | Windows, Linux, macOS |
| Google Antigravity | Based on supported versions of VS Code | Windows, Linux, macOS |
| IntelliJ® IDEA | 2023.2 – 2026.1 | Windows, Linux, macOS |
| Kiro | Based on supported versions of VS Code | Windows, Linux, macOS |
| Microsoft® Visual Studio® | Visual Studio 2017: release 15.8 and greater  Visual Studio 2019: release 16.3 and greater  Visual Studio 2022: release 17.1 and greater  Visual Studio 2026: release 18.0 and greater | Windows |
| Microsoft Visual Studio Code™ | 1.94 – 1.137 | Windows, Linux, macOS |
| PhpStorm™ | 2023.2 – 2026.1 | Windows, Linux, macOS |
| PyCharm™ | 2023.2 – 2026.1 | Windows, Linux, macOS |
| Rider™ | 2025.1 – 2026.1 | Windows, Linux, macOS |
| RubyMine™ | 2023.2 – 2026.1 | Windows, Linux, macOS |
| WebStorm™ | 2023.2 – 2026.1 | Windows, Linux, macOS |
| Windsurf™ | Based on supported versions of VS Code | Windows, Linux, macOS |

Note:

- We support Cursor, Kiro, Google Antigravity, and Windsurf versions that are
  based on currently supported versions of VS Code. We do not test these IDEs
  with every release; support is based on our testing with VS Code.
- We do not test all JetBrains IDEs with every release. Support is based on our testing with IntelliJ IDEA.
