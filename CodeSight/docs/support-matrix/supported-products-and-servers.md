# Supported Products and Servers

These are the Black Duck Software, Inc. products and servers that Code Sight supports.

| Product or Server | Versions |
| --- | --- |
| Black Duck SCA | Black Duck SCA versions more recent than those listed in the End of Support column on the [“Product Maintenance, Support, and Service Schedule”](https://documentation.blackduck.com/bundle/blackduck-compatibility/page/topics/Support-and-Service-Schedule.html) page. |
| Coverity Analysis (SAST) | Coverity versions shown as supported on the [“Coverity product components: supported versions and compatibility”](https://documentation.blackduck.com/bundle/coverity-docs/page/deploy-install-guide/topics/coverity_product_components_supported_versions_and_compatibility.html) page. |
| Coverity Connect (SAST) |
| Coverity on Polaris Software Integrity Platform (SAST)™ | The most recent cloud-hosted version of Coverity on Polaris |
| Polaris | The most recent cloud-hosted version of Polaris |
| Rapid Scan Static for the Standard Edition and Coverity (SAST) | The current Sigma version as shown on the Sigma [“Support Matrix”](https://documentation.blackduck.com/bundle/sigma-ug/page/topics/support/support-matrix.html) pages. |
| Rapid Scan SCA for the Standard Edition and Black Duck (SCA) | Black Duck® Detect version 11.0 through the most recent version listed in the [Black Duck Artifactory](https://repo.blackduck.com/artifactory/bds-integrations-release/com/blackduck/integration/detect/). |
| Software Risk Manager | 2023.4.5 and more recent versions. See [Software Risk Manager Install and Deployment Options](https://documentation.blackduck.com/bundle/srm/page/install_guide/Installation/deployment_options.html) for further details. |
| Black Duck Detect | Black Duck Detect versions as shown on the [Black Duck Release Compatibility](https://documentation.blackduck.com/bundle/blackduck-compatibility/page/topics/Black-Duck-Release-Compatibility.html) page. |
| Black Duck Signal | Most recent version of [Signal](https://documentation.blackduck.com/bundle/signal/page/topics/c_signal_overview.html) |

Note:
Black Duck®
Detect is the executable that powers both Black Duck SCA and Rapid Scan SCA.
Sigma is the executable that powers Rapid Scan Static.
(Sigma does not power Coverity Analysis, but Coverity Analysis does run certain Sigma checkers).

Attention:
**Polaris users:**

You must upgrade Code Sight to version 2025.4.0 or a later version by September 15, 2025.
Failure to upgrade will result in an inability to interact with Polaris.

For more information, please see
