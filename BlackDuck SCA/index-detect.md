# Black Duck Detect Documentation

This is the default entry point for unversioned Detect questions.

## Default: Detect 12.0.0

Use the [Detect 12.0.0 catalog](index-detect-12.0.0.md) and `docs/detect-12.0.0/` unless the question explicitly names another Detect version.

## Historical: Detect 11.5.1

Use the [Detect 11.5.1 catalog](index-detect-11.5.1.md) and `docs/detect/` only for an installed 11.5.1 environment or an explicit version comparison.

## Version comparison

For a 11.5.1-to-12.0.0 question, start with the [generated comparison](index-detect-11.5.1-to-12.0.0.md), then inspect the linked 12.0.0 release notes and paired topics.
