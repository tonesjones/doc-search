# Editing a custom field

For all custom fields, you can edit the label, description, and the designation whether
this custom field is required. For drop down, single, and multiple selection custom
fields, you can:

- rearrange the order of options
- edit existing options
- add new options

Edits made to options will propagate to any policies.

Note that you cannot change the type of custom field once it has been created. For
example, suppose you created a multiple selections custom field. If, after you created
the field, you want to change that custom field to a single selection custom field, you
must create a new custom field.

To edit a custom field:

1. Click [image: image] and then
   select **Custom Fields**.

     
    [image: Custom Fields page]
2. Select the tab which contains the custom field you want to edit.
3. Click [image: Options] and select **Edit** in the row of the custom field.
4. In the Edit Custom Field dialog box, modify the custom field, and click
   **Save**.
