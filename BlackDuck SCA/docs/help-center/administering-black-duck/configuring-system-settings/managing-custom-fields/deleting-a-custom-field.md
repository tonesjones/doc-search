# Deleting a custom field

Deleting a custom field removes the custom field and all data associated with it.

Note: You can deactivate a
field so that it retains its data but no longer appears to your end
users.

You must have the system administrator role to delete a custom field.

To delete a custom field:

1. Click [image: image] and then
   select **Custom Fields**.

     
    [image: Custom Fields page]
2. Select the tab which contains the custom field you want to delete.
3. Click [image: Options] and select **Delete** in the row of the custom field.
4. In the Delete Custom Field dialog box, confirm that you have selected the correct
   custom field to delete, and click **Delete**.
