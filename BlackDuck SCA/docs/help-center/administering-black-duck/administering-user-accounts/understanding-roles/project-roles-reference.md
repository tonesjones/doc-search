# Project Roles Reference

Project roles apply only to the projects to which a user has been assigned.
These roles provide access to project-specific activities such as BOM
management, vulnerability remediation, policy review, reporting, and project
administration.

| Role | Description | Key capabilities |
| --- | --- | --- |
| Project Administrator | Provides administrative access to assigned projects. | Manage project versions, manage project membership, manage project settings, manage tags, run and delete reports. |
| Project Manager | Provides full management access to assigned projects. | Manage BOMs, project versions, project membership, reports, comments, policy violations, and vulnerability remediation. |
| Project Viewer | Provides read-only access to assigned projects. | View project information, view BOMs, run reports, and add comments. |
| Project Code Scanner | Manages scans for assigned projects. | Upload, map, unmap, and delete scans; create project versions. |
| BOM Manager | Manages BOM content for assigned projects. | Modify BOM data, manage component identifications, update review status, manage licences, add comments, and run reports. |
| BOM Annotator | Updates BOM annotations and component metadata. | Add comments and update BOM component custom fields. |
| Security Manager | Manages vulnerability remediation activities. | Modify vulnerability remediation information. |
| Policy Violation Reviewer | Reviews and approves policy overrides. | Override policy violations and remove overrides. |
