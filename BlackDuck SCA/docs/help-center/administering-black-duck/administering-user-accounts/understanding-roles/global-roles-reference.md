# Global Roles Reference

Global roles grant permissions across the entire Black Duck SCA
environment. These roles are typically assigned to users who administer Black Duck SCA, manage projects across the organisation, or perform
specialised security, compliance, and reporting tasks.

| Role | Description | Key capabilities |
| --- | --- | --- |
| Component Manager | Manages custom components and component version information. | Create, modify, and delete custom components; update component and component version custom fields. |
| Copyright Editor | Manages copyright information for components. | Create, modify, and view copyright statements. |
| Custom Fields Administrator | Manages custom fields used throughout Black Duck SCA. | Create, modify, and delete custom fields. |
| Global Code Scanner | Manages code scans across all projects. | Run, upload, map, unmap, and delete scans. |
| Global Notification Viewer | Provides visibility into notifications across the environment. | View notifications for all projects and receive all system notifications regardless of user preferences. |
| Global Project Group Administrator | Manages project groups across Black Duck SCA. | Create, modify, and delete project groups; manage project group membership. |
| Global Project Administrator | Provides administrative access to all projects. | Create, modify, and delete projects and project versions; assign project roles; manage project settings; run and delete reports; view BOMs. |
| Global Project Manager | Provides management access to all projects and BOMs. | Manage projects, project versions, BOMs, tags, reports, scans, and comments. Can add users to projects but cannot assign project roles. |
| Global Project Viewer | Provides read-only access to all projects. | View all projects, BOMs, reports, dashboards, and comments. Cannot modify BOMs or project settings. |
| Global Release Creator | Creates project versions. | Create project versions. |
| Global Security Manager | Manages global remediation statuses. | Create, modify, and delete remediation statuses for component vulnerabilities. |
| Integration Manager | Manages integrations with external systems. | Configure and manage integrations and integration servers. |
| License Manager | Manages licence-related data across Black Duck. | Create and manage licences, licence families, and licence terms; manage KnowledgeBase licence information. |
| Lite Global Project Manager | Manages lightweight BOMs. | Administer lightweight BOMs. |
| Policy Manager | Manages policy rules. | Create, modify, and delete policy rules. |
| Project Creator | Creates projects. | Create projects, create project versions, and manage projects they create. |
| System Administrator | Administers and configures Black Duck SCA. | Configure system settings, SAML, LDAP, password requirements, system announcements, registration, and system jobs. |
| User Administrator | Manages users and groups. | Create and manage users and groups, reset passwords, manage access tokens, and enable or disable MFA. |
