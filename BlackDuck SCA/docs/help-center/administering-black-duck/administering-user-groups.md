# Administering user groups

You can use user groups in Black Duck to manage global roles and project
team membership for several user accounts at once instead of managing that information
at the individual user account level. You can:

- Create a user group
- Manage user group
  information such as the group name or status
- Manage user group global
  roles
- Add or remove a member from a user group
- Delete a user group

Note: If you are using an external LDAP directory server to authenticate users and have enabled
LDAP group synchronization, the Users & Groups page uses the **Source** column to
identify groups that were created in Black Duck (**Internal**)
and groups that were created because of LDAP authentication (**LDAP**).
