# Managing scans in the Black Duck UI

Use Black Duck's UI to manage scans:

- Uploading a scan file using the Black Duck UI.
- Browsing component scans.
- Mapping a scan to a
  project.
- Removing a scan from a project.
- Deleting a scan.
- Viewing an audit log for a BOM
  file.
