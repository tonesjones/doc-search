# Signature Scanner client requirements

A Windows 7 or later, Mac OS X 10.9 or later, or Linux 64-bit system is required to run Signature Scanner. Client systems must have a minimum of 6 GB of RAM.

The JAVA_HOME environment variable must be set to the location of the JRE which is included in the download of the Signature Scanner. For example:

- Linux: `<INSTALL_DIR>/scan.cli-2026.7.1/jre`
- Mac OS X: `<INSTALL_DIR>``/scan.cli-2026.7.1``/jre/Contents/Home`
- Windows: `<INSTALL_DIR>\scan.cli-2026.7.1\jre`
