# Deleting a project version

You can delete a version from a project.

Note: You cannot delete a project version if that version is a subproject in a BOM: you
must remove the project version from all BOMs before you can delete it. Select the
**Details** tab to view where this project version is used as a
subproject.

To delete a project version:

1. Log in to Black Duck SCA.
2. Select the project name using the **Watching** or **My Projects**
   dashboard. The *Project Name* page appears.
3. Click [image: Down arrow] in the row of the version of the project you want to delete and select
   **Delete**.
4. Click **Delete** to confirm.

   Black Duck removes
   the project version.
