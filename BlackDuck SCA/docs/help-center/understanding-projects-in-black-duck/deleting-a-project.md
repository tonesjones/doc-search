# Deleting a project

CAUTION:

Once you delete a project, you cannot restore it. You can create another
project with the same name, but the new project will not have any of the version or BOM
information associated with the deleted project.

To delete a project:

1. Log in to Black Duck SCA.
2. Locate the project by using the **Watching** or **My Projects**
   dashboard.
3. Click [image: Options icon] in the project you want to delete and select **Delete**.
4. In the Delete Project dialog box, confirm that you have selected the correct
   project, and click **Delete**.

   The project is deleted.
