# Setting a Default SBOM or VEX Template

The default template is automatically pre-selected when a user generates a SBOM or VEX report.

- Setting a default SBOM template
- Setting a default VEX template

## Setting a default SBOM template

To select the default template used in SBOM reports:

1. Click [image: Manage] and then select **SBOM and VEX Templates**.
2. Click the **SBOM** tab.
3. Click [image: Options] of the desired SBOM template and select **Set as Default**.

Once configured, the selected SBOM template will acquire the **Default** tag, indicating that the change has been made.

## Setting a default VEX template

To select the default template used in VEX reports:

1. Click [image: Manage] and then select **SBOM and VEX Templates**.
2. Click the **VEX Templates** tab.
3. Click [image: Options] of the desired VEX template and select **Set as Default**.

Once configured, the selected VEX template will acquire the **Default** tag, indicating that the change has been made.

Note: The System template is the default until you designate a different one. The current default template cannot be deactivated or deleted — set a different template as the default first.
