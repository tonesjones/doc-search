# Deleting a SBOM Template

- Deleting a SBOM template
- Deleting a VEX template

Note:

**Required permissions:** You must have Custom Fields Administrator role permissions to delete templates.

## Deleting a SBOM template

To delete a SBOM template:

1. Click [image: Manage] and then select **SBOM and VEX Templates**.
2. Click the **SBOM** tab.
3. Click [image: Options] of the desired SBOM template and select **Delete**.
4. In the confirmation dialog, verify you have selected the correct template and click **Delete**.

## Deleting a VEX template

To delete a VEX template:

1. Click [image: Manage] and then select **SBOM and VEX Templates**.
2. Click the **VEX** tab.
3. Click [image: Options] of the desired VEX template and select **Delete**.
4. In the confirmation dialog, verify you have selected the correct template and click **Delete**.

Note: The System (built-in) template cannot be deleted. The current default template also cannot be deleted — set a different template as the default first.
