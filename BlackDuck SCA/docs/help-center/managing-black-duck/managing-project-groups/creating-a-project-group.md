# Creating a Project Group

You can create a project group by following these steps:

1. Log in to Black Duck.
2. Click [image: Administration icon] .
3. Select **Project Groups** to display the Project Group Management page.

     
    [image: image]
4. Click [image: image] and select **Groups and Projects** from the dropdown menu.
5. Click [image: image] and select **Create New...** from the dropdown menu.
6. In the Create New Project Group dialog box:

   1. Type the name of the group in the **Group Name** field. This field is mandatory.
   2. Type a description for the Project Group in the Description field. This field is optional.
   3. Click **Save**. The Project Group Management page updates to display the new group.

You can now:

- Add members and user groups to the project group.
- Validate the generation of SBOM reports against policies.
