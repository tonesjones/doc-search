# Installing the Azure DevOps plugin

From the Azure Pipelines page, add the Black Duck® Detect plug-in for ADO.

Note: If you are an existing Detect user, manually uninstall the Synopsys Detect Plugin and install the Black Duck® Detect plugin to receive future updates.

**Install the Detect extension for Azure DevOps**

- Click the plus sign (**+**) under Tasks for Agent Job
- Search for the Detect plugin and click **Add** to add it to your pipeline.
