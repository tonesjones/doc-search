# Detect basic workflow

Using Detect to analyze your code typically involves the following basic steps:

1. Satisfy system and other execution requirements
2. Download Detect
3. Determine how you will configure Detect to connect to your Black Duck® SCA server
4. Determine how you will configure Detect to execute the desired functions
5. Run Detect
6. Examine the analysis results
7. Generate desired reports
