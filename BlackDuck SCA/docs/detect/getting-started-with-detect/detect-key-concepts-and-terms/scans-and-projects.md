# Scans and projects

A project is the base unit in Black Duck® SCA and Black Duck® Detect. A project can be both a stand-alone development project and part of another project. For example, Apache Tomcat is a project but it may also be part of other, larger projects, that make use of its functionality.

Detect scans are mapped to one project. A project version can have more than one scan mapped to it, which enables the mapping of multiple separate folders and their scan results into one aggregated project version.
