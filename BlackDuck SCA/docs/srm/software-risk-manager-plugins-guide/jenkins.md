# Jenkins

The Software Risk Manager Jenkins plugin integrates the Jenkins continuous integration
platform with your Software Risk Manager server. It allows you to push build results to
your Software Risk Manager server as part of the build process.

A Software Risk Manager project and an API key are required. The API key must
have the `create`
role for
the project.

This section of the Plugins Guide explains how to install and use the Jenkins plugin. For
more information you may visit the [Official Code Dx Jenkins Wiki Page](https://plugins.jenkins.io/codedx/) or our
[GitHub Repository](https://github.com/jenkinsci/codedx-plugin). This plugin is open source and we welcome
community involvement.
