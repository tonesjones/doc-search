# Issue Tracking

Click the Integrations icon in the navigation bar and select Issue Tracking to open the
Issue Tracking page.

[image: image]

Use the Search field to search for a specific tool.

SRM supports the following issue tracking tools (click the link for more
information):

- Azure
  DevOps
- GitHub
- GitLab
- Jira
- ServiceNow
