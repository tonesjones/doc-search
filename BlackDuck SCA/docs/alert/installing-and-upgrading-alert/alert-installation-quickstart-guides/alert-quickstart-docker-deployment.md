# Alert Quickstart: Docker Deployment

This section provides a quickstart for deploying Alert using Docker,
including Docker Swarm–based deployment scenarios and common configuration options.

Use the topics in this section to deploy Alert in a Docker-based environment.
These quickstarts focus on getting Alert up and running quickly using Docker Swarm,
with variations for different infrastructure and database requirements.

The topics that follow walk through standard Docker Swarm deployments,
standalone configurations, and deployments that use an external database.

- Docker Swarm Deployment
- Docker Swarm Standalone Deployment
- Docker Swarm Deployment with External Database
