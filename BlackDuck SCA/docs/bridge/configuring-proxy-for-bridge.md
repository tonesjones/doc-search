# Configuring proxy for Bridge

Standard proxy environment variables are supported by Bridge CLI, Black Duck Security Scan Action, Black Duck Security Scan Template, and Black Duck Security Scan Extension for Azure DevOps.

- HTTP_PROXY – Bridge will use the specified proxy.
- HTTPS_PROXY – Bridge will use the specified HTTPS proxy.
- NO_PROXY – Provide a list of domains to be excluded from proxying.

Note: Black Duck® SCA users, see Using Bridge CLI with Black Duck SCA for additional information about proxy configuration.
