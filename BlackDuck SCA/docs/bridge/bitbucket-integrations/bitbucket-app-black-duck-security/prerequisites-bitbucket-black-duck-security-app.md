# Prerequisites: Bitbucket Black Duck Security App

The prerequisites for installing the Black Duck Security App are found here. Please ensure all requirements in each section are completed.

## Compatibility

The Bitbucket App is intended solely for Bitbucket Cloud users; the data center is not supported.

## Bitbucket Workspace requirements

To install the forge app you must possess **Owner** or **Admin** permissions in your Bitbucket workspace. For further details to create Admin permissions please consult the official Bitbucket documentation. Installing forge app is optional.

## Next steps

Once all prerequisites are satisfied, proceed to the user guide to ensure that preliminary steps have been considered and perform the installation process.
