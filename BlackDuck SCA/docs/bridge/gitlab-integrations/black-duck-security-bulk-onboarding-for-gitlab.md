# Black Duck Security Bulk Onboarding for GitLab

Black Duck Security Bulk Onboarding provides a streamlined user interface for workflow configuration. Users may use the menus to generate and inject workflow configuration files on their projects. The bulk onboarding solution supports bulk workflow configuration, for configuring multiple projects at once. Users may also tailor configurations to small sets of projects, or use the bulk onboarding solution to configure a single project.

Note: Current support is for Black Duck® SCA, Coverity and Polaris.
