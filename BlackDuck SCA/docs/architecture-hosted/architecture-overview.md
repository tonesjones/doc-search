# Architecture Overview

Black Duck helps security and development teams identify
and mitigate open source related risks across application portfolios. Black Duck scans and identifies open source software
throughout your code base, maps vulnerabilities to your open source software, triages
vulnerability results and tracks remediation, and monitors for newly disclosed
vulnerabilities in your open source code.

- Scans and identifies open source software throughout your code base
- Maps vulnerabilities to your open source software
- Triages vulnerability results and tracks remediation
- Monitors for newly disclosed vulnerabilities in your open source code
