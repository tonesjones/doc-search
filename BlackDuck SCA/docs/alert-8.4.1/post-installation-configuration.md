# Post Installation Configuration

Information required to configure Alert after installation.

After installing Alert, you must configure the system to integrate with external providers, define notification behavior, and enable automated processing.

Use the topics in this section to complete the required and optional configuration steps needed to prepare Alert for operational use.

## Post Installation Configuration Topics

- Configuring Alert
- Configuring Providers
- Configuring Channels
- Configuring Distribution Jobs
- Scheduling Notifications
- Scheduling Auditing Notifications
- Encryption and Proxy Configuration
