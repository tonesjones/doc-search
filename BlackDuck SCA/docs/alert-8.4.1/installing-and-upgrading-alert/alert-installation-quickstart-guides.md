# Alert Installation Quickstart Guides

There are two deployment options for Alert when deployed in Kubernetes - within the same
namespace as Black Duck SCA, or in its own namespace *standalone*.

There are several different deployment options for Alert when deployed in Docker.
Standalone where is it deployed under its own stack, or *integrated*, where it is
deployed within a Black Duck SCA deployment, and in both cases either using an internal or
external database.

Below are quickstart guides for different deployment configurations of Alert. These are
base deployments, please refer to the install and configuration sections of the
documentation for a more in depth overview.

## Docker Swarm

- Internal Database (integrated mode)
- Internal Database (standalone mode)
- External Database (integrated mode)

## Kubernetes (HELM)

- Internal Database (integrated mode)
- Internal Database (standalone mode)
- External Database (integrated mode)
