# Announcements for Version 2021.6.0

## Support ending for PostgreSQL version 9.6 for external databases

As of the Black Duck 2021.6.0 release, Black Duck has ended support for PostgreSQL
version 9.6 for external databases.

Black Duck will now only support PostgreSQL version 11.x for external
databases.

## Deprecated page

As announced previously, the Scans > Components page has been removed.

## Deprecated APIs

The following endpoints have been deprecated:

- GET /oauthclients
- POST /oauthclients
- DELETE /oauthclients/{oAuthClientId}
- GET /oauthclients/{oAuthClientId}
- PUT /oauthclients/{oAuthClientId}
- POST /vulnerabilities/vulndb-copy

## Japanese language

The 2021.4.0 version of the UI, online help, and release notes has been localized to
Japanese.
