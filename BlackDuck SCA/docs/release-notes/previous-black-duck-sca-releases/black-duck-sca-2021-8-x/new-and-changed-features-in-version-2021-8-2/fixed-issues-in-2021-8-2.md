# Fixed Issues in 2021.8.2

The following customer-reported issues were fixed in this release:

- (HUB-31078). Documented an issue where install and upgrade to Black Duck
  2021.8 would fail in Kubernetes when the `--reuse-values`
  flag is used as part of the installation/upgrade. Please refer to the
  REAME.md under Helm charts for more details.
- (HUB-31086). Fixed an issue where the snippets box at top right side of BOM
  Page was missing for few project versions.
- (HUB-31156). Fixed an issue where users with the Project level BOM Manager
  role and without any Global or Overall roles would not able to access the
  Project BOM.
