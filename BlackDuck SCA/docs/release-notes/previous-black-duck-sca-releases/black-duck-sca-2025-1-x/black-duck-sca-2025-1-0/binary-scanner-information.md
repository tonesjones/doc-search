# Binary scanner information

The binary scanner has been updated to version **2024.12.2**.

## Release highlights

- Added support for ARM64 architecture
- NET scanner updated:

  - Reduced unknown version components on BOM for less manual triage
  - More accurately reflect .NET component structure

For a comprehensive list of changes, see the Black Duck Binary Analysis[release notes](https://docs.blackduck.com/access?ft:originId=e710b88e10dda3e8bddaa3cb6e7c882d/454e2874b0adf4a86f94f01b7643f5be.topic).
