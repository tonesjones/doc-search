# Fixed Issues in 2021.4.1

The following customer-reported issues were fixed in this release:

- (Hub-28347). Fixed an issue where bulk snippet adjustments failed with
  the following error: "Adjustment Failed: The server encountered an
  error, please check your connection and try again."
- (Hub-28807). Fixed an issue where the following error was seen in the
  Artifactory plugin: "Too many parameters error on
  /api/projects/<projectID>/versions/<projectVersionID>/components/<componentID>/versions/<componentVersionID>?offset=0&limit=100."
- (Hub-29002). Fixed an issue where filtering for unignored snippets in the
  Snippet Confirmation window displayed system-wide snippets.
- (Hub-29448). Fixed an issue where the LDAP user authorization failed with
  an IncorrectResultSizeDataAccessException error.
