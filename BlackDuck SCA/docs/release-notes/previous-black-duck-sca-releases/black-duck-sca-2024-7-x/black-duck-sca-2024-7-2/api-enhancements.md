# API enhancements

For more information on API requests, please refer to the REST API Developers Guide
available in Black Duck.

## Updated snippet matching API

The `POST /api/snippet-matching` API request has been updated to
accept fingerprints generated from source code via an algorithm provided by Black Duck to customers.
