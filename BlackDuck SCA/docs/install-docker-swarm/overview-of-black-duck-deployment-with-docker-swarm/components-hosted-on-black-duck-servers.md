# Components hosted on Black Duck servers

The following remote Black Duck services are leveraged by Black Duck:

- Registration server: Used to validate Black Duck's license.
- Black Duck KnowledgeBase server: The Black Duck KnowledgeBase (KB) is the
  industry’s most comprehensive database of open source project, license, and
  security information. Leveraging the Black Duck KB in the cloud ensures that Black Duck can display the most up-to-date information about
  open source software (OSS) without requiring regular updates to your Black Duck installation.
