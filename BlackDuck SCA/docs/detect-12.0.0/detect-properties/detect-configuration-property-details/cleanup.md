# cleanup

## Cleanup Output

```
--detect.cleanup=true
```

If true, the files created by Detect will be cleaned up.

| Details |  |
| --- | --- |
| Added | 3.2.0 |
| Type | Boolean |
| Default Value | true |
| Comma Separated | No |
| Case Sensitive | No |
| Acceptable Values | Any |
| Strict | No |
