# global

## Autonomous Scan Enabled (Advanced)

```
--detect.autonomous.scan.enabled=false
```

If true, Detect will enable autonomous scanning feature.

| Details |  |
| --- | --- |
| Added | 9.8.0 |
| Type | Boolean |
| Default Value | false |
| Comma Separated | No |
| Case Sensitive | No |
| Acceptable Values | Any |
| Strict | No |
