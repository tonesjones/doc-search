# Detect configuration overview

What Detect looks at and how it performs analysis depends on how it is configured.

Note: For accurate SCA analysis, Detect should typically be executed as a post-build step in the native build environment.

Using properties, you can configure the following:

- What code to examine
- Authentication information
- Connection information
- Required detectors
- Sensitivity to policy violations
- Reporting
- Logging
