# Getting started with Detect

Before you start using Detect, it is recommended that you become familiar with the makeup of Detect and how it works. Review the 'Getting started with Detect' pages listed in the left-hand menu, to learn about, and prepare to start using Detect.

For a quick tutorial see: [Introduction to Scanning](https://community.blackduck.com/s/article/Black-Duck-Introduction-to-Scanning).

Note: Detect documentation is incremental in nature with new functionality and changes indentified in the Release notes and Properties. However, documentation is also available for previous Detect versions by navigating to the documentation portal [linked here](https://docs.blackduck.com) and selecting one of the hosted document versions from the drop-down when viewing Detect documentation.
