# Installation

## Prerequirements

Minimum version of Black Duck SCA required is 2020.10.0

## Installation commands

To install from pypi:

```
pip install blackduck-c-cpp
```

To install a specific version:

```
pip install blackduck-c-cpp==2.0.0
```
