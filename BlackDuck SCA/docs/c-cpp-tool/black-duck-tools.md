# Black Duck Tools

Welcome to the Black Duck Tools navigation page. Here, you can
easily access and learn about various tools available in the Black Duck ecosystem. Below are the tools currently available:

## Black Duck C/CPP Tool

The Black Duck C/CPP tool allows you to generate a BOM report
for projects written in C/C++ by building the project, capturing the source and
binary files involved, and then delivering a BDIO and signatures to Black Duck SCA.

- Explore the Black Duck
  C/CPP Tool

## SCASS MCP Server

The Black Duck SCA MCP Server connects AI coding assistants to your Black Duck
Software Composition Analysis (SCA) instance using the Model Context Protocol
(MCP).

- Learn more
  about the SCASS MCP Server.
