# Prerequisites: GitLab Black Duck Security Bulk Onboarding

The prerequisites for using Black Duck Security Bulk Onboarding for GitLab are found here. Please ensure all requirements in each section are completed.

## Supported GitLab instances

- GitLab.com (Cloud)

Note: Currently GitLab Self-Managed is not supported for bulk onboarding.

## Minimum role requirement

To use Black Duck Security Bulk Onboarding for GitLab the following is required to successfully onboard GitLab workflows:

- User needs to have minimum of **Developer** role for a GitLab group or GitLab projects.
- Users must have *Read & Write* access to the projects.

## Next steps

Once all prerequisites are satisfied, proceed to the user guide to ensure that preliminary steps have been considered and perform the workflow injection process.
