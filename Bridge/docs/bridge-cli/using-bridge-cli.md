# Using Bridge CLI

Once you have `bridge-cli` executable installed, you are ready to use Bridge CLI to integrate SAST and/or SCA scans into your CI/CD pipeline.

You can run Bridge CLI in one of the following two ways:

1. Passing Arguments using a JSON file
2. Passing Arguments using the CLI

For a complete list of exit codes returned by Bridge CLI, see the Exit codes table.

To configure Bridge with a proxy, see Configuring proxy for Bridge
