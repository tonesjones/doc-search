# Azure DevOps Integrations

Users may integrate Black Duck scanning software with Azure DevOps pipelines in the following two ways:

- **Black Duck Security Bulk Onboarding** is recommended for most users, enabling the configuration of scans for Coverity, Black Duck® SCA or Polaris through an intuitive web interface. Based on the user's selected configuration options within Black Duck Security Azure DevOps Onboarding, a pipeline will be generated that will perform a scan for Coverity, Black Duck® SCA and Polaris. Users can use the app to review, edit and deploy the workflow to selected repositories within their organization.
- **Black Duck Security Scan** is a Azure DevOps Extension that allows users to manually configure workflow files for single repositories.
