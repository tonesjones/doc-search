# Black Duck Security Bulk Onboarding for Azure DevOps

Black Duck Security Bulk Onboarding provides a streamlined user interface for pipeline configuration. Users may use the Black Duck Security Bulk Onboarding menus to generate and install pipeline configuration files on their Azure DevOps repositories. The onboarding solution supports bulk pipeline configuration, for configuring multiple repositories at once. Users may also tailor configurations to small sets of repositories, or use the app to configure a single repository.

Note: Current support is for Black Duck® SCA, Coverity and Polaris

Black Duck Security Bulk Onboarding for Azure DevOps is available at <https://integrations.blackduck.com/onboard>
