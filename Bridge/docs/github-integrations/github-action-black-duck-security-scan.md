# GitHub Action – Black Duck Security Scan

The Black Duck Security Scan Action can be used to integrate Black Duck security testing into your CI pipeline. You can download the GitHub Action directly from the GitHub Marketplace link at: <https://github.com/marketplace/actions/black-duck-security-scan>.

By including and configuring the GitHub Action in your *workflow*.yml file, you can quickly integrate Black Duck security products into your CI pipeline. We recommend using GitHub secrets for sensitive data like access tokens.
