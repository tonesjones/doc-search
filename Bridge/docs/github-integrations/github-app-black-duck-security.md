# GitHub App – Black Duck Security

The Black Duck Security App provides a streamlined user interface for workflow configuration. Users may use the Security App's menus to generate and install workflow configuration files on their repositories. The app supports bulk workflow configuration, for configuring multiple repositories at once. Users may also tailor configurations to small sets of repositories, or use the app to configure a single repository.

Note: Current support is for Black Duck® SCA, Coverity and Polaris.

The Black Duck Security App is available in the Apps section of the GitHub Marketplace at <https://github.com/marketplace/black-duck-security>
