# Bitbucket – Black Duck Security Scan Pipe

Black Duck Security Scan Pipe can be used to integrate Black Duck security testing
into your Bitbucket pipeline.

By including and configuring the Black Duck Security Scan Pipe in your
`bitbucket-pipelines.yml` file, you can quickly integrate Black Duck
security products into your CI pipeline.

You can download Black Duck Security Scan Pipe directly from the Bitbucket Marketplace link at <https://bitbucket.org/blackduck-inc/blackduck-security-scan>

**Please read the Black Duck documentation on Bitbucket prerequisites (listed below) prior to configuring your Black Duck Security Scan Pipe.**
