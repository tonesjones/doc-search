# Jenkins Integrations

The Black Duck Security Scan Plugin for Jenkins allows Black Duck® SCA, Coverity and Polaris scans to run in your Jenkins pipeline.

## How it works

You can configure your jenkinsfile so that static and compositional analysis tests run whenever a contributor pushes code or opens a pull request. By default issues become available in your instance of Black Duck® SCA, Coverity, or Polaris. You can also configure pr comments, so that the plug-in will create pull request comments for new issues found in the pull request.

The plug-in is available on the [Jenkins Marketplace](https://plugins.jenkins.io/blackduck-security-scan/).
