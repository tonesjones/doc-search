# Jenkins prerequisites

## Basic requirements

- Jenkins version 2.492.3 or later.
  - The [Jenkins Pipeline](https://plugins.jenkins.io/workflow-aggregator/) plug-in
- Supported SCMs:
  - Bitbucket
  - GitHub
  - GitLab
- An active license for one of these Black Duck Products: Black Duck® SCA, Coverity, Polaris, SRM.

## Platform requirements for Black Duck Security Scan Plugin for Jenkins

- Java 17
- 8GB of RAM
- Starting with Bridge version 3.5.1, the [Black Duck Security Scan Plugin](https://plugins.jenkins.io/blackduck-security-scan/) now includes support for Linux ARM architectures.
